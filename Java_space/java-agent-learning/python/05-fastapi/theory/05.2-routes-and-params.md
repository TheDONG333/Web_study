# 05.2 路由与参数：GET、路径参数、查询参数

> **学习目标**
> - 会写 GET 接口并返回 JSON
> - 会写路径参数，理解自动类型校验
> - 会写查询参数，分清必填、默认值、可选参数
> - 知道参数类型错误会返回 422

---

## 1. 白话理解：路由就是"哪个 URL 交给哪个函数"

```python
@app.get("/hello")
def hello():
    return {"message": "hello"}
```

- `@app.get("/hello")`：当有人用 GET 请求 `/hello` 时，调用下面的函数
- 函数返回值会自动转成 JSON

> **Java 对照**：`@GetMapping("/hello")` + `@ResponseBody`，写法几乎一一对应。

---

## 2. 最简单的 GET 接口

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/hello")
def hello():
    return {"message": "hello", "code": 200}
```

访问 `http://127.0.0.1:8000/hello`，返回：

```json
{"message": "hello", "code": 200}
```

返回值可以是：

| 返回类型 | 结果 |
|---------|------|
| `dict` | JSON 对象 |
| `list` | JSON 数组 |
| `str` | JSON 字符串 |
| `int` / `float` | JSON 数字 |

> 最常用的是返回 `dict`，结构清晰，方便加 `code`、`message`、`data`。

---

## 3. 路径参数：URL 里的一段

```python
@app.get("/users/{user_id}")
def get_user(user_id: int):
    return {"user_id": user_id, "name": "Tom"}
```

| 请求 | 结果 |
|------|------|
| `/users/1` | `{"user_id": 1, "name": "Tom"}` |
| `/users/abc` | **422**，类型校验失败 |

- `{user_id}` 是占位符
- 函数参数名必须和占位符一致
- `user_id: int` 会自动把字符串转成整数，并校验

> **Java 对照**：`@GetMapping("/users/{id}")` + `@PathVariable Long id`，FastAPI 把两步合成了一步。

### 多个路径参数

```python
@app.get("/users/{user_id}/orders/{order_id}")
def get_order(user_id: int, order_id: int):
    return {"user_id": user_id, "order_id": order_id}
```

---

## 4. 查询参数：URL 问号后面的部分

```python
@app.get("/items")
def list_items(page: int = 1, size: int = 10, keyword: str | None = None):
    return {
        "page": page,
        "size": size,
        "keyword": keyword
    }
```

请求：

```
/items?page=2&size=5&keyword=手机
```

返回：

```json
{"page": 2, "size": 5, "keyword": "手机"}
```

### 规则

| 写法 | 含义 |
|------|------|
| `page: int = 1` | 有默认值 → **可选**，不传就是 1 |
| `size: int = 10` | 同上 |
| `keyword: str \| None = None` | 可选，不传就是 None |
| `q: str`（没有默认值） | **必填**，不传返回 422 |

> `str | None` 是 Python 3.10+ 的写法；也可以写 `Optional[str]`（需要 `from typing import Optional`）。

### 必填查询参数

```python
@app.get("/search")
def search(q: str):
    return {"query": q}
```

- `/search?q=Python` ✅
- `/search` ❌ 422，缺少必填参数 `q`

---

## 5. 路径参数 + 查询参数一起用

```python
@app.get("/users/{user_id}/orders")
def user_orders(user_id: int, page: int = 1, size: int = 10):
    return {
        "user_id": user_id,
        "page": page,
        "size": size
    }
```

请求：

```
/users/1001/orders?page=2&size=5
```

- `user_id` 来自路径
- `page`、`size` 来自查询字符串

---

## 6. 类型校验：FastAPI 的免费保险

```python
@app.get("/items/{item_id}")
def get_item(item_id: int, price: float | None = None):
    return {"item_id": item_id, "price": price}
```

| 请求 | 结果 |
|------|------|
| `/items/1?price=9.9` | ✅ `{"item_id": 1, "price": 9.9}` |
| `/items/abc` | ❌ 422（item_id 不是整数） |
| `/items/1?price=abc` | ❌ 422（price 不是浮点数） |

422 返回示例：

```json
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["path", "item_id"],
      "msg": "Input should be a valid integer...",
      "input": "abc"
    }
  ]
}
```

> **好处**：不用手写 `try: int(...) except ValueError`，框架帮你校验并返回标准错误。

## 7. 路由顺序的小坑

```python
@app.get("/users/me")
def get_me():
    return {"user": "current"}

@app.get("/users/{user_id}")
def get_user(user_id: int):
    return {"user_id": user_id}
```

- `/users/me` 必须写在 `/users/{user_id}` **前面**
- 否则 `me` 会被当成 `user_id`，返回 422

> 规则：**具体路径写在参数路径前面**。

---

## 8. `def` 还是 `async def`？

两种都可以：

```python
@app.get("/sync")
def sync_api():
    return {"type": "sync"}

@app.get("/async")
async def async_api():
    return {"type": "async"}
```

| 写法 | 什么时候用 |
|------|-----------|
| `def` | 普通同步代码（本阶段够用） |
| `async def` | 调用异步库（如异步 HTTP 客户端、异步数据库） |

> 初学先用 `def`，不用纠结；后面 Agent 调异步 SDK 时再切 `async def`。

---

## 9. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ GET 接口 | `@app.get("/path")` + 函数 |
| ✅ 返回值 | dict/list 自动转 JSON |
| ✅ 路径参数 | `{user_id}` + `user_id: int` 自动校验 |
| ✅ 查询参数 | 函数参数不在路径里就是查询参数 |
| ✅ 默认值 | 有默认值 = 可选 |
| ✅ 可选参数 | `str \| None = None` |
| ✅ 必填参数 | 不写默认值 |
| ✅ 422 | 类型不对/缺必填参数时返回 |
| ✅ 路由顺序 | 具体路径写在参数路径前面 |
