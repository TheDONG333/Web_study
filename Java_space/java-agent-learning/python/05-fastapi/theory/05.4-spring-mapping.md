# 05.4 Java 概念对照：把 Spring 经验迁移到 FastAPI

> **学习目标**
> - 把 Spring Boot 的概念一一对应到 FastAPI
> - 看懂同样的接口在两边怎么写
> - 知道哪些地方"形似"，哪些地方"神不同"

---

## 1. 一张总表

| Spring Boot / Java | FastAPI / Python | 说明 |
|--------------------|------------------|------|
| `@SpringBootApplication` 启动类 | `app = FastAPI()` + uvicorn | 应用入口 |
| 内嵌 Tomcat | uvicorn | Web 服务器 |
| `@RestController` | 路由函数集合 | 不需要类 |
| `@GetMapping("/users")` | `@app.get("/users")` | 路由注解/装饰器 |
| `@PostMapping` | `@app.post` | 后续再学 |
| `@PathVariable Long id` | `def f(id: int)` + 路径 `{id}` | 路径参数 |
| `@RequestParam int page` | `def f(page: int = 1)` | 查询参数 |
| `@RequestParam(required = false)` | `def f(kw: str \| None = None)` | 可选参数 |
| `@RequestBody User user` | Pydantic 模型参数 | 后续再学 |
| `@ResponseBody` / 返回对象 | 直接 `return dict` | 自动转 JSON |
| Bean Validation 注解 | 类型注解 + `Query/Path` 约束 | 基础校验 |
| springdoc / Swagger | 内置 `/docs` | 自动文档 |
| `application.yml` | 代码里配置为主 | 少写配置 |
| Service / Mapper 分层 | 函数 / 模块 / 包 | 按项目规模决定 |

## 2. 同一个接口，两边怎么写

### 2.1 Spring Boot

```java
@RestController
@RequestMapping("/users")
public class UserController {

    @GetMapping("/{id}")
    public User getUser(@PathVariable Long id) {
        return new User(id, "Tom");
    }
}
```

### 2.2 FastAPI

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/users/{user_id}")
def get_user(user_id: int):
    return {"id": user_id, "name": "Tom"}
```

### 2.3 对应关系

| Spring | FastAPI |
|--------|---------|
| 类上的 `@RequestMapping("/users")` | 路径里直接写 `/users/{user_id}` |
| 方法上的 `@GetMapping("/{id}")` | `@app.get("/users/{user_id}")` |
| `@PathVariable Long id` | 函数参数 `user_id: int` |
| `return new User(...)` | `return {"id": ..., "name": ...}` |

> **最大的不同**：FastAPI 不需要 Controller 类，**一个函数就是一个接口**。

## 3. 查询参数对照

### 3.1 Spring Boot

```java
@GetMapping("/items")
public List<Item> list(
        @RequestParam(defaultValue = "1") int page,
        @RequestParam(defaultValue = "10") int size,
        @RequestParam(required = false) String keyword) {
    ...
}
```

### 3.2 FastAPI

```python
@app.get("/items")
def list_items(
    page: int = 1,
    size: int = 10,
    keyword: str | None = None
):
    return {"page": page, "size": size, "keyword": keyword}
```

| Spring | FastAPI |
|--------|---------|
| `defaultValue = "1"` | `page: int = 1` |
| `required = false` | `str \| None = None` |
| 参数名 | 函数参数名，必须和 URL 一致 |

## 4. 返回值对照

### Spring Boot

```java
@GetMapping("/hello")
public Map<String, Object> hello() {
    return Map.of("message", "hello", "code", 200);
}
```

### FastAPI

```python
@app.get("/hello")
def hello():
    return {"message": "hello", "code": 200}
```

- Spring 用对象/Map，Jackson 序列化
- FastAPI 直接返回 dict/list，自动 JSON 序列化

> **规范建议**：Agent 接口统一返回 `{"code": 200, "message": "ok", "data": {...}}`，和前面 Spring Boot 章节的 Result 结构保持一致。

## 5. 分层怎么迁移

Spring 项目通常分：

```
Controller → Service → Mapper
```

FastAPI 小项目可以直接：

```
main.py（路由 + 简单逻辑）
```

项目变大后：

```
app/
├── main.py          ← 创建 app
├── routers/         ← 路由（类似 Controller）
├── services/        ← 业务逻辑（类似 Service）
└── models/          ← Pydantic 模型（类似 DTO）
```

> 本阶段先单文件，等 Agent 项目功能多了再拆。**不要为了分层而分层**。

## 6. 几个"神不同"的地方

| 点 | Spring Boot | FastAPI |
|----|-------------|---------|
| 依赖注入 | 容器管理 Bean，`@Autowired` | 默认直接函数调用/模块导入，需要时再引入依赖注入 |
| 参数校验 | Bean Validation 注解 | 类型注解 + Pydantic/Query/Path |
| 异步 | 多线程/WebFlux | 原生 `async def`（也支持普通 def） |
| 配置 | `application.yml` | 代码为主，复杂配置用环境变量/Pydantic Settings |
| 启动 | `java -jar` / IDE | `uvicorn main:app` |
| 文档 | 需要集成 springdoc | 内置 `/docs` |

> **迁移心态**：路由、参数、返回值这三件事几乎一一对应；容器、事务、ORM 这些 Spring 的重型能力，FastAPI 走的是另一套轻量路线，不要硬套。

---

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 路由 | `@GetMapping` ↔ `@app.get` |
| ✅ 路径参数 | `@PathVariable` ↔ 路径占位符 + 类型注解 |
| ✅ 查询参数 | `@RequestParam` ↔ 函数参数 + 默认值 |
| ✅ 返回值 | `@ResponseBody` ↔ 直接 return dict |
| ✅ 文档 | springdoc ↔ 内置 `/docs` |
| ✅ Controller | 类 ↔ 函数 |
| ✅ 最大差异 | 无需容器和大量配置，轻量直接 |
