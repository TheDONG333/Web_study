# 05.1 环境与启动：跑通第一个 FastAPI 服务

> **学习目标**
> - 安装 fastapi 和 uvicorn
> - 理解 `uvicorn main:app --reload` 的含义
> - 会写入口文件并用 `if __name__ == "__main__"` 启动
> - 知道热重载怎么用

---

## 1. 白话理解：FastAPI 是"代码里的 Web 服务"

Spring Boot 里你写 `@RestController`，内嵌 Tomcat 帮你把服务跑起来。  
FastAPI 里你写 Python 函数 + 装饰器，**uvicorn** 帮你把服务跑起来。

| Spring Boot | FastAPI |
|-------------|---------|
| Spring MVC | FastAPI |
| 内嵌 Tomcat | uvicorn（ASGI 服务器） |
| `@RestController` | `@app.get(...)` 装饰器 |
| `application.yml` | 基本不用配，代码即配置 |

> **ASGI** 是 Python 的异步 Web 服务器规范，uvicorn 是实现。现在只要知道"它是 FastAPI 的服务器"即可。

---

## 2. 安装

先激活 venv（模块 1 讲过），然后：

```bash
pip install fastapi "uvicorn[standard]"
```

| 包 | 作用 |
|----|------|
| `fastapi` | Web 框架：路由、参数校验、自动文档 |
| `uvicorn[standard]` | 服务器：把服务跑起来，`[standard]` 带热重载等常用依赖 |

导出依赖：

```bash
pip freeze > requirements.txt
```

---

## 3. 第一个服务

新建项目目录：

```
fastapi-demo/
├── .venv/
├── requirements.txt
└── main.py
```

`main.py`：

```python
from fastapi import FastAPI

app = FastAPI(title="My First API")

@app.get("/")
def root():
    return {"message": "Hello FastAPI"}

if __name__ == "__main__":
    import uvicorn
    uvicorn.run("main:app", host="127.0.0.1", port=8000, reload=True)
```

---

## 4. 两种启动方式

### 4.1 命令行启动（最常用）

在 `main.py` 所在目录执行：

```bash
uvicorn main:app --reload
```

| 部分 | 含义 |
|------|------|
| `main` | 模块名，即 `main.py`（不带 .py） |
| `app` | 文件里的 FastAPI 实例变量名 |
| `--reload` | 改代码自动重启（开发时用） |

启动成功会看到：

```
Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
```

### 4.2 直接运行 Python 文件

```bash
python main.py
```

因为文件末尾有：

```python
if __name__ == "__main__":
    uvicorn.run("main:app", host="127.0.0.1", port=8000, reload=True)
```

> **注意**：`uvicorn.run` 里用字符串 `"main:app"` 而不是 `app` 对象，这样热重载才能工作。

## 6. 热重载：开发时的效率神器

开着 `--reload` 时，修改 `main.py` 并保存，服务会**自动重启**，不用手动 Ctrl+C 再启动。

| 场景 | 用不用 --reload |
|------|----------------|
| 本地开发 | ✅ 用 |
| 生产部署 | ❌ 不用（性能和安全考虑） |

> 如果改了代码没重启，先检查启动命令里有没有 `--reload`。

---

## 7. 常见启动参数

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

| 参数 | 作用 |
|------|------|
| `--host 0.0.0.0` | 允许局域网其他机器访问（默认只允许本机） |
| `--port 8000` | 改端口 |
| `--reload` | 热重载 |

> Windows 上如果 8000 被占用，换成 `--port 8001` 即可。

## 8. 项目结构建议

```
fastapi-demo/
├── .venv/                 ← 虚拟环境，不提交
├── requirements.txt
└── main.py                ← 入口
```

后面 Agent 项目变大后，可以拆成：

```
app/
├── main.py                ← 创建 FastAPI 实例
├── routers/               ← 按业务分路由
└── services/              ← 业务逻辑
```

本模块先保持单文件，够用即可。

## 9. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 安装 | `pip install fastapi "uvicorn[standard]"` |
| ✅ 启动 | `uvicorn main:app --reload` |
| ✅ main:app | 模块名:FastAPI 实例名 |
| ✅ 热重载 | 开发时 `--reload`，改代码自动重启 |
| ✅ `__main__` | 可以直接 `python main.py` 启动 |
| ✅ 验证 | 浏览器访问 `/` 和 `/docs` |
