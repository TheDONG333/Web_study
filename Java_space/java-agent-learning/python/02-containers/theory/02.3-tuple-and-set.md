## 1. 元组 tuple：不能改的列表

### 1.1 创建

```python
point = (3, 5)
colors = ("red", "green", "blue")
single = (1,)          # ⚠️ 一个元素必须带逗号
empty = ()

print(type(point))     # <class 'tuple'>
print(type((1)))       # <class 'int'>  ← 没有逗号，只是普通括号
print(type((1,)))      # <class 'tuple'>
```

> **易错点**：单元素元组 `(1,)` 的逗号不能省，否则就是一个普通的 `1`。

### 1.2 不可变

```python
point = (3, 5)

print(point[0])        # 3
# point[0] = 9         # ❌ TypeError: 'tuple' object does not support item assignment
```

元组创建后**不能增、删、改**。要改只能创建一个新元组：

```python
point = (3, 5)
new_point = (9,) + point[1:]
print(new_point)       # (9, 5)
```

### 1.3 索引、切片、遍历（和列表一样）

```python
colors = ("red", "green", "blue")

print(colors[0])       # red
print(colors[-1])      # blue
print(colors[0:2])     # ('red', 'green')

for color in colors:
    print(color)
```

### 1.4 解包赋值

```python
point = (3, 5)
x, y = point
print(x, y)            # 3 5

# 交换两个变量（不用临时变量）
a, b = 1, 2
a, b = b, a
print(a, b)            # 2 1
```

> `a, b = b, a` 是 Python 的经典写法，底层就是元组解包。

### 1.5 函数多返回值（典型用途）

```python
def get_user():
    return 1001, "Tom"      # 实际返回的是一个元组

user_id, name = get_user()
print(user_id, name)        # 1001 Tom
```

> Java 里要返回多个值通常得建一个 DTO 或 Map，Python 直接用元组。

### 1.6 其他用途

| 场景 | 示例 |
|------|------|
| 固定坐标 / 配置 | `point = (3, 5)` |
| 函数多返回值 | `return code, message` |
| 字典的键 | `{(1, 2): "坐标"}`（元组可哈希） |
| 不希望被修改的数据 | 常量组合 |

## 2. 集合 set：自动去重 + 集合运算

### 2.1 创建

```python
tags = {"vip", "new", "vip"}
print(tags)              # {'vip', 'new'} —— 自动去重

empty = set()            # ⚠️ 空集合只能用 set()
print(type({}))          # <class 'dict'> —— {} 是空字典！
```

- **无序**：打印顺序不保证
- **不重复**：相同的值只保留一个
- **可变**：可以 add / remove

### 2.2 基础操作

```python
tags = {"vip", "new"}

tags.add("active")           # 添加
tags.remove("new")           # 删除，不存在会 KeyError
tags.discard("not_exist")    # 删除，不存在也不报错

print("vip" in tags)         # True
print(len(tags))             # 2
```

| 方法 | 不存在时 |
|------|---------|
| `remove(x)` | 抛 `KeyError` |
| `discard(x)` | 静默忽略 |

> 不确定元素在不在，用 `discard` 更稳。

### 2.3 集合运算：交 / 并 / 差

```python
a = {"vip", "new", "active"}
b = {"vip", "active", "churn"}

print(a & b)      # {'vip', 'active'}      交集：两边都有
print(a | b)      # {'vip', 'new', 'active', 'churn'}  并集：合起来
print(a - b)      # {'new'}                差集：在 a 不在 b
```

| 运算符 | 方法 | 含义 |
|--------|------|------|
| `a & b` | `a.intersection(b)` | 交集 |
| `a \| b` | `a.union(b)` | 并集 |
| `a - b` | `a.difference(b)` | 差集 |

### 2.4 去重

```python
nums = [1, 2, 2, 3, 3, 3]
unique = list(set(nums))
print(unique)            # [1, 2, 3]（顺序不保证）
```

**去重但保留原顺序**（了解，常见技巧）：

```python
unique_ordered = list(dict.fromkeys(nums))
print(unique_ordered)    # [1, 2, 3]
```

> `dict.fromkeys` 利用字典键唯一的特性，顺便保留了插入顺序。

### 2.5 典型场景

| 场景 | 写法 |
|------|------|
| 列表去重 | `list(set(items))` |
| 标签匹配 | `user_tags & product_tags` |
| 权限判断 | `"admin" in user_roles` |
| 找出新增/缺失 | `new_ids - old_ids` |

> **Agent 场景**：工具返回的文档 ID 去重、用户标签与商品标签求交集做推荐。

### 2.6 限制

集合元素必须是**可哈希**的（str、int、tuple），列表和字典不能放进去：

```python
# {[1, 2]}          # ❌ TypeError: unhashable type: 'list'
# {{"a": 1}}        # ❌ TypeError: unhashable type: 'dict'
```

## 3. 四种容器怎么选

| 容器 | 有序 | 可变 | 去重 | 适合 |
|------|------|------|------|------|
| list | ✅ | ✅ | ❌ | 对话历史、结果列表、需要顺序 |
| dict | ✅（插入序） | ✅ | 键唯一 | 带字段的对象、配置、工具参数 |
| tuple | ✅ | ❌ | ❌ | 多返回值、固定数据、字典键 |
| set | ❌ | ✅ | ✅ | 去重、交并差、成员判断 |

> **选择口诀**：**有顺序用 list，有字段用 dict，不能改用 tuple，要唯一用 set。**

---

## 4. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 元组不可变 | 创建后不能改元素 |
| ✅ 单元素元组 | `(1,)` 逗号不能省 |
| ✅ 解包 | `x, y = point`，交换变量很常用 |
| ✅ 函数多返回值 | 返回元组，接收时解包 |
| ✅ 集合自动去重 | 无序，重复值只留一个 |
| ✅ 空集合 | 用 `set()`，`{}` 是字典 |
| ✅ 集合运算 | `&` 交、`\|` 并、`-` 差 |
| ✅ 选型 | 顺序 list、字段 dict、固定 tuple、唯一 set |
