## 1. 白话理解：列表是"有顺序、可修改的排号柜"

```python
fruits = ["苹果", "香蕉", "橙子"]
```

- **有顺序**：每个元素有下标，从 0 开始
- **可修改**：能增、删、改
- **可重复**：`["a", "a"]` 合法
- **类型不限**：`[1, "a", True]` 也合法（但建议同类放一起）

> **Java 对照**：相当于 `ArrayList<Object>`——长度可变、能装任意类型。

## 2. 增删改查

### 2.1 增加

```python
nums = [1, 2]

nums.append(3)          # 末尾加一个元素
print(nums)             # [1, 2, 3]

nums.extend([4, 5])     # 把另一个列表的元素逐个加进来
print(nums)             # [1, 2, 3, 4, 5]

nums.insert(0, 99)      # 在下标 0 处插入
print(nums)             # [99, 1, 2, 3, 4, 5]
```

| 方法 | 作用 | 例子 |
|------|------|------|
| `append(x)` | 末尾加**一个**元素 | `[1,2].append(3)` → `[1,2,3]` |
| `extend(iterable)` | 把可迭代对象的元素**逐个**加入 | `[1].extend([2,3])` → `[1,2,3]` |
| `insert(i, x)` | 在下标 i 处插入 | `[1,3].insert(1,2)` → `[1,2,3]` |

> **最易混**：`append([4,5])` 会把整个列表当成一个元素，结果是 `[1,2,[4,5]]`；要逐个加用 `extend`。

### 2.2 删除

```python
nums = [10, 20, 30, 20]

last = nums.pop()       # 删除并返回最后一个
print(last)             # 20
print(nums)             # [10, 20, 30]

first = nums.pop(0)     # 删除并返回指定下标
print(first)            # 10

nums.remove(20)         # 删除第一个值为 20 的元素
print(nums)             # [30]
```

| 方法 | 按什么删 | 返回值 | 找不到时 |
|------|---------|--------|---------|
| `pop(i)` | 下标（默认最后一个） | 被删元素 | `IndexError` |
| `remove(x)` | 值（第一个匹配） | `None` | `ValueError` |

> **选择**：知道下标用 `pop`，知道值用 `remove`。

### 2.3 修改

```python
nums = [1, 2, 3]
nums[1] = 99
print(nums)             # [1, 99, 3]
```

### 2.4 查询

```python
nums = [10, 20, 30, 20]

print(nums[0])          # 10
print(nums[-1])         # 20（最后一个）
print(len(nums))        # 4
print(nums.index(20))   # 1（第一个 20 的下标）
print(20 in nums)       # True
```

> `index(x)` 找不到会抛 `ValueError`，不确定时先用 `in` 判断。

## 3. 排序与反转

```python
nums = [3, 1, 2]

nums.sort()             # 原地升序，返回 None
print(nums)             # [1, 2, 3]

nums.sort(reverse=True) # 原地降序
print(nums)             # [3, 2, 1]

nums.reverse()          # 原地反转
print(nums)             # [1, 2, 3]

new_nums = sorted([3, 1, 2])   # 返回新列表，原列表不变
print(new_nums)                # [1, 2, 3]
```

| 写法 | 是否改原列表 | 返回值 |
|------|-------------|--------|
| `lst.sort()` | ✅ | `None` |
| `sorted(lst)` | ❌ | 新列表 |
| `lst.reverse()` | ✅ | `None` |

> **坑**：`nums = nums.sort()` 会把 `nums` 变成 `None`——因为 sort 是原地排序，不返回新列表。

## 4. 索引、切片、遍历

### 4.1 切片（和字符串一样）

```python
nums = [0, 1, 2, 3, 4, 5]

print(nums[1:4])     # [1, 2, 3]（左闭右开）
print(nums[:3])      # [0, 1, 2]
print(nums[3:])      # [3, 4, 5]
print(nums[::2])     # [0, 2, 4]
print(nums[::-1])    # [5, 4, 3, 2, 1]（反转）
```

> 切片返回**新列表**，修改切片不影响原列表。

### 4.2 遍历

```python
fruits = ["苹果", "香蕉", "橙子"]

for fruit in fruits:
    print(fruit)

for i, fruit in enumerate(fruits):
    print(i, fruit)
```

## 5. 列表推导式（重点）

### 白话理解

列表推导式是"**一行生成新列表**"的写法，相当于把 for 循环 + append 压缩成一句。

```python
# 普通写法
nums = [1, 2, 3, 4]
squares = []
for n in nums:
    squares.append(n * n)

# 推导式写法（等价）
squares = [n * n for n in nums]
print(squares)          # [1, 4, 9, 16]
```

### 5.1 带条件（过滤）

```python
nums = [1, 2, 3, 4, 5, 6]
evens = [n for n in nums if n % 2 == 0]
print(evens)            # [2, 4, 6]
```

### 5.2 带转换

```python
names = ["tom", "jerry"]
upper_names = [name.upper() for name in names]
print(upper_names)      # ["TOM", "JERRY"]
```

### 5.3 处理对话历史（Agent 高频）

```python
history = [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好，有什么可以帮你？"},
    {"role": "user", "content": "介绍一下 Python"}
]

user_messages = [msg["content"] for msg in history if msg["role"] == "user"]
print(user_messages)    # ["你好", "介绍一下 Python"]
```

### 5.4 语法结构

```
[对每个元素做什么  for 元素 in 原列表  if 条件]
```

> **建议**：简单转换/过滤用推导式；逻辑超过一层（嵌套 if、复杂计算）就用普通 for 循环，可读性优先。

## 6. 嵌套列表

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]

print(matrix[0])        # [1, 2, 3]
print(matrix[1][0])     # 4（第二行第一列）

matrix[1][2] = 99       # 修改
print(matrix)           # [[1, 2, 3], [4, 5, 99]]
```

### 遍历嵌套列表

```python
for row in matrix:
    for num in row:
        print(num, end=" ")
```

### 展平（了解）

```python
flat = [num for row in matrix for num in row]
print(flat)             # [1, 2, 3, 4, 5, 99]
```

> 两层 for 的推导式顺序是"**先写外层循环，再写内层循环**"，初学看不懂就用普通循环。

## 7. Agent 场景：列表最常做什么

| 场景 | 写法 |
|------|------|
| 对话历史 | `history.append({"role": "user", "content": text})` |
| 提取所有消息内容 | `[msg["content"] for msg in history]` |
| 过滤用户消息 | `[m for m in history if m["role"] == "user"]` |
| 工具返回结果列表 | `results = [tool1(), tool2()]` |
| 批量拼接 Prompt | `"\n".join([m["content"] for m in history])` |

---

## 8. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ append vs extend | 加一个元素 vs 逐个加多个 |
| ✅ pop vs remove | 按下标删 vs 按值删 |
| ✅ sort 原地排序 | 返回 None，别赋值 |
| ✅ 切片 | 左闭右开，返回新列表 |
| ✅ 列表推导式 | `[表达式 for x in 列表 if 条件]` |
| ✅ 嵌套列表 | `matrix[行][列]` |
| ✅ Agent 高频 | 对话历史、过滤消息、拼接 Prompt |
