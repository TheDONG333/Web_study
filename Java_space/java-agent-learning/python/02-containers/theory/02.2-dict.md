> - 会写字典推导式

## 1. 白话理解：字典是"带名字的储物格"

```python
user = {
    "name": "Tom",
    "age": 25,
    "role": "admin"
}
```

- 每个值都有一个**键（key）**，通过键取值，不靠下标
- 键必须唯一；重复赋值会覆盖
- 键必须是**不可变类型**（str、int、tuple），list / dict 不能当键
- Python 3.7+ 字典**保留插入顺序**（但不要依赖它做排序）

> **Java 对照**：相当于 `HashMap<String, Object>`，但取值语法更简单：`user["name"]`。

## 2. 增删改查

### 2.1 查：`d[key]` vs `d.get(key)`

```python
user = {"name": "Tom", "age": 25}

print(user["name"])          # Tom
print(user["email"])         # ❌ KeyError: 'email'
```

键不存在时，`d[key]` 直接抛 `KeyError`。生产代码更常用 `get`：

```python
print(user.get("email"))              # None（不报错）
print(user.get("email", "未填写"))     # 未填写（给默认值）
```

| 写法 | 键不存在时 | 建议 |
|------|-----------|------|
| `d[key]` | 抛 `KeyError` | 确定键一定存在时用 |
| `d.get(key)` | 返回 `None` | 不确定时用 |
| `d.get(key, 默认值)` | 返回默认值 | **生产必用** |

> **Agent 场景**：模型返回的 JSON 经常缺字段，一律用 `get` 取值，避免程序崩掉。

### 2.2 增 / 改

```python
user = {"name": "Tom"}

user["age"] = 25             # 键不存在 → 新增
user["name"] = "Jerry"       # 键已存在 → 修改

print(user)                  # {'name': 'Jerry', 'age': 25}
```

> 字典的"增"和"改"是同一个写法：**存在就改，不存在就加**。

### 2.3 删

```python
user = {"name": "Tom", "age": 25, "email": "tom@demo.com"}

age = user.pop("age")                 # 删除并返回值 → 25
missing = user.pop("phone", None)     # 不存在时返回 None，不报错

del user["email"]                     # 直接删除，不存在会 KeyError
print(user)                           # {'name': 'Tom'}
```

| 方式 | 不存在时 | 返回值 |
|------|---------|--------|
| `pop(key)` | `KeyError` | 被删的值 |
| `pop(key, 默认值)` | 返回默认值 | 默认值 |
| `del d[key]` | `KeyError` | 无 |

## 3. 常用方法

### 3.1 keys / values / items

```python
user = {"name": "Tom", "age": 25}

print(user.keys())      # dict_keys(['name', 'age'])
print(user.values())    # dict_values(['Tom', 25])
print(user.items())     # dict_items([('name', 'Tom'), ('age', 25)])
```

### 3.2 遍历

```python
# 遍历键
for key in user:
    print(key, user[key])

# 遍历键值对（最常用）
for key, value in user.items():
    print(key, "=", value)
```

> `items()` 返回的是"键值对元组"，所以可以直接 `for key, value in ...` 解包（元组下一节讲）。

### 3.3 update：合并 / 批量更新

```python
config = {"model": "gpt-4o-mini", "temperature": 0.7}

config.update({"temperature": 0.5, "max_tokens": 2048})

print(config)
# {'model': 'gpt-4o-mini', 'temperature': 0.5, 'max_tokens': 2048}
```

- 已存在的键 → 覆盖
- 不存在的键 → 新增

> **Agent 场景**：默认配置 + 用户配置合并，`update` 一句搞定。

## 4. 字典推导式

### 4.1 基本写法

```python
prices = {"apple": 5, "banana": 3, "orange": 8}

# 所有价格打八折
discounted = {name: price * 0.8 for name, price in prices.items()}
print(discounted)
# {'apple': 4.0, 'banana': 2.4, 'orange': 6.4}
```

### 4.2 带条件过滤

```python
expensive = {name: price for name, price in prices.items() if price >= 5}
print(expensive)        # {'apple': 5, 'orange': 8}
```

### 4.3 结构

```
{键表达式: 值表达式  for 键, 值 in 原字典.items()  if 条件}
```

> 列表推导式返回列表 `[]`，字典推导式返回字典 `{}`，只是括号和"键:值"不同。

## 5. 嵌套字典（Agent 的核心数据结构）

### 5.1 长什么样

```python
agent_state = {
    "session_id": "s001",
    "config": {
        "model": "gpt-4o-mini",
        "temperature": 0.7,
        "max_tokens": 1024
    },
    "user": {
        "id": 1001,
        "name": "Tom",
        "tags": ["vip", "new"]
    },
    "tools": {
        "search": {"enabled": True, "timeout": 30},
        "calculator": {"enabled": False, "timeout": 5}
    }
}
```

### 5.2 读取和修改

```python
print(agent_state["config"]["model"])          # gpt-4o-mini
print(agent_state["user"]["tags"][0])          # vip

agent_state["config"]["temperature"] = 0.3     # 改嵌套值
agent_state["tools"]["search"]["timeout"] = 60
```

> 一层一层往下取，每一层都是一个字典或列表。

### 5.3 安全读取：get 链

```python
model = agent_state.get("config", {}).get("model", "unknown")
print(model)        # gpt-4o-mini

timeout = agent_state.get("tools", {}).get("search", {}).get("timeout", 10)
print(timeout)      # 60
```

> 任何一层缺失都不会报错，返回默认值——**处理模型返回结果时特别有用**。

## 6. Agent 场景：字典几乎无处不在

### 6.1 对话历史（列表套字典）

```python
history = [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好，有什么可以帮你？"}
]

history.append({"role": "user", "content": "介绍一下 Python"})
```

### 6.2 Prompt 变量

```python
variables = {"name": "Tom", "task": "总结这段文字"}

prompt = f"用户：{variables['name']}\n任务：{variables['task']}"
print(prompt)
```

### 6.3 工具入参

```python
tool_args = {
    "query": "Python 教程",
    "top_k": 5,
    "filters": {"category": "编程"}
}

print(tool_args.get("top_k", 10))
```

### 6.4 大模型返回结果（多层嵌套）

```python
response = {
    "choices": [
        {
            "message": {
                "role": "assistant",
                "content": "你好，我是 AI 助手"
            }
        }
    ]
}

content = response["choices"][0]["message"]["content"]
print(content)      # 你好，我是 AI 助手
```

> 记住这个路径：`choices → [0] → message → content`，以后调 API 天天用。

### 6.5 和 JSON 的关系

| Python | JSON |
|--------|------|
| `dict` | object `{}` |
| `list` | array `[]` |

> 请求体、响应体、配置文件、对话历史，最终都是"**列表 + 字典**"的组合，再用 `json.dump` 存盘（回忆 01.5）。

## 7. 常见坑

| 坑 | 错误 | 正确 |
|----|------|------|
| 用不存在的键 | `user["email"]` → KeyError | `user.get("email", "未填写")` |
| 把列表当键 | `{[1,2]: "x"}` → TypeError | 键用 str / int / tuple |
| 遍历时修改字典 | `for k in d: del d[k]` → RuntimeError | 先 `list(d.keys())` 再删 |
| 以为 `{}` 是空集合 | `type({})` 是 dict | 空集合用 `set()` |
| 直接 `d.get("a")["b"]` | 第一层不存在返回 None，再取就崩 | `d.get("a", {}).get("b")` |

---

## 8. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 取值 | 不确定键是否存在就用 `get(key, 默认值)` |
| ✅ 增改 | `d[key] = value`，存在即改，不存在即增 |
| ✅ 删除 | `pop(key, 默认值)` 最安全 |
| ✅ 遍历 | `for k, v in d.items()` |
| ✅ update | 合并配置/批量更新 |
| ✅ 字典推导式 | `{k: v for k, v in d.items() if 条件}` |
| ✅ 嵌套取值 | 逐层 `["key"]`，安全读取用 get 链 |
| ✅ Agent 地位 | 对话消息、配置、工具参数、模型返回全是字典 |
