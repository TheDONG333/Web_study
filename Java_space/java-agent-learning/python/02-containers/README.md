## 自检清单

- [ ] 能分清 append / extend / insert 的区别
- [ ] 知道 pop 和 remove 的区别，index 找不到会怎样
- [ ] 会写列表推导式（带条件、带转换）
- [ ] 会读写嵌套列表
- [ ] 会用 `d[key]` 和 `d.get(key, 默认值)`，知道前者什么时候报 KeyError
- [ ] 会用 keys / values / items 遍历字典
- [ ] 会写字典推导式
- [ ] 能读写三层嵌套字典（Agent 状态）
- [ ] 知道元组不可变，会解包赋值
- [ ] 会用 set 去重、求交并差
- [ ] 能说出列表、字典、元组、集合各自适合什么场景

## 了解即可（不深挖）

- collections：defaultdict / Counter / namedtuple
- 生成器表达式、迭代器基础概念
- 容器的高级排序（`key=`）、切片进阶

## 完全不用学

- frozenset、array 等冷门容器
- 容器底层实现原理、CPython 源码细节
