# 03.2 *args / **kwargs：可变参数与参数解包

> **学习目标**
> - 会用 `*args` 接收任意个位置参数
> - 会用 `**kwargs` 接收任意个关键字参数
> - 会在调用时用 `*列表` / `**字典` 解包传参
> - 理解大模型 function calling 为什么离不开 `**kwargs`

---

## 1. 白话理解：两种"接住所有"的网

普通参数像**固定数量的盘子**，多一个少一个都不行。  
`*args` / `**kwargs` 像一张大网：**来多少接多少**。

```python
def sum_all(*nums):
    print(nums)          # (1, 2, 3) ← 元组
    return sum(nums)

print(sum_all(1, 2, 3))  # 6
print(sum_all(1, 2, 3, 4, 5))  # 15
```

```python
def show_info(**info):
    print(info)          # {'name': 'Tom', 'age': 25} ← 字典

show_info(name="Tom", age=25)
```

| 写法 | 接住什么 | 收成什么 |
|------|---------|---------|
| `*args` | 多余的位置参数 | 元组 tuple |
| `**kwargs` | 多余的关键字参数 | 字典 dict |

> 名字 `args` / `kwargs` 只是惯例，叫 `*nums` / `**info` 也行；**关键是 `*` 和 `**` 的个数**。

## 2. 组合使用

### 2.1 参数顺序

```python
def func(a, b=2, *args, **kwargs):
    print("a =", a)
    print("b =", b)
    print("args =", args)
    print("kwargs =", kwargs)

func(1, 3, 5, 7, x=10, y=20)
```

输出：

```
a = 1
b = 3
args = (5, 7)
kwargs = {'x': 10, 'y': 20}
```

顺序规则：

```
普通参数 → 默认参数 → *args → **kwargs
```

> `*args` 必须在 `**kwargs` 前面；默认参数必须在 `*args` 前面。

### 2.2 一个函数接受任意参数

```python
def log(level, *messages, **extra):
    print(f"[{level}]", *messages)
    if extra:
        print("附加信息:", extra)

log("INFO", "任务开始", "模型=gpt-4o", user="Tom")
```

输出：

```
[INFO] 任务开始 模型=gpt-4o
附加信息: {'user': 'Tom'}
```

## 3. 调用时解包：`*` 和 `**` 反过来用

### 3.1 把列表拆成位置参数

```python
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add(*nums))       # 6，等价于 add(1, 2, 3)
```

### 3.2 把字典拆成关键字参数

```python
def create_user(name, age, city="北京"):
    return f"{name}, {age} 岁, 来自 {city}"

params = {"name": "Tom", "age": 25, "city": "上海"}
print(create_user(**params))
```

> **不加 `**` 会怎样？** `create_user(params)` 会把整个字典当成第一个位置参数 `name`，直接报错或结果错误。

### 3.3 两种一起用

```python
def func(a, b, c=3):
    print(a, b, c)

args = [1, 2]
kwargs = {"c": 99}
func(*args, **kwargs)    # 1 2 99
```

## 4. Agent 场景：大模型 function calling 的核心

### 4.1 模型返回的结构

大模型决定调用工具时，通常返回类似这样的 JSON：

```json
{
  "name": "search",
  "arguments": {
    "query": "Python 装饰器",
    "top_k": 3
  }
}
```

注意：**arguments 是一个字典**，字段数量不固定（不同工具参数不同）。

### 4.2 用 **kwargs 调用工具

```python
def search(query, top_k=5):
    return f"搜索「{query}」，返回 {top_k} 条结果"

tool_call = {
    "name": "search",
    "arguments": {"query": "Python 装饰器", "top_k": 3}
}

result = search(**tool_call["arguments"])
print(result)       # 搜索「Python 装饰器」，返回 3 条结果
```

**为什么必须用 `**`**：工具函数的参数名各不相同，只有把字典拆开，才能按名字对上号。

### 4.3 通用分发器

```python
def call_tool(func, arguments):
    return func(**arguments)

print(call_tool(search, {"query": "Agent", "top_k": 2}))
```

> 这就是后面 LangChain / 自研 Agent 里"工具执行器"的雏形。

## 5. 装饰器里的 `*args, **kwargs`（预习）

写装饰器时，你不知道被装饰的函数有几个参数，所以统一写成：

```python
def wrapper(*args, **kwargs):
    return func(*args, **kwargs)
```

- `*args` 原样接住所有位置参数
- `**kwargs` 原样接住所有关键字参数
- 再原样传给原函数

> 下一节装饰器会反复出现这个写法，现在先记住它。

---

## 6. 常见坑

| 坑 | 错误 | 正确 |
|----|------|------|
| 用字典传参忘了 `**` | `func(params)` | `func(**params)` |
| 用列表传参忘了 `*` | `add(nums)` | `add(*nums)` |
| 顺序写反 | `def f(**kwargs, *args)` | `def f(*args, **kwargs)` |
| 以为 args 是列表 | `args.append(...)` | 它是元组，不能 append |
| 参数名写错 | `**{"nmae": "Tom"}` | 字典的键必须和函数参数名一致 |

---

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ `*args` | 收集多余位置参数 → 元组 |
| ✅ `**kwargs` | 收集多余关键字参数 → 字典 |
| ✅ 定义顺序 | 普通 → 默认 → *args → **kwargs |
| ✅ 调用解包 | `f(*列表)`、`f(**字典)` |
| ✅ Agent 用途 | 模型返回 arguments 字典，用 `func(**arguments)` 调用 |
| ✅ 装饰器用途 | `wrapper(*args, **kwargs)` 适配任意函数签名 |
