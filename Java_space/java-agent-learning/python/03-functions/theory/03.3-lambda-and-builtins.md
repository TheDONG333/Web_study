## 1. lambda：一行的匿名函数

### 白话理解

lambda 是"**用完就扔的小函数**"，只适合一句话能写完的逻辑。

```python
double = lambda x: x * 2
print(double(3))        # 6

add = lambda a, b: a + b
print(add(1, 2))        # 3
```

语法：

```
lambda 参数1, 参数2: 表达式
```

- 只能写**一个表达式**，不能写多行、不能写 return
- 结果就是表达式的值
- 通常不单独赋值，而是作为参数传给别的函数

## 2. lambda + sorted：按字段排序

```python
products = [
    {"title": "iPhone", "price": 7999},
    {"title": "键盘", "price": 299},
    {"title": "显示器", "price": 1500}
]

by_price = sorted(products, key=lambda p: p["price"])
print([p["title"] for p in by_price])
# ['键盘', '显示器', 'iPhone']

by_price_desc = sorted(products, key=lambda p: p["price"], reverse=True)
```

| 参数 | 作用 |
|------|------|
| `key=lambda p: p["price"]` | 告诉 sorted 按哪个值排 |
| `reverse=True` | 降序 |

> 这比写一个 `def get_price(p): return p["price"]` 更简洁。

## 3. lambda + map / filter

### 3.1 map：对每个元素做转换

```python
nums = [1, 2, 3, 4]

result = map(lambda x: x * 2, nums)
print(result)            # <map object ...> ← 不是列表！
print(list(result))      # [2, 4, 6, 8]
```

### 3.2 filter：按条件筛选

```python
nums = [1, 2, 3, 4, 5, 6]

result = filter(lambda x: x % 2 == 0, nums)
print(list(result))      # [2, 4, 6]
```

> **重要**：Python 3 的 `map` / `filter` 返回的是**迭代器**，要 `list()` 转成列表才能直接看。只遍历一次时不用转。

### 3.3 和列表推导式对比

```python
nums = [1, 2, 3, 4]

# map + lambda
print(list(map(lambda x: x * 2, nums)))

# 列表推导式（更 Pythonic，初学推荐）
print([x * 2 for x in nums])

# filter + lambda
print(list(filter(lambda x: x > 2, nums)))

# 列表推导式
print([x for x in nums if x > 2])
```

| 写法 | 建议 |
|------|------|
| 简单转换/过滤 | 列表推导式更易读 |
| 已有现成函数 | `map(str, nums)` 可以直接用 |
| 排序的 key | lambda 最常用 |

> **结论**：lambda 最高频的用途是 **sorted / max / min 的 key**，其次是简单的 map/filter。

## 4. 常用内置函数

以下函数**不需要 import**，直接就能用。

### 4.1 len / type / isinstance

```python
print(len("hello"))              # 5
print(len([1, 2, 3]))            # 3
print(type(123))                 # <class 'int'>
print(type("abc"))               # <class 'str'>

print(isinstance(123, int))      # True
print(isinstance("abc", str))    # True
print(isinstance(123, (int, float)))  # True（可以是类型元组）
```

| 函数 | 作用 |
|------|------|
| `len(x)` | 长度（字符串、列表、字典等） |
| `type(x)` | 精确类型 |
| `isinstance(x, 类型)` | 是否是某类型（**推荐用于类型判断**） |

> `type(x) == int` 也能判断，但 `isinstance` 支持继承关系、可传类型元组，工程里更常用。

### 4.2 range / enumerate（复习）

```python
for i in range(3):
    print(i)                 # 0 1 2

fruits = ["苹果", "香蕉"]
for i, fruit in enumerate(fruits, start=1):
    print(i, fruit)          # 1 苹果 / 2 香蕉
```

> 之前讲过，这里只提醒：`range` 左闭右开，`enumerate` 的 `start` 可以指定起始编号。

### 4.3 zip：把多个列表"拉链式"配对

```python
names = ["Tom", "Jerry", "Lucy"]
ages = [25, 30, 28]

for name, age in zip(names, ages):
    print(name, age)

# 快速构建字典
user = dict(zip(names, ages))
print(user)      # {'Tom': 25, 'Jerry': 30, 'Lucy': 28}
```

**注意**：`zip` 以**最短的列表**为准，多出来的会被忽略。

```python
print(list(zip([1, 2, 3], ["a", "b"])))   # [(1, 'a'), (2, 'b')]
```

### 4.4 sorted（复习 + key）

```python
nums = [3, 1, 2]
print(sorted(nums))                  # [1, 2, 3]
print(sorted(nums, reverse=True))    # [3, 2, 1]
```

- 返回**新列表**，原列表不变
- 配合 `key` 按字段排序（见上面的 lambda 部分）

### 4.5 max / min

```python
nums = [3, 1, 5, 2]
print(max(nums))     # 5
print(min(nums))     # 1

# 按字段取最大/最小
products = [
    {"title": "iPhone", "price": 7999},
    {"title": "键盘", "price": 299}
]
most_expensive = max(products, key=lambda p: p["price"])
print(most_expensive["title"])       # iPhone

# 空列表时给默认值
print(max([], default=0))            # 0
```

| 写法 | 作用 |
|------|------|
| `max(列表)` | 最大值 |
| `max(列表, key=...)` | 按某个字段取最大 |
| `max(列表, default=...)` | 空列表时返回默认值 |

## 5. 一张表总结

| 函数 | 一句话 | 示例 |
|------|--------|------|
| `len(x)` | 长度 | `len("abc")` → 3 |
| `type(x)` | 类型 | `type(1)` → int |
| `isinstance(x, T)` | 是否某类型 | `isinstance(1, int)` → True |
| `range(a, b, step)` | 数字序列 | `range(1, 5)` → 1~4 |
| `enumerate(x, start)` | 带下标遍历 | `for i, v in enumerate(...)` |
| `zip(a, b)` | 配对 | `dict(zip(keys, vals))` |
| `sorted(x, key, reverse)` | 排序（新列表） | `sorted(ps, key=lambda p: p["price"])` |
| `max/min(x, key, default)` | 最大/最小 | `max(nums)` |

---

## 6. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ lambda | 一行匿名函数，只能一个表达式 |
| ✅ 高频用途 | sorted / max / min 的 key |
| ✅ map/filter | 返回迭代器，需要 list() 转换 |
| ✅ 列表推导式 | 简单转换/过滤通常更易读 |
| ✅ isinstance | 类型判断首选 |
| ✅ zip | 配对，以最短为准，可配合 dict() |
| ✅ max/min | 支持 key 和 default |
