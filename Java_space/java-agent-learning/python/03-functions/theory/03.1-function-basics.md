## 1. 白话理解：函数是"可重复使用的加工机器"

把一段逻辑包起来，起个名字，以后需要就调用——不用每次复制粘贴。

```python
def greet(name):
    return f"你好，{name}"

print(greet("Tom"))      # 你好，Tom
print(greet("Jerry"))    # 你好，Jerry
```

- `def`：定义函数
- `greet`：函数名（小写 + 下划线）
- `name`：参数
- `return`：返回结果

> **Java 对照**：Python 不需要写返回类型和参数类型，写法更短。

## 2. 返回值 return

### 2.1 有返回值

```python
def add(a, b):
    return a + b

result = add(1, 2)
print(result)      # 3
```

### 2.2 没有 return → 返回 None

```python
def say_hi(name):
    print("你好，", name)

result = say_hi("Tom")
print(result)      # None
```

> 没有显式 `return` 的函数，默认返回 `None`。

### 2.3 提前返回

```python
def check_age(age):
    if age < 0:
        return "年龄不合法"      # 提前结束函数
    if age < 18:
        return "未成年"
    return "成年"
```

### 2.4 多返回值（复习 02.3）

```python
def min_max(nums):
    return min(nums), max(nums)     # 实际返回一个元组

low, high = min_max([3, 1, 5, 2])
print(low, high)                    # 1 5
```

> 接收时直接解包即可，Java 里通常要建 DTO 或数组。

## 3. 参数体系（重点）

### 3.1 位置参数：按顺序传

```python
def create_user(name, age, city):
    return f"{name}, {age} 岁, 来自 {city}"

print(create_user("Tom", 25, "北京"))
```

参数按**位置**一一对应，顺序错了结果就错。

### 3.2 关键字参数：按名字传

```python
print(create_user(name="Tom", age=25, city="北京"))
print(create_user(age=25, name="Tom", city="北京"))   # 顺序可以打乱
```

- 可读性好，参数多时推荐
- 关键字参数必须放在位置参数后面

```python
create_user("Tom", city="北京", age=25)     # ✅ 位置 + 关键字混用
# create_user(name="Tom", 25, "北京")       # ❌ 关键字之后不能再写位置参数
```

### 3.3 默认参数：不传就用默认值

```python
def greet(name, greeting="你好"):
    return f"{greeting}，{name}"

print(greet("Tom"))                    # 你好，Tom
print(greet("Tom", "早上好"))           # 早上好，Tom
print(greet("Tom", greeting="晚上好"))  # 晚上好，Tom
```

规则：

- 默认参数必须放在**非默认参数后面**
- 调用时可以不传，使用默认值

```python
# def f(a=1, b):    # ❌ 默认参数在前，语法错误
def f(a, b=1):      # ✅
    pass
```

### 3.4 默认参数的大坑：不要用可变对象

```python
# ❌ 错误写法：默认列表在所有调用之间共享
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("a"))    # ['a']
print(add_item("b"))    # ['a', 'b']  ← 不是 ['b']！
```

```python
# ✅ 正确写法：默认用 None，函数内部再创建
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

> 这是 Python 最经典的坑之一，**默认参数永远不要写 `[]`、`{}`、`set()`**。

## 4. 变量作用域

### 4.1 局部变量

函数内部定义的变量，只在函数内部有效：

```python
def test():
    local_var = 10
    print(local_var)    # ✅

test()
# print(local_var)      # ❌ NameError
```

### 4.2 全局变量

函数外部定义的变量，函数内部**可以读**：

```python
app_name = "MyAgent"

def show():
    print(app_name)     # ✅ 能读全局变量

show()
```

但**直接修改**会出问题：

```python
count = 0

def increase():
    count = count + 1   # ❌ UnboundLocalError

# 正确（但不推荐）：先声明 global
def increase_ok():
    global count
    count += 1
```

### 4.3 global 关键字（了解，工程中尽量别用）

```python
count = 0

def increase():
    global count
    count += 1

increase()
print(count)    # 1
```

| 做法 | 建议 |
|------|------|
| 函数通过参数接收数据 | ✅ 推荐 |
| 函数通过返回值输出结果 | ✅ 推荐 |
| 用 global 改全局变量 | ⚠️ 尽量别用 |

> **为什么别用 global**：谁都能改、改了什么难以追踪、测试困难。Agent 项目里用参数和返回值传递状态，不要依赖全局变量。

### 4.4 作用域查找顺序

```
局部 → 外层函数 → 全局 → 内置
```

```python
name = "全局"

def outer():
    name = "外层"

    def inner():
        print(name)     # 外层（就近原则）

    inner()

outer()                 # 外层
```

> 和 JavaScript 的作用域链思路一致：**内层能看外层，外层看不到内层**。

## 5. 函数命名与文档（建议）

```python
def calculate_total_price(unit_price, quantity):
    """计算总价：单价 × 数量。"""
    return unit_price * quantity
```

- 函数名用动词开头：`get_user`、`build_prompt`、`call_llm`
- 三个引号写一句说明，方便别人（和 AI）理解
- 一个函数只做一件事

## 6. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ def / return | 无 return 返回 None |
| ✅ 多返回值 | 本质是元组，接收时解包 |
| ✅ 位置参数 | 按顺序对应 |
| ✅ 关键字参数 | 按名字传，顺序可变 |
| ✅ 默认参数 | 放在非默认参数后面 |
| ✅ 默认值别用可变对象 | 用 None 代替 `[]` / `{}` |
| ✅ 局部 vs 全局 | 函数内能读全局，直接改会报错 |
| ✅ global | 了解即可，工程中尽量别用 |
