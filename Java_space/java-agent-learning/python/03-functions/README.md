## 自检清单

- [ ] 会定义函数、返回值，知道没有 return 时返回 None
- [ ] 能分清位置参数、关键字参数、默认参数
- [ ] 知道默认参数为什么不能写可变对象（如 `[]`）
- [ ] 会用 `*args` 接收任意个位置参数
- [ ] 会用 `**kwargs` 接收任意个关键字参数
- [ ] 会在调用时用 `*列表` / `**字典` 解包传参
- [ ] 能说出局部变量和全局变量的区别，知道 global 尽量别用
- [ ] 会写 lambda，并配合 sorted / map / filter 使用
- [ ] 知道 map/filter 返回的是迭代器，需要 list() 转换
- [ ] 会用 len / type / isinstance / zip / max / min
- [ ] 能写出基础装饰器并保留函数名（functools.wraps）
- [ ] 能写出带参数的装饰器（三层结构）
- [ ] 能说出装饰器在 Agent 里的四个典型用途
