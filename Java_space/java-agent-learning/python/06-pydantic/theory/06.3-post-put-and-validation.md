# 06.3 POST / PUT：接收 JSON 请求体并自动校验

> **学习目标**
> - 会写 POST / PUT 接口
> - 知道 Pydantic 模型参数会自动变成请求体
> - 能看懂 422 校验错误
> - 会区分路径参数、查询参数、请求体

---

## 1. 白话理解：POST 是"递一张表格"

GET 参数放在 URL 里，适合查询；POST/PUT 把数据放在**请求体（body）**里，适合提交复杂结构。

```json
{
  "message": "你好",
  "model": "gpt-4o-mini",
  "temperature": 0.7
}
```

Pydantic 模型就是这张表格的模板：**字段、类型、校验规则都写好了，填错直接打回**。

---

## 2. 写第一个 POST 接口

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

class ChatRequest(BaseModel):
    message: str = Field(..., min_length=1, max_length=2000)
    model: str = "gpt-4o-mini"
    temperature: float = Field(0.7, ge=0.0, le=2.0)

@app.post("/chat")
def chat(req: ChatRequest):
    return {
        "reply": f"[{req.model}] 收到：{req.message}",
        "temperature": req.temperature
    }
```

请求：

```
POST /chat
Content-Type: application/json

{
  "message": "你好",
  "model": "gpt-4o",
  "temperature": 0.5
}
```

返回：

```json
{
  "reply": "[gpt-4o] 收到：你好",
  "temperature": 0.5
}
```

> **关键**：函数参数类型是 `BaseModel` 子类，FastAPI 就知道"这是请求体"，自动解析 JSON、校验、转成对象。

## 3. 三种参数怎么区分

```python
@app.put("/agents/{agent_id}")
def update_agent(
    agent_id: int,                  # 路径参数
    force: bool = False,            # 查询参数
    config: AgentConfig = ...       # 请求体
):
    ...
```

| 参数位置 | 写法 | 来源 |
|---------|------|------|
| 路径参数 | 名字在 `{}` 里 | URL 路径 |
| 查询参数 | 普通类型 + 默认值 | URL `?key=value` |
| 请求体 | 类型是 BaseModel | JSON body |

> **规则**：FastAPI 看类型。BaseModel 子类 → 请求体；名字在路径占位符里 → 路径参数；其他 → 查询参数。

## 4. PUT：更新资源

PUT 和 POST 写法一样，只是语义不同：

```python
class AgentConfig(BaseModel):
    model: str = "gpt-4o-mini"
    temperature: float = Field(0.7, ge=0.0, le=2.0)
    max_tokens: int = Field(1024, ge=1, le=8192)

@app.put("/agents/{agent_id}/config")
def update_config(agent_id: int, config: AgentConfig):
    return {
        "agent_id": agent_id,
        "config": config.model_dump(),
        "message": "配置已更新"
    }
```

请求：

```
PUT /agents/1001/config
Content-Type: application/json

{"temperature": 0.3, "max_tokens": 2048}
```

返回：

```json
{
  "agent_id": 1001,
  "config": {"model": "gpt-4o-mini", "temperature": 0.3, "max_tokens": 2048},
  "message": "配置已更新"
}
```

> POST 常用于"创建/执行动作"，PUT 常用于"整体更新资源"，但技术写法完全一样。

## 5. 自动校验：不符合格式直接 422

### 5.1 缺少必填字段

请求：

```json
{"model": "gpt-4o-mini"}
```

响应 422：

```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "message"],
      "msg": "Field required",
      "input": {"model": "gpt-4o-mini"}
    }
  ]
}
```

### 5.2 类型错误

```json
{"message": "你好", "temperature": "abc"}
```

```json
{
  "detail": [
    {
      "type": "float_parsing",
      "loc": ["body", "temperature"],
      "msg": "Input should be a valid number",
      "input": "abc"
    }
  ]
}
```

### 5.3 超出范围

```json
{"message": "你好", "temperature": 3.0}
```

```json
{
  "detail": [
    {
      "type": "less_than_equal",
      "loc": ["body", "temperature"],
      "msg": "Input should be less than or equal to 2",
      "input": 3.0
    }
  ]
}
```

### 5.4 长度不够

```json
{"message": ""}
```

```json
{
  "detail": [
    {
      "type": "string_too_short",
      "loc": ["body", "message"],
      "msg": "String should have at least 1 character",
      "input": ""
    }
  ]
}
```

> **`loc` 的第一项是 `body`**，表示错误在请求体；如果是路径/查询参数，会是 `path` / `query`。

---

## 6. 校验失败时你自己的代码不用动

```python
@app.post("/chat")
def chat(req: ChatRequest):
    # 能走到这里，说明 req 已经通过全部校验
    return {"reply": f"收到：{req.message}"}
```

- 缺字段、类型错、超范围 → FastAPI 在进入函数前就返回 422
- 函数里拿到的 `req` **一定是合法的**
- 不用写 `if not req.message: ...`

> 这就是 Pydantic 相对手写校验的最大价值：**业务代码只处理合法数据**。

---

## 7. `/docs` 里怎么测

1. 打开 `/docs`
2. 找到 POST `/chat`
3. **Try it out**，会看到一个 JSON 编辑器（请求体模板自动生成）
4. 修改字段，点 **Execute**
5. 看 Response body 或 422 错误

> 文档里的请求体模板就是从 Pydantic 模型自动生成的，字段说明来自 `Field(description=...)`。

---

## 8. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ POST/PUT | `@app.post` / `@app.put` |
| ✅ 请求体 | 参数类型是 BaseModel 就是 body |
| ✅ 自动解析 | JSON → 模型对象 |
| ✅ 自动校验 | 不合格直接 422 |
| ✅ `loc` | `body` / `path` / `query` + 字段路径 |
| ✅ 函数内数据一定合法 | 不用手写 if 校验 |
| ✅ `/docs` | 自动生成请求体模板，可直接调试 |
