## 1. 白话理解：Pydantic 是"带校验的数据模板"

前面接收请求，参数都是零散的：

```python
@app.post("/chat")
def chat(message: str, model: str, temperature: float):
    ...
```

如果请求体是一个复杂的 JSON（嵌套消息、工具参数），靠一个个参数接就很乱，也难校验。

Pydantic 的做法：**先定义一张"数据模板"**，FastAPI 自动把 JSON 填进模板并校验。

```python
from pydantic import BaseModel

class ChatRequest(BaseModel):
    message: str
    model: str = "gpt-4o-mini"
    temperature: float = 0.7
```

请求 JSON：

```json
{"message": "你好", "model": "gpt-4o", "temperature": 0.5}
```

FastAPI 自动把它变成一个 `ChatRequest` 对象，字段不对直接返回 422。

> **Java 对照**：Pydantic Model ≈ 实体类 DTO + JSR380 校验注解（`@NotBlank`、`@Min`、`@Max`），但校验规则和类型写在一起，不需要额外注解处理器。

## 2. 定义第一个模型

```python
from pydantic import BaseModel

class ChatRequest(BaseModel):
    message: str
    model: str = "gpt-4o-mini"
    temperature: float = 0.7
    stream: bool = False
```

使用：

```python
req = ChatRequest(message="你好")
print(req.message)          # 你好
print(req.model)            # gpt-4o-mini
print(req.temperature)      # 0.7
print(req.stream)           # False

print(req.model_dump())
# {'message': '你好', 'model': 'gpt-4o-mini', 'temperature': 0.7, 'stream': False}
```

| 字段 | 类型 | 是否必填 |
|------|------|---------|
| message | str | ✅ 必填（没有默认值） |
| model | str | 可选，默认 gpt-4o-mini |
| temperature | float | 可选，默认 0.7 |
| stream | bool | 可选，默认 False |

### 类型自动转换

```python
req = ChatRequest(message="你好", temperature="0.5")
print(req.temperature)      # 0.5（字符串被转成 float）
print(type(req.temperature)) # <class 'float'>
```

> Pydantic 会尝试把 `"0.5"` 转成 `0.5`；转不了就报错。

## 3. 校验失败会怎样

```python
from pydantic import ValidationError

try:
    ChatRequest()           # 缺少必填的 message
except ValidationError as e:
    print(e)
```

输出类似：

```
1 validation error for ChatRequest
message
  Field required [type=missing, input_value={}, input_type=dict]
```

> 在 FastAPI 接口里，这个错误会自动变成 **422** 响应，不需要你写 try/except。

## 4. 常用字段类型

```python
from typing import Any
from pydantic import BaseModel

class Demo(BaseModel):
    name: str
    age: int
    score: float
    active: bool
    tags: list[str]
    metadata: dict[str, Any]
```

| 类型 | 示例值 | 说明 |
|------|--------|------|
| `str` | `"你好"` | 字符串 |
| `int` | `18` | 整数（`"18"` 也会转） |
| `float` | `0.7` | 小数 |
| `bool` | `true` | 布尔 |
| `list[str]` | `["a", "b"]` | 字符串列表 |
| `dict[str, Any]` | `{"k": 1}` | 任意字典 |
| `嵌套模型` | `{...}` | 下一节讲 |

> Python 3.9+ 可以直接用 `list[str]`、`dict[str, Any]`，不需要 `List` / `Dict`。

## 5. 必填、可选、可空

```python
class ChatRequest(BaseModel):
    message: str                       # 必填
    model: str = "gpt-4o-mini"         # 可选，有默认值
    system_prompt: str | None = None   # 可选，可以为 None
```

| 写法 | 含义 | 不传时 |
|------|------|--------|
| `message: str` | 必填 | 422 |
| `model: str = "gpt-4o-mini"` | 可选 | 使用默认值 |
| `system_prompt: str \| None = None` | 可选且可为空 | None |

> **区分**：`str = ""` 是"有默认空字符串"；`str | None = None` 是"可以是空值"。前者类型仍是 str，后者允许 None。

## 6. Field：默认值、描述、校验规则

```python
from pydantic import BaseModel, Field

class ChatRequest(BaseModel):
    message: str = Field(
        ...,
        min_length=1,
        max_length=2000,
        description="用户输入的消息"
    )
    model: str = Field(
        "gpt-4o-mini",
        pattern=r"^[a-zA-Z0-9.\-]+$",
        description="模型名称"
    )
    temperature: float = Field(
        0.7,
        ge=0.0,
        le=2.0,
        description="温度，0~2"
    )
```

| 参数 | 作用 |
|------|------|
| `...` | 必填（相当于没有默认值） |
| `min_length` / `max_length` | 字符串长度 |
| `ge` / `le` | 大于等于 / 小于等于 |
| `gt` / `lt` | 大于 / 小于 |
| `pattern` | 正则匹配（v2 用 pattern，不是 regex） |
| `description` | 显示在 `/docs` 里的说明 |
| `default_factory` | 可变默认值（如 `list`） |

### 列表的默认值

```python
class ChatRequest(BaseModel):
    tags: list[str] = Field(default_factory=list)
```

> 列表/字典这类可变默认值，推荐用 `default_factory`，避免多个实例共享同一个对象。

## 7. Enum：限制取值

```python
from enum import Enum

class Role(str, Enum):
    SYSTEM = "system"
    USER = "user"
    ASSISTANT = "assistant"

class Message(BaseModel):
    role: Role
    content: str
```

使用：

```python
m = Message(role="user", content="你好")
print(m.role)              # Role.USER
print(m.role.value)        # user

# Message(role="boss", content="x")   # ❌ 422，取值不在枚举内
```

> `class Role(str, Enum)` 让枚举值序列化成普通字符串，最适合给 API 用。

## 8. Pydantic v2 常用方法

```python
req = ChatRequest(message="你好")

req.model_dump()            # 转成 dict
req.model_dump_json()       # 转成 JSON 字符串
ChatRequest.model_validate({"message": "你好"})   # 从 dict 创建并校验
ChatRequest.model_json_schema()                  # 生成 JSON Schema
```

| v1 旧写法 | v2 新写法 |
|----------|----------|
| `req.dict()` | `req.model_dump()` |
| `req.json()` | `req.model_dump_json()` |
| `ChatRequest.parse_obj(...)` | `ChatRequest.model_validate(...)` |
| `Field(regex=...)` | `Field(pattern=...)` |

> 网上很多老教程是 v1 写法，照抄会报错。**认准 v2 的 model_ 开头方法**。

## 9. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ BaseModel | 定义数据结构 + 自动校验 |
| ✅ 必填 | 不写默认值 |
| ✅ 可选 | 写默认值或 `\| None = None` |
| ✅ Field | 描述 + 长度/范围/正则校验 |
| ✅ Enum | 限制字段只能取固定值 |
| ✅ v2 方法 | `model_dump` / `model_validate` / `pattern` |
| ✅ Java 对照 | DTO 实体类 + JSR380 校验 |
