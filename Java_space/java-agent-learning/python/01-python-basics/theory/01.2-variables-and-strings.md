> - 掌握 f-string（拼接 Prompt 模板的最高频写法）
> - 掌握 split / join / strip / replace / find / startswith / endswith

## 1. 白话理解：变量是"贴名字的标签"

Java 声明变量像"**造一个固定形状的盒子**"：

```java
int age = 18;        // 盒子只能装 int
```

Python 的变量像"**给对象贴一个名字标签**"：

```python
age = 18             # 标签 age 贴在整数 18 上
age = "十八"          # 同一个标签，改贴到字符串上，完全合法
```

**类型跟着值走，不跟着变量走**。用 `type()` 查看当前值的类型：

```python
age = 18
print(type(age))     # <class 'int'>

age = "十八"
print(type(age))     # <class 'str'>
```

> **和 Java 对照**：Java 是静态类型（编译时检查），Python 是动态类型（运行时才确定）。灵活，但拼写错误、类型用错只能运行时发现——所以要多写、多调试。

## 2. 变量命名规范

| 规则/习惯 | 示例 |
|----------|------|
| 小写 + 下划线（snake_case） | `user_name`、`max_retry_count` |
| 常量用全大写 | `MAX_TOKENS = 4096` |
| 不能数字开头 | ❌ `1name` |
| 不能用关键字 | ❌ `class`、`for`、`None` |
| 见名知意 | ✅ `prompt_template`，❌ `a`、`tmp` |

> Java 的驼峰命名（`userName`）在 Python 里也能跑，但**不符合规范**，统一用下划线。

---

## 3. 五种基础类型

| 类型 | 写法 | 说明 |
|------|------|------|
| `int` | `18`、`-3`、`10**100` | 整数，**没有大小上限** |
| `float` | `3.14`、`1.5e3` | 小数（浮点数） |
| `bool` | `True` / `False` | 首字母大写（Java 是小写） |
| `str` | `"tom"`、`'tom'`、`"""..."""` | 字符串 |
| `NoneType` | `None` | 表示"空"，类似 Java 的 null |

```python
print(type(18))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type(True))       # <class 'bool'>
print(type("tom"))      # <class 'str'>
print(type(None))       # <class 'NoneType'>
```

### 几个必须知道的点

```python
print(10 ** 100)        # 超大整数也没问题（Java 要 BigInteger）
print(0.1 + 0.2)        # 0.30000000000000004（浮点数精度问题）
print(True + 1)         # 2（bool 本质是 int 的子类，了解即可）
```

### 类型转换

```python
int("123")      # 123
int(3.9)        # 3（直接截断，不四舍五入）
float("3.14")   # 3.14
str(123)        # "123"
bool(0)         # False
bool("")        # False
bool("0")       # True（非空字符串都是 True！）
```

> `int("abc")` 会抛 `ValueError`——异常处理那节会讲怎么兜住。

### None 的判断

```python
result = None

if result is None:          # ✅ 规范写法
    print("没有结果")
```

> 判断 None 用 `is None`，不要用 `== None`。原因下一节讲 `is` 时会说。

## 4. 字符串：本模块的重中之重

Agent 的工作本质就是"**把文本拼进去、把结果切出来**"：Prompt 模板、模型回复解析、日志处理，全是字符串操作。

### 4.1 创建字符串

```python
s1 = "hello"              # 双引号
s2 = 'hello'              # 单引号，完全等价
s3 = """你好，
我是多行文本。"""           # 三引号：保留换行

print(s1, s2)
print(s3)
```

> **Agent 场景**：Prompt 通常很长、有多行，用三引号写最自然。

### 4.2 索引：按下标取字符

```python
s = "Python"

print(s[0])     # P
print(s[1])     # y
print(s[-1])    # n（-1 表示最后一个）
print(s[-2])    # o
```

| 写法 | 含义 |
|------|------|
| `s[0]` | 第一个字符 |
| `s[-1]` | 最后一个字符 |
| `s[100]` | ❌ 越界，抛 `IndexError` |

### 4.3 切片：一次取一段

语法：`s[开始:结束:步长]`，**包含开始，不包含结束**（和 Java 的 `substring` 一样是左闭右开）。

```python
s = "Python"

print(s[0:3])    # Pyt
print(s[:3])     # Pyt（省略开始 = 从头）
print(s[3:])     # hon（省略结束 = 到末尾）
print(s[::2])    # Pto（每隔一个取一个）
print(s[::-1])   # nohtyP（步长为 -1 = 反转）
```

### 4.4 字符串不可变

```python
s = "Python"
# s[0] = "J"      # ❌ TypeError: 'str' object does not support item assignment

s = "J" + s[1:]   # ✅ 只能创建一个新字符串
print(s)          # Jython
```

> 所有字符串方法（replace、strip 等）**都返回新字符串，不修改原字符串**。

### 4.5 拼接

```python
name = "tom"
greeting = "你好，" + name        # 用 + 拼接
print(greeting)

line = "-" * 30                  # 重复
print(line)
```

### 4.6 f-string：最常用的格式化方式（必会）

在字符串前加 `f`，用 `{}` 嵌入变量或表达式：

```python
name = "tom"
age = 18

print(f"我叫 {name}，今年 {age} 岁")          # 我叫 tom，今年 18 岁
print(f"明年我 {age + 1} 岁")                 # {} 里可以写表达式
print(f"圆周率约等于 {3.14159:.2f}")          # 保留两位小数 → 3.14
```

**多行 Prompt 模板**（Agent 最常用）：

```python
system_prompt = f"""你是一个助手。
用户的名字是：{name}
请用简洁的中文回答。"""
```

> **Java 对照**：Java 以前用 `String.format("我叫 %s", name)` 或 `+` 拼接；Python 的 f-string 更直观，是本模块最高频的语法。

## 5. 常用字符串方法（必背）

```python
text = "  Hello, Python World  "

print(text.strip())                 # "Hello, Python World"（去首尾空格）
print(text.replace("World", "AI"))  # 替换
print(text.find("Python"))          # 9（找不到返回 -1）
print(text.startswith("  He"))      # True
print(text.endswith("  "))          # True

s = "a,b,c"
parts = s.split(",")                # ["a", "b", "c"]
print(parts)
print("-".join(parts))              # "a-b-c"
```

| 方法 | 作用 | 返回 |
|------|------|------|
| `split(sep)` | 按分隔符切开 | 列表 |
| `join(iterable)` | 用当前字符串连接列表 | 新字符串 |
| `strip()` | 去掉首尾空白 | 新字符串 |
| `replace(old, new)` | 替换所有匹配 | 新字符串 |
| `find(sub)` | 找子串位置 | 下标，找不到 `-1` |
| `startswith(prefix)` | 是否以某内容开头 | bool |
| `endswith(suffix)` | 是否以某内容结尾 | bool |
| `len(s)`（内置函数） | 字符串长度 | int |

### 容易错的两点

```python
# ① join 的元素必须都是字符串
"-".join([1, 2, 3])                  # ❌ TypeError
"-".join(map(str, [1, 2, 3]))        # ✅ "1-2-3"（map 后面会学）

# ② split 不传参数时，按任意空白切分
"a  b   c".split()                   # ["a", "b", "c"]
```

## 6. Agent 场景小例子

```python
user_input = "  帮我总结一下这段文字  "

clean_input = user_input.strip()

prompt = f"""请完成以下任务：
{clean_input}

要求：
1. 不超过 100 字
2. 使用中文回答"""

print(prompt)
```

> 这段代码就是以后 Agent 拼接 Prompt 的雏形：**strip 清洗输入 → f-string 套模板**。
