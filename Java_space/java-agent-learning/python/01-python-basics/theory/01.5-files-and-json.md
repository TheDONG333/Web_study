## 1. 白话理解：with 是"自动关门的管家"

打开文件后一定要关闭，否则可能丢数据、占资源。手动关闭的写法：

```python
f = open("notes.txt", "r", encoding="utf-8")
content = f.read()
f.close()          # 万一中途抛异常，这行就执行不到
```

`with` 帮你**无论是否异常都自动关闭**：

```python
with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()
# 出了 with 缩进块，文件已经自动关闭
```

> **规范**：读写文件**一律用 with**，不要手动 `open` + `close`。这和 Java 的 try-with-resources 是同一个思路。

---

## 2. 读文件

### 2.1 一次读全部

```python
with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
```

### 2.2 按行读成列表

```python
with open("notes.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()

print(lines)          # ['第一行\n', '第二行\n']
```

### 2.3 逐行遍历（大文件推荐）

```python
with open("notes.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())     # 每行末尾有换行符，strip 掉
```

| 方法 | 返回 | 适合 |
|------|------|------|
| `read()` | 整个文件字符串 | 小文件 |
| `readlines()` | 每行组成的列表 | 小文件、要按行处理 |
| `for line in f` | 每次一行 | 大文件（省内存） |

> **编码必须写 `encoding="utf-8"`**：Windows 默认编码可能是 GBK，不写容易中文乱码。

---

## 3. 写文件

### 3.1 覆盖写（w）

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")
```

> `"w"` 会**清空原文件**再写。文件不存在会自动创建。

### 3.2 追加写（a）

```python
with open("notes.txt", "a", encoding="utf-8") as f:
    f.write("第三行\n")
```

| 模式 | 含义 | 文件不存在 |
|------|------|-----------|
| `"r"` | 只读 | 抛 `FileNotFoundError` |
| `"w"` | 覆盖写 | 创建 |
| `"a"` | 追加写 | 创建 |

> **Agent 场景**：运行日志用追加模式（`"a"`），配置文件初始化用覆盖模式（`"w"`）。

## 4. JSON：大模型世界的通用语言

### 4.1 为什么必须会 JSON

- 调用大模型 API：请求体是 JSON，响应也是 JSON
- Agent 配置：模型名、温度、最大 token 数，通常存 JSON
- 对话历史：消息列表，通常存 JSON
- 工具调用参数：JSON

> **一句话**：Python 对象 ↔ JSON 字符串的互转，是 Agent 开发的高频动作。

### 4.2 dumps：Python 对象 → JSON 字符串

```python
import json

user = {"name": "张三", "age": 18, "vip": True}

text = json.dumps(user)
print(text)      # {"name": "张三", "age": 18, "vip": true}
```

默认会把中文转成 `\uXXXX`，人看不懂。加 `ensure_ascii=False`：

```python
text = json.dumps(user, ensure_ascii=False)
print(text)      # {"name": "张三", "age": 18, "vip": true}
```

加 `indent=2` 格式化换行（写配置文件时好看）：

```python
print(json.dumps(user, ensure_ascii=False, indent=2))
```

```json
{
  "name": "张三",
  "age": 18,
  "vip": true
}
```

### 4.3 loads：JSON 字符串 → Python 对象

```python
import json

text = '{"name": "张三", "age": 18}'
user = json.loads(text)

print(user["name"])     # 张三
print(type(user))       # <class 'dict'>
```

> `loads` 里的 **s** 可以记成 **string**：字符串 → 对象。`dumps` 的 **s** 是 **string**：对象 → 字符串。

### 4.4 文件和 JSON 结合：dump / load

```python
# 写：对象直接存进文件
with open("config.json", "w", encoding="utf-8") as f:
    json.dump(user, f, ensure_ascii=False, indent=2)

# 读：从文件直接还原成对象
with open("config.json", "r", encoding="utf-8") as f:
    data = json.load(f)

print(data["name"])
```

| 函数 | 方向 | 操作对象 |
|------|------|---------|
| `json.dumps(obj)` | Python → JSON | 字符串 |
| `json.loads(str)` | JSON → Python | 字符串 |
| `json.dump(obj, f)` | Python → JSON | 文件 |
| `json.load(f)` | JSON → Python | 文件 |

### 4.5 类型对应关系

| Python | JSON |
|--------|------|
| `dict` | object `{}` |
| `list` | array `[]` |
| `str` | string |
| `int` / `float` | number |
| `True` / `False` | `true` / `false` |
| `None` | `null` |

> JSON 的键**必须是字符串**。Python 字典的 int 键在 dumps 时会自动转成字符串。

### 4.6 解析失败怎么办

```python
import json

text = "{不是合法 JSON}"

try:
    data = json.loads(text)
except json.JSONDecodeError as e:
    print("JSON 解析失败:", e)
```

> 大模型偶尔会返回带多余文字、缺引号的"伪 JSON"，这个异常必须捕获。`JSONDecodeError` 是 `ValueError` 的子类。

## 5. Agent 场景：配置 + 对话历史

### 5.1 配置文件

```python
import json

config = {
    "model": "gpt-4o-mini",
    "temperature": 0.7,
    "max_tokens": 1024,
    "system_prompt": "你是一个简洁的中文助手"
}

with open("agent_config.json", "w", encoding="utf-8") as f:
    json.dump(config, f, ensure_ascii=False, indent=2)
```

### 5.2 对话历史

```python
import json

history = [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好，有什么可以帮你？"}
]

history.append({"role": "user", "content": "介绍一下 Python"})

with open("chat_history.json", "w", encoding="utf-8") as f:
    json.dump(history, f, ensure_ascii=False, indent=2)

with open("chat_history.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)

for msg in loaded:
    print(f"{msg['role']}: {msg['content']}")
```

> 这段就是后续 Agent 保存/恢复对话的雏形。

## 6. 了解即可（不深挖）

| 内容 | 一句话说明 |
|------|-----------|
| `input()` | `name = input("请输入：")`，返回字符串；Agent 基本不用控制台交互 |
| `%` 格式化 | `"你好 %s" % name`，老写法，f-string 可替代 |
| `format()` | `"你好 {}".format(name)`，同样被 f-string 取代 |
| 二进制文件 | `open(path, "rb")` / `"wb"`，读写图片、音频时才用 |
| 编码进阶 | GBK / UTF-8 / BOM 等细节，遇到乱码再查 |
| 正则表达式 | `re` 模块，复杂文本提取时再学 |

> 这些内容**现在不用花时间**，知道有这回事即可。

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ with open | 自动关闭文件，异常也安全 |
| ✅ 读 | read / readlines / 逐行遍历 |
| ✅ 写 | `"w"` 覆盖，`"a"` 追加 |
| ✅ 编码 | 始终写 `encoding="utf-8"` |
| ✅ dumps / loads | 对象 ↔ JSON 字符串 |
| ✅ dump / load | 对象 ↔ JSON 文件 |
| ✅ 中文可读 | `ensure_ascii=False` |
| ✅ 解析失败 | 捕获 `json.JSONDecodeError` |
| ✅ Agent 用途 | 配置文件、对话历史、API 数据 |
