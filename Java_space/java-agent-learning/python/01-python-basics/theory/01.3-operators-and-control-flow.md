## 1. 运算符

### 1.1 算术运算符

```python
print(7 + 3)      # 10
print(7 - 3)      # 4
print(7 * 3)      # 21
print(7 / 3)      # 2.3333...  ← 除法结果一定是 float
print(7 // 3)     # 2           ← 整除（向下取整）
print(7 % 3)      # 1           ← 取余
print(2 ** 10)    # 1024        ← 幂运算（Java 没有这个运算符）
```

| 运算符 | 含义 | 注意 |
|--------|------|------|
| `/` | 除法 | **结果总是 float**，不是整除 |
| `//` | 整除 | 向下取整 |
| `%` | 取余 | 常用判断奇偶 |
| `**` | 幂 | `2 ** 3` = 8 |

### 1.2 比较运算符

```python
print(3 == 3)       # True
print(3 != 4)       # True
print(3 > 2)        # True

# Python 支持链式比较（Java 不行）
age = 20
print(18 <= age < 60)   # True
```

### 1.3 逻辑运算符

Python 用 `and` / `or` / `not`，不是 Java 的 `&&` / `||` / `!`。

```python
age = 20
is_student = True

print(age >= 18 and is_student)   # True
print(age < 18 or is_student)     # True
print(not is_student)             # False
```

> **小坑**：`and` / `or` 返回的不一定是 `True`/`False`，而是**参与运算的值**：
>
> ```python
> print("" or "默认值")     # 默认值
> print("tom" and "jerry")  # jerry
> ```
>
> 放在 `if` 里按真假判断就行，不用深究。

### 1.4 成员运算符：in / not in

```python
print("a" in "cat")              # True
print("x" not in "cat")          # True
print(2 in [1, 2, 3])            # True
print("name" in {"name": "tom"}) # True ← 字典判断的是 key
```

| 用途 | 示例 |
|------|------|
| 子串判断 | `"error" in log_line` |
| 列表包含 | `user_id in allowed_ids` |
| 字典键存在 | `"role" in message` |

### 1.5 身份运算符：is / is not

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)     # True  ← 值相等
print(a is b)     # False ← 不是同一个对象
print(a is c)     # True  ← 指向同一个对象
```

| 运算符 | 比较什么 | 什么时候用 |
|--------|---------|-----------|
| `==` | **值**是否相等 | 绝大多数比较 |
| `is` | 是否是**同一个对象** | 判断 `None`、`True`、`False` |

```python
result = None
if result is None:       # ✅ 规范
    print("无结果")

if result == None:       # ⚠️ 能跑但不规范
    print("无结果")
```

> **规范**：值比较用 `==`，判断 None 用 `is None`。

## 2. 分支结构

### 2.1 if / elif / else

Python 用**缩进**表示代码块，没有大括号，条件后面有冒号：

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

| Java | Python |
|------|--------|
| `else if` | `elif` |
| `{ }` 包代码块 | **缩进**（通常 4 个空格） |
| 条件必须 boolean | 任何值都能按真假判断 |

> **缩进就是语法**：同一代码块必须缩进一致，混用 Tab 和空格会报 `IndentationError`。

### 2.2 三元表达式

```python
age = 20
label = "成年" if age >= 18 else "未成年"
print(label)      # 成年
```

语法：`值1 if 条件 else 值2`（条件为真取值1，否则取值2）。

## 3. 先认识列表和字典（遍历的基础）

### 3.1 列表 list：有序、可变

```python
fruits = ["苹果", "香蕉", "橙子"]

print(fruits[0])        # 苹果
print(fruits[-1])       # 橙子
print(len(fruits))      # 3

fruits.append("葡萄")    # 末尾添加
print(fruits)           # ['苹果', '香蕉', '橙子', '葡萄']

fruits[0] = "西瓜"       # 修改
```

### 3.2 字典 dict：键值对

```python
user = {
    "name": "tom",
    "age": 18,
    "role": "admin"
}

print(user["name"])          # tom
print(user.get("email"))     # None（key 不存在不报错）
print(user.get("email", "无"))  # 无（给默认值）

user["age"] = 19             # 修改
user["email"] = "tom@demo.com"  # 新增
```

| 操作 | 写法 |
|------|------|
| 取值 | `d[key]`（不存在抛 KeyError） |
| 安全取值 | `d.get(key, 默认值)` |
| 新增/修改 | `d[key] = value` |
| 所有键 | `d.keys()` |
| 所有值 | `d.values()` |
| 所有键值对 | `d.items()` |

### 3.3 对话历史：列表套字典（Agent 的核心数据结构）

```python
history = [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好，有什么可以帮你？"}
]

print(history[0]["content"])     # 你好
```

> 大模型的对话消息基本就是这个结构，后面会天天见。

## 4. 循环结构

### 4.1 for：遍历（最高频）

```python
# 遍历列表
for fruit in ["苹果", "香蕉", "橙子"]:
    print(fruit)

# 遍历字符串
for ch in "abc":
    print(ch)

# 遍历字典的键
user = {"name": "tom", "age": 18}
for key in user:
    print(key, user[key])

# 遍历字典的键值对（最常用）
for key, value in user.items():
    print(key, "=", value)
```

### 4.2 range：按次数循环

```python
for i in range(5):          # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):       # 1, 2, 3, 4, 5（左闭右开）
    print(i)

for i in range(0, 10, 2):   # 0, 2, 4, 6, 8（步长 2）
    print(i)
```

> 相当于 Java 的 `for (int i = 0; i < 5; i++)`，但**结束值不包含**。

### 4.3 while

```python
count = 0
while count < 3:
    print("第", count + 1, "次")
    count += 1
```

> Python 没有 `count++`，用 `count += 1`。

### 4.4 break / continue

```python
for i in range(10):
    if i == 3:
        continue        # 跳过本次，继续下一次
    if i == 6:
        break           # 直接结束整个循环
    print(i)
```

输出：`0 1 2 4 5`

| 关键字 | 作用 |
|--------|------|
| `break` | 立刻退出整个循环 |
| `continue` | 跳过本次剩余代码，进入下一次 |

### 4.5 遍历对话历史（综合例子）

```python
history = [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好，有什么可以帮你？"},
    {"role": "user", "content": "介绍一下 Python"}
]

for i, msg in enumerate(history, start=1):
    print(f"{i}. [{msg['role']}] {msg['content']}")
```

> `enumerate` 能在遍历时同时拿到下标，写日志、做编号很方便（了解即可）。

## 5. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ `/` 结果是小数 | 整除用 `//` |
| ✅ 逻辑运算符 | `and` / `or` / `not` |
| ✅ `==` 比值，`is` 比对象 | 判断 None 用 `is None` |
| ✅ 缩进就是语法 | 没有大括号，冒号 + 4 空格 |
| ✅ 三元表达式 | `a if 条件 else b` |
| ✅ for 遍历 | 列表直接遍历，字典用 `.items()` |
| ✅ range 左闭右开 | `range(1, 6)` 是 1~5 |
| ✅ break / continue | 退出整个循环 / 跳过本次 |
