## 1. `__str__` / `__repr__`：调试必备

### 白话理解

默认打印对象是这样的：

```python
class Agent:
    def __init__(self, name):
        self.name = name

agent = Agent("小助手")
print(agent)        # <__main__.Agent object at 0x000001...>
```

这串地址几乎没用。`__str__` 和 `__repr__` 就是让对象**打印出来有意义**。

### 1.1 `__str__`：给人看

```python
class Agent:
    def __init__(self, name, model="gpt-4o-mini"):
        self.name = name
        self.model = model

    def __str__(self):
        return f"Agent({self.name})"

agent = Agent("小助手")
print(agent)        # Agent(小助手)
print(str(agent))   # Agent(小助手)
```

### 1.2 `__repr__`：给开发者调试看

```python
    def __repr__(self):
        return f"Agent(name={self.name!r}, model={self.model!r})"
```

```python
print(repr(agent))          # Agent(name='小助手', model='gpt-4o-mini')
print([agent])              # [Agent(name='小助手', model='gpt-4o-mini')]
```

> **为什么列表里用的是 __repr__**：容器打印元素时用 `repr()`，所以 `__repr__` 更适合展示完整字段，方便调试。

### 1.3 两者的区别

| | `__str__` | `__repr__` |
|---|-----------|-----------|
| 面向 | 用户/日志 | 开发者/调试 |
| 触发 | `print(obj)`、`str(obj)` | `repr(obj)`、列表/字典打印 |
| 内容 | 简洁可读 | 尽量完整、无歧义 |
| 缺省 | 没定义时回退到 `__repr__` | 没定义时显示内存地址 |

> **建议**：至少写一个 `__repr__`，把关键字段都带上，调试时能少打很多 print。

## 2. `__call__`：让对象像函数一样调用

### 白话理解

正常调用对象的方法要写 `agent.chat("你好")`。  
实现 `__call__` 后，可以写成 `agent("你好")`——**对象本身变成了可调用的**。

```python
class Agent:
    def __init__(self, name):
        self.name = name

    def chat(self, message):
        return f"{self.name} 收到：{message}"

    def __call__(self, message):
        return self.chat(message)

agent = Agent("小助手")
print(agent("你好"))        # 小助手 收到：你好
```

### 为什么 Agent 类常用这种写法

```python
# 编排多个 Agent 时，统一用调用语法
for agent in agents:
    result = agent("你好")
```

- 调用形式统一，代码简洁
- 框架（如 LangChain 的部分组件）也常用 `__call__` 或类似的调用协议
- 内部仍然可以走 `chat()`，对外只暴露一个"入口"

> **注意**：`__call__` 只是语法糖，真正的逻辑还是写在 `chat()` 或 `respond()` 里。

## 3. @classmethod：类方法

### 3.1 基本写法

```python
class Agent:
    def __init__(self, name, model="gpt-4o-mini"):
        self.name = name
        self.model = model

    @classmethod
    def from_config(cls, config):
        return cls(config["name"], config.get("model", "gpt-4o-mini"))
```

使用：

```python
agent = Agent.from_config({"name": "小助手", "model": "gpt-4o"})
print(agent.name, agent.model)     # 小助手 gpt-4o
```

- 第一个参数是 `cls`（代表类本身），不是 `self`
- 可以通过 `cls(...)` 创建对象
- 常见用途：**替代构造方法 / 工厂方法**（从配置、从 JSON、从数据库创建对象）

### 3.2 类方法能访问类属性

```python
class Agent:
    default_model = "gpt-4o-mini"

    @classmethod
    def show_default(cls):
        print("默认模型:", cls.default_model)
```

## 4. @staticmethod：静态方法

### 4.1 基本写法

```python
class Agent:
    @staticmethod
    def is_valid_role(role):
        return role in {"system", "user", "assistant"}
```

使用：

```python
print(Agent.is_valid_role("user"))     # True
print(Agent.is_valid_role("boss"))     # False
```

- 没有 `self`，也没有 `cls`
- 就是"放在类里的小工具函数"
- 不需要访问实例或类的状态时使用

### 4.2 为什么放类里

- 逻辑上属于这个类（比如"角色校验"属于 Agent 的规则）
- 用 `Agent.is_valid_role(...)` 调用，命名空间清晰
- 不需要创建对象就能用

## 5. 三种方法对比

| | 实例方法 | 类方法 `@classmethod` | 静态方法 `@staticmethod` |
|---|---------|----------------------|--------------------------|
| 第一个参数 | `self` | `cls` | 无 |
| 能访问实例属性 | ✅ | ❌ | ❌ |
| 能访问类属性 | ✅（通过 self/类） | ✅ | ❌（只能通过类名） |
| 调用方式 | `obj.method()` | `Cls.method()` / `obj.method()` | `Cls.method()` |
| 典型用途 | 业务逻辑 | 工厂方法、读取类配置 | 工具函数、校验 |

```python
class Agent:
    def chat(self, msg): ...          # 实例方法：需要对象状态
    @classmethod
    def from_config(cls, cfg): ...    # 类方法：创建对象
    @staticmethod
    def is_valid_role(role): ...      # 静态方法：纯工具
```

## 6. 完整示例：一个"好用"的 Agent 类

```python
class Agent:
    VALID_ROLES = {"system", "user", "assistant"}

    def __init__(self, name, model="gpt-4o-mini"):
        self.name = name
        self.model = model
        self.history = []

    def __str__(self):
        return f"Agent({self.name})"

    def __repr__(self):
        return f"Agent(name={self.name!r}, model={self.model!r})"

    def __call__(self, message):
        return self.chat(message)

    def chat(self, message):
        self.history.append({"role": "user", "content": message})
        reply = f"[{self.model}] 收到：{message}"
        self.history.append({"role": "assistant", "content": reply})
        return reply

    @classmethod
    def from_config(cls, config):
        return cls(config["name"], config.get("model", "gpt-4o-mini"))

    @staticmethod
    def is_valid_role(role):
        return role in Agent.VALID_ROLES
```

使用：

```python
agent = Agent.from_config({"name": "小助手", "model": "gpt-4o"})
print(agent)                 # Agent(小助手)
print(agent("你好"))          # [gpt-4o] 收到：你好
print(agent.history)
print(Agent.is_valid_role("user"))   # True
```

## 7. 了解即可（不深挖）

| 内容 | 一句话说明 |
|------|-----------|
| 其他魔术方法 | `__len__`、`__getitem__`、`__eq__`、`__iter__` 等，让对象支持 len、下标、比较、遍历 |
| 元类 metaclass | 创建类的类，框架底层偶尔用，业务代码几乎不写 |
| 反射 | `getattr` / `setattr` / `hasattr`，运行时操作属性 |
| 设计模式 | 单例、工厂、策略等，写多了自然会接触，不要求现在背 |

> 本阶段只需要掌握 `__str__`、`__repr__`、`__call__` 和两种类方法，其他遇到再查。

## 8. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ `__str__` | 给人看，print 触发 |
| ✅ `__repr__` | 给开发者看，列表打印触发 |
| ✅ `__call__` | 让对象可以 `agent("你好")` |
| ✅ @classmethod | 第一个参数 cls，工厂方法常用 |
| ✅ @staticmethod | 无 self/cls，类里的工具函数 |
| ✅ 方法选择 | 需要对象状态用实例方法，需要创建对象用类方法，纯工具用静态方法 |
