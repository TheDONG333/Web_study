# 04.3 继承与多态：基类 Agent 与不同业务 Agent

> **学习目标**
> - 会写单继承，会用 super() 调用父类
> - 会重写父类方法
> - 理解多态：同一调用，不同表现
> - 了解鸭子类型（概念即可）
> - 能设计"基类 Agent + 子类 Agent"的结构

---

## 1. 白话理解：继承是"通用模板 + 个性化定制"

所有 Agent 都有共同点：

- 有名字、模型、对话历史
- 能接收用户输入
- 能记录对话

但它们"怎么回答"不一样：

- 对话 Agent：普通聊天
- 工具调用 Agent：先决定调哪个工具
- 数据分析 Agent：先分析数据

继承的做法：**把共同点写在基类，把差异留给子类**。

```
BaseAgent（基类）
├── ChatAgent（对话）
├── ToolAgent（工具调用）
└── DataAgent（数据分析）
```

---

## 2. 单继承：子类继承父类

```python
class BaseAgent:
    def __init__(self, name):
        self.name = name
        self.history = []

    def add_message(self, role, content):
        self.history.append({"role": role, "content": content})

    def respond(self, user_input):
        raise NotImplementedError("子类必须实现 respond")

    def chat(self, user_input):
        self.add_message("user", user_input)
        reply = self.respond(user_input)
        self.add_message("assistant", reply)
        return reply
```

子类：

```python
class ChatAgent(BaseAgent):
    def respond(self, user_input):
        return f"[对话] 收到：{user_input}"
```

使用：

```python
agent = ChatAgent("小助手")
print(agent.chat("你好"))
# [对话] 收到：你好
print(agent.history)
```

- `class ChatAgent(BaseAgent)`：继承 BaseAgent
- 自动拥有父类的 `__init__`、`add_message`、`chat`
- 只需要实现有差异的 `respond`

> **Java 对照**：`extends` → 括号里写父类；方法重写不需要 @Override（但建议保持方法名一致）。

## 3. super()：调用父类的方法

### 3.1 子类要加自己的属性时

```python
class ToolAgent(BaseAgent):
    def __init__(self, name, tools):
        super().__init__(name)     # 先让父类初始化 name/history
        self.tools = tools         # 再加子类自己的属性

    def respond(self, user_input):
        return f"[工具] 可用工具 {self.tools}，收到：{user_input}"
```

> **必须调用 `super().__init__(...)`**，否则父类的 `name`、`history` 不会初始化，后面调用会报错。

### 3.2 super() 的两种常见用法

```python
super().__init__(name)                 # 调用父类的构造方法
super().chat(user_input)               # 调用父类的其他方法
```

| 场景 | 写法 |
|------|------|
| 子类新增属性 | `super().__init__(...)` |
| 在父类逻辑上扩展 | `result = super().chat(...)` 再加工 |
| 完全重写 | 直接定义同名方法，不调 super |

## 4. 方法重写（Override）

子类定义和父类**同名的方法**，就会覆盖父类的版本：

```python
class BaseAgent:
    def respond(self, user_input):
        return "默认回答"

class ChatAgent(BaseAgent):
    def respond(self, user_input):
        return f"[对话] {user_input}"

class ToolAgent(BaseAgent):
    def respond(self, user_input):
        return f"[工具] {user_input}"
```

调用 `chat()` 时，父类的 `chat` 里调用 `self.respond(...)`，实际执行的是**子类重写后的版本**。

> 这就是多态的关键：**父类定义流程，子类决定细节**。

---

## 5. 多态：同一调用，不同表现

```python
agents = [
    ChatAgent("小助手"),
    ToolAgent("工具助手", ["search", "calculator"])
]

for agent in agents:
    print(agent.chat("你好"))
```

输出：

```
[对话] 收到：你好
[工具] 可用工具 ['search', 'calculator']，收到：你好
```

- 调用的都是 `agent.chat("你好")`
- 具体行为由对象的实际类型决定
- 新增一种 Agent，只需要再写一个子类，**循环代码不用改**

> **Agent 场景**：编排多个 Agent 时，统一调用 `agent(...)` 或 `agent.chat(...)`，不需要为每个子类写 if-else。

## 6. 鸭子类型（Duck Typing）

### 白话理解

"如果它走起来像鸭子、叫起来像鸭子，那它就是鸭子。"

Python **不要求必须继承某个基类**，只要对象有需要的方法，就能用：

```python
class WeatherAgent:
    def chat(self, user_input):
        return f"[天气] 查询 {user_input}"

def run_agent(agent, text):
    return agent.chat(text)

print(run_agent(ChatAgent("小助手"), "你好"))
print(run_agent(WeatherAgent(), "北京天气"))
```

- `WeatherAgent` 没有继承 `BaseAgent`
- 但它有 `chat` 方法，`run_agent` 照样能用

> **和 Java 的区别**：Java 需要接口/继承来保证"有这个方法"；Python 只看**运行时有没有这个方法**。灵活，但调用前要确认方法存在。

### typeof / isinstance（复习）

```python
print(isinstance(ChatAgent("x"), BaseAgent))   # True
print(isinstance(ChatAgent("x"), ChatAgent))   # True
print(isinstance("abc", str))                  # True
```

## 7. 了解：多继承与 MRO

Python 允许一个类继承多个父类：

```python
class A:
    def hello(self):
        print("A")

class B:
    def hello(self):
        print("B")

class C(A, B):
    pass

C().hello()      # A（按 MRO 顺序找）
print(C.__mro__) # (<class 'C'>, <class 'A'>, <class 'B'>, <class 'object'>)
```

- **MRO**（Method Resolution Order）：方法查找顺序
- 规则大致是"从左到右、深度优先，但共享父类只取一次"
- **本阶段了解即可**，实际项目优先用单继承 + 组合，避免多继承带来的复杂性

## 8. 一个完整的继承体系

```python
class BaseAgent:
    def __init__(self, name, model="gpt-4o-mini"):
        self.name = name
        self.model = model
        self.history = []

    def respond(self, user_input):
        raise NotImplementedError("子类必须实现 respond")

    def chat(self, user_input):
        self.history.append({"role": "user", "content": user_input})
        reply = self.respond(user_input)
        self.history.append({"role": "assistant", "content": reply})
        return reply

class ChatAgent(BaseAgent):
    def respond(self, user_input):
        return f"[对话] {user_input}"

class ToolAgent(BaseAgent):
    def __init__(self, name, tools):
        super().__init__(name)
        self.tools = tools

    def respond(self, user_input):
        return f"[工具] 可用：{self.tools}；输入：{user_input}"
```

> 下一节会给基类加 `__str__`、`__call__`，让它更好用。

## 9. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 继承 | `class 子类(父类)`，复用父类代码 |
| ✅ super() | 调用父类构造方法或其他方法 |
| ✅ 重写 | 子类定义同名方法覆盖父类 |
| ✅ 多态 | 同一调用，不同子类有不同表现 |
| ✅ 鸭子类型 | 不要求继承，有方法就能用 |
| ✅ NotImplementedError | 基类声明"子类必须实现" |
| ✅ 多继承/MRO | 了解即可，优先单继承 |
