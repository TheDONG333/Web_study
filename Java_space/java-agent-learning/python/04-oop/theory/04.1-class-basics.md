# 04.1 类与对象基础：class、__init__、self

> **学习目标**
> - 会定义类、创建对象
> - 理解 `__init__` 和 self
> - 掌握实例属性、实例方法
> - 分清实例属性和类属性

---

## 1. 白话理解：类是图纸，对象是房子

- **类（class）**：图纸，描述"这类东西有什么属性、能做什么"
- **对象（对象/实例）**：按图纸造出来的具体东西

```python
class Agent:
    """一个最简 Agent 类。"""

    def __init__(self, name):
        self.name = name

    def chat(self, message):
        return f"{self.name} 收到：{message}"
```

用类创建对象：

```python
agent = Agent("小助手")
print(agent.name)              # 小助手
print(agent.chat("你好"))       # 小助手 收到：你好
```

> **Java 对照**：`class`、`new` 的思路类似，但 Python 不需要写类型，创建对象也不用 `new`，直接 `Agent(...)`。

---

## 2. `__init__`：对象创建时自动执行

```python
class Agent:
    def __init__(self, name, model="gpt-4o-mini"):
        print("创建对象时自动执行")
        self.name = name
        self.model = model
        self.history = []          # 每个对象自己的对话历史

agent = Agent("小助手")
# 输出：创建对象时自动执行
```

| 要点 | 说明 |
|------|------|
| 方法名固定 | `__init__`（前后各两个下划线） |
| 自动调用 | `Agent("小助手")` 时自动执行 |
| 作用 | 初始化对象的属性 |
| 返回值 | **不能 return 值**（返回 None） |

> 叫它"构造方法"也行，但严格说对象已经创建好了，`__init__` 负责**初始化**。

## 3. self：代表"当前对象"

```python
class Agent:
    def __init__(self, name):
        self.name = name

    def say_hi(self):
        print(f"我是 {self.name}")

a1 = Agent("小助手")
a2 = Agent("分析师")

a1.say_hi()      # 我是 小助手
a2.say_hi()      # 我是 分析师
```

调用 `a1.say_hi()` 时，Python 自动把 `a1` 传给 `self`，等价于：

```python
Agent.say_hi(a1)
```

| 要点 | 说明 |
|------|------|
| self 不是关键字 | 只是约定俗成的名字，但**必须写** |
| 必须是第一个参数 | 实例方法的第一个参数 |
| 谁调用就指向谁 | `a1` 调用，self 就是 `a1` |
| 访问属性/方法 | `self.name`、`self.chat(...)` |

> **初学常见错误**：方法里忘了写 self，或者调用时手动传 self。

## 4. 实例属性 vs 类属性

### 4.1 实例属性：每个对象各一份

```python
class Agent:
    def __init__(self, name):
        self.name = name
        self.history = []

a1 = Agent("小助手")
a2 = Agent("分析师")

a1.history.append("你好")
print(a1.history)      # ['你好']
print(a2.history)      # []  ← 互不影响
```

> 在 `__init__` 里用 `self.xxx = ...` 创建的是实例属性。

### 4.2 类属性：所有对象共享

```python
class Agent:
    category = "AI Agent"      # 类属性

    def __init__(self, name):
        self.name = name

a1 = Agent("小助手")
a2 = Agent("分析师")

print(a1.category)      # AI Agent
print(a2.category)      # AI Agent
```

### 4.3 坑：可变的类属性会被共享

```python
class Agent:
    history = []           # ❌ 类属性，所有对象共用

    def __init__(self, name):
        self.name = name

a1 = Agent("小助手")
a2 = Agent("分析师")

a1.history.append("你好")
print(a2.history)          # ['你好'] ← a2 也看到了！
```

> **规范**：每个对象独立的数据（如 history）一定放 `__init__` 里用 `self.xxx` 创建；类属性只放常量或共享配置。

## 5. 实例方法

```python
class Agent:
    def __init__(self, name):
        self.name = name
        self.history = []

    def add_message(self, role, content):
        self.history.append({"role": role, "content": content})

    def chat(self, user_input):
        self.add_message("user", user_input)
        return f"{self.name} 收到：{user_input}"
```

- 定义在类里、第一个参数是 self 的函数
- 可以访问 `self.xxx`，也可以调用其他实例方法 `self.add_message(...)`

---

## 6. 对象的基本使用

```python
agent = Agent("小助手")

# 访问属性
print(agent.name)

# 修改属性
agent.name = "新名字"

# 调用方法
print(agent.chat("你好"))

# 查看对象类型
print(type(agent))          # <class '__main__.Agent'>
print(isinstance(agent, Agent))   # True
```

> Python 允许运行时给对象加新属性（如 `agent.age = 1`），但不推荐——所有属性最好在 `__init__` 里定义清楚。

## 7. 一个完整的 Agent 雏形

```python
class Agent:
    def __init__(self, name, model="gpt-4o-mini"):
        self.name = name
        self.model = model
        self.history = []

    def add_message(self, role, content):
        self.history.append({"role": role, "content": content})

    def chat(self, user_input):
        self.add_message("user", user_input)
        reply = f"[{self.model}] 收到：{user_input}"
        self.add_message("assistant", reply)
        return reply

agent = Agent("小助手")
print(agent.chat("你好"))
print(agent.history)
```

> 这个类已经有 Agent 的雏形：名字、模型、对话历史、聊天方法。下一节用封装把内部状态保护起来。

---

## 8. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 类 vs 对象 | 图纸 vs 按图纸造出来的实例 |
| ✅ `__init__` | 创建对象时自动执行，初始化属性 |
| ✅ self | 当前对象，必须是实例方法的第一个参数 |
| ✅ 实例属性 | `self.xxx`，每个对象独立 |
| ✅ 类属性 | 类里直接定义，所有对象共享 |
| ✅ 可变类属性有坑 | history 这类数据放 `__init__` |
| ✅ 实例化 | `Agent("名字")`，不需要 new |
