# 05.4 Spring 整合 MyBatis

> **学习目标**
> - 理解整合的核心：把 MyBatis 的 SqlSessionFactory 和 Mapper 交给 Spring 管
> - 掌握 SqlSessionFactoryBean 和 MapperScannerConfigurer 的配置
> - 能通过容器直接获取 Mapper 接口使用

---

## 1. 为什么要整合？

### 白话理解

第四章里，你要手动写 `MyBatisUtil` 拿 SqlSession，再 `session.selectOne("userMapper.findById", 1)` 传字符串调用。

**整合后**：SqlSessionFactory 由 Spring 创建和管理，Mapper 自动注册成 Bean，你直接注入接口就能用——**不用再碰 SqlSession，也不用拼字符串**：

```java
// 第四章的写法（手动）
SqlSession session = MyBatisUtil.openSession();
User user = session.selectOne("userMapper.findById", 1);
session.close();

// 整合 Spring 后（声明式）
@Autowired
private UserMapper userMapper;     // 直接注入 Mapper 接口

User user = userMapper.findById(1); // 直接调方法
```

> **一句话**：Spring 把 MyBatis 的 SqlSessionFactory 和 Mapper 都接管了，你只管写接口和 XML，然后注入使用。

---

## 2. Mapper 接口登场

### 白话理解

第四章用字符串定位 SQL（`"userMapper.findById"`），容易写错且编译期查不出来。整合后改用**接口 + 方法名**定位：

```java
public interface UserMapper {
    User findById(int id);
    List<User> findAll();
    int insert(User user);
}
```

**对应关系**：XML 的 `namespace` 写接口全类名，`id` 写方法名：

```xml
<!-- namespace 必须是接口的全类名 -->
<mapper namespace="com.demo.mapper.UserMapper">

    <!-- id 必须和接口方法名一致 -->
    <select id="findById" parameterType="int" resultType="com.demo.entity.User">
        SELECT * FROM users WHERE id = #{id}
    </select>

</mapper>
```

接口和 XML 配对后，调用 `userMapper.findById(1)` 就等于执行了那条 SQL。

## 3. 整合配置（applicationContext.xml 核心部分）

### 白话理解

三件事：① 数据源（连数据库）② SqlSessionFactoryBean（创建会话工厂，交给 Spring）③ MapperScannerConfigurer（扫描 Mapper 接口注册成 Bean）。

```xml
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
           http://www.springframework.org/schema/beans/spring-beans.xsd
           http://www.springframework.org/schema/context
           http://www.springframework.org/schema/context/spring-context.xsd">

    <!-- ① 组件扫描：把 @Service/@Repository 等注册进容器 -->
    <context:component-scan base-package="com.demo"/>

    <!-- ② 数据源：告诉 Spring 怎么连数据库 -->
    <bean id="dataSource" class="org.springframework.jdbc.datasource.DriverManagerDataSource">
        <property name="driverClassName" value="com.mysql.cj.jdbc.Driver"/>
        <property name="url" value="jdbc:mysql://localhost:3306/agent_learn?useSSL=false&amp;serverTimezone=Asia/Shanghai"/>
        <property name="username" value="root"/>
        <property name="password" value="123456"/>
    </bean>

    <!-- ③ SqlSessionFactoryBean：把 MyBatis 的工厂交给 Spring 管理 -->
    <bean id="sqlSessionFactory" class="org.mybatis.spring.SqlSessionFactoryBean">
        <property name="dataSource" ref="dataSource"/>
        <!-- Mapper XML 文件位置 -->
        <property name="mapperLocations" value="classpath:mapper/*.xml"/>
    </bean>

    <!-- ④ MapperScannerConfigurer：扫描 Mapper 接口，自动注册为 Bean -->
    <bean class="org.mybatis.spring.mapper.MapperScannerConfigurer">
        <!-- 扫描哪个包下的 Mapper 接口 -->
        <property name="basePackage" value="com.demo.mapper"/>
    </bean>

</beans>
```

### 每个配置的作用

| 配置 | 白话理解 |
|------|---------|
| `<context:component-scan>` | 扫描 @Service、@Repository 等注解类 |
| `dataSource` | 数据库连接信息 |
| `SqlSessionFactoryBean` | 替代第四章的 MyBatisUtil，由 Spring 创建会话工厂 |
| `MapperScannerConfigurer` | 扫描 Mapper 接口包，自动把每个接口注册成 Bean（不用一个个手动配） |

## 4. Maven 依赖

```xml
<dependencies>
    <!-- Spring 核心（IOC/DI/AOP） -->
    <dependency>
        <groupId>org.springframework</groupId>
        <artifactId>spring-context</artifactId>
        <version>5.3.31</version>
    </dependency>
    <!-- Spring JDBC（事务） -->
    <dependency>
        <groupId>org.springframework</groupId>
        <artifactId>spring-jdbc</artifactId>
        <version>5.3.31</version>
    </dependency>
    <!-- MyBatis + Spring 整合包（关键） -->
    <dependency>
        <groupId>org.mybatis</groupId>
        <artifactId>mybatis-spring</artifactId>
        <version>2.1.2</version>
    </dependency>
    <!-- MyBatis -->
    <dependency>
        <groupId>org.mybatis</groupId>
        <artifactId>mybatis</artifactId>
        <version>3.5.16</version>
    </dependency>
    <!-- MySQL 驱动 -->
    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-java</artifactId>
        <version>8.0.33</version>
    </dependency>
</dependencies>
```

> 注意：整合后**不再需要 mybatis-config.xml**（数据源、mapper 位置都移到 Spring 配置里了）。

## 5. 使用：从容器获取 Mapper

```java
public class Main {
    public static void main(String[] args) {
        // 启动 Spring 容器
        ClassPathXmlApplicationContext ctx =
            new ClassPathXmlApplicationContext("applicationContext.xml");

        // 从容器获取 Mapper（MapperScannerConfigurer 已注册好）
        UserMapper userMapper = ctx.getBean(UserMapper.class);

        // 直接调用方法（内部自动走 SqlSession）
        User user = userMapper.findById(1);
        System.out.println(user);

        ctx.close();
    }
}
```

**Service 中注入使用（实际开发的主流写法）：**

```java
@Service
public class UserServiceImpl implements UserService {

    @Autowired
    private UserMapper userMapper;   // 容器自动注入 Mapper

    @Override
    @Transactional
    public void register(User user) {
        userMapper.insert(user);     // 直接调用
    }
}
```

## 6. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 整合三件套：数据源 + SqlSessionFactoryBean + MapperScannerConfigurer | 全在 Spring 配置里 |
| ✅ XML 的 namespace 写接口全类名 | id 和接口方法名一致 |
| ✅ Mapper 接口直接 @Autowired 注入 | 告别 SqlSession 和字符串 |
| ✅ 整合后不需要 mybatis-config.xml | 配置都移入 Spring |
| ✅ mybatis-spring 是整合的关键依赖 | 别漏了 |
