# 12.4 分页、结果高亮与两个"了解即可"

> **学习目标**
> - 会用 from / size 做分页，知道页码怎么换算
> - 会用 highlight 给命中关键词加高亮标签
> - 了解 fuzzy 和 wildcard 的用途与性能代价（别乱用）

---

## 1. 分页：from + size

### 白话理解

和 SQL 的 `LIMIT offset, size` 一模一样：

```json
GET /products/_search
{
  "query": { "match_all": {} },
  "from": 0,
  "size": 10
}
```

| 参数 | 含义 | 换算 |
|------|------|------|
| `size` | 每页几条 | 页大小 |
| `from` | 跳过几条 | **(页码 - 1) × size** |

```
第 1 页：from = 0,  size = 10
第 2 页：from = 10, size = 10
第 3 页：from = 20, size = 10
```

> **常见错误**：把 `from` 当成页码写。`from` 是**跳过的条数**，不是第几页。

### 深分页的限制（了解）

ES 默认限制 `from + size ≤ 10000`，超过会报：

```
Result window is too large, from + size must be less than or equal to: [10000]
```

- 普通商品列表翻到前几百页完全够用
- 真要深翻（如导出全量数据），用 `search_after`（了解，用到再查）

## 2. 高亮：把命中的词标出来

### 白话理解

搜索结果里关键词显示为红色/加粗，就是高亮。ES 不返回改过的原文，而是在 `highlight` 字段里**单独返回一段带标签的片段**，前端负责渲染样式。

```json
GET /products/_search
{
  "query": {
    "match": { "title": "iPhone" }
  },
  "highlight": {
    "fields": {
      "title": {}
    },
    "pre_tags": ["<em>"],
    "post_tags": ["</em>"]
  }
}
```

返回结果里每条命中会多一个 `highlight`：

```json
"highlight": {
  "title": ["Apple <em>iPhone</em> 15 Pro 手机"]
}
```

| 参数 | 作用 | 说明 |
|------|------|------|
| `fields` | 高亮哪些字段 | 必须是被查询的字段 |
| `pre_tags` / `post_tags` | 包裹关键词的标签 | 默认就是 `<em>`，前端可换 `<span class="hl">` |

> **注意**：高亮字段必须是**参与查询的 text 字段**。拿没搜过的字段做 highlight，不会有结果。

## 3. 了解即可：fuzzy 与 wildcard

### fuzzy：容错搜索（拼写错了也能搜到）

```json
{ "fuzzy": { "title": "iphnoe" } }
```

- 基于"**编辑距离**"：允许拼错 1~2 个字母（`iphnoe` → `iphone`）
- 适合：英文搜索的纠错、手机号/单号输入容错
- 代价：会枚举大量相似词，**性能一般**，别给每个查询都加上

### wildcard：通配符匹配

```json
{ "wildcard": { "title": "iPho*" } }
```

- `*` 匹配任意字符，`?` 匹配单个字符，类似 SQL 的 LIKE
- ⚠️ **性能很差**，尤其是 `*` 放在开头（`*phone`）——无法利用索引，等同全表扫描
- 能不用就不用；必须用时，把通配符放**末尾**（前缀匹配）

> **记忆**：fuzzy 是"**纠错**"，wildcard 是"** LIKE 的翻版**"。两者都属于"知道有这回事，用到再查"。

## 4. 查询语法全貌（本阶段版）

```
_search
├── query
│   ├── match       全文关键词
│   ├── term        精确值
│   ├── range       范围
│   └── bool
│       ├── must       必须 + 算分
│       ├── filter     必须 + 不算分（快）
│       ├── must_not   排除
│       └── should     可选加分（了解）
├── from / size     分页
└── highlight       高亮
```

> 这张图就是本阶段要掌握的全部。聚合（aggs）、嵌套（nested）、向量搜索等，遇到再学。

---

## 5. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ from 是跳过条数 | `(页码-1) × size`，不是页码 |
| ✅ 深分页上限 10000 | 超了用 search_after（了解） |
| ✅ highlight | 指定字段 + 前后标签，返回带标签片段 |
| ✅ 高亮字段必须被查询 | 且是 text 字段 |
| ✅ fuzzy 纠错 | 编辑距离，性能一般 |
| ✅ wildcard 性能差 | 开头 `*` 等于全表扫描，别乱用 |
