# 13.3 数组与对象：map / filter / forEach 是高频三件套

> **学习目标**
> - 掌握数组 push / pop / map / filter / forEach
> - 分清"改原数组"和"返回新数组"的方法
> - 会读写、新增、删除对象属性
> - 看得懂解构赋值（了解）

---

## 1. 白话理解：数组就是"有序的万能盒子"

```javascript
const nums = [10, 20, 30];
```

- 下标从 **0** 开始（和 Java 一样）
- `nums.length` 拿长度
- 长度可变，类型可混（`[1, "a", true]` 也合法，但不推荐）

```javascript
console.log(nums[0]);      // 10
console.log(nums.length);  // 3
console.log(nums[3]);      // undefined（越界不报错，只是 undefined）
```

> **和 Java 的差异**：Java 数组长度固定、类型固定；JS 数组更像 `ArrayList`，可以随时 push/pop。

---

## 2. push / pop：改原数组

```javascript
const arr = [1, 2];

arr.push(3);        // 末尾加一个，返回新长度
console.log(arr);   // [1, 2, 3]

const last = arr.pop();   // 末尾删一个，返回被删的值
console.log(last);  // 3
console.log(arr);   // [1, 2]
```

| 方法 | 作用 | 返回值 | 是否改原数组 |
|------|------|--------|-------------|
| `push(x)` | 末尾添加 | 新长度 | ✅ |
| `pop()` | 末尾删除 | 被删的元素 | ✅ |

> 补充（了解）：`unshift` / `shift` 是"头部添加/删除"，用法对称，用到再查。

---

## 3. forEach：遍历，只是"过一遍"

```javascript
const names = ["张三", "李四", "王五"];

names.forEach((name, index) => {
  console.log(index, name);
});

// 0 张三
// 1 李四
// 2 王五
```

| 特点 | 说明 |
|------|------|
| 参数 | `(元素, 下标, 原数组)`，通常只用前两个 |
| 返回值 | **undefined**（不返回新数组） |
| 用途 | 打印、发请求、往页面塞数据等"**副作用**"操作 |

> 想"加工数据得到一个新数组"，用下面的 `map`，别用 forEach 手动 push。

---

## 4. map：转换，一个变一个

```javascript
const prices = [100, 200, 300];

const discounted = prices.map(price => price * 0.8);

console.log(discounted);   // [80, 160, 240]
console.log(prices);       // [100, 200, 300] ← 原数组没变
```

| 特点 | 说明 |
|------|------|
| 返回值 | **新数组**，长度和原数组一样 |
| 回调返回值 | 就是新数组对应位置的元素 |
| 用途 | 提取字段、单位换算、格式化 |

```javascript
const users = [
  { name: "张三", age: 20 },
  { name: "李四", age: 25 }
];

const names = users.map(user => user.name);
console.log(names);   // ["张三", "李四"]
```

---

## 5. filter：过滤，留下满足条件的

```javascript
const nums = [5, 12, 8, 130, 44];

const big = nums.filter(n => n >= 10);
console.log(big);     // [12, 130, 44]
console.log(nums);    // 原数组不变
```

| 特点 | 说明 |
|------|------|
| 返回值 | **新数组**，长度 ≤ 原数组 |
| 回调返回值 | `true` 保留，`false` 丢弃 |
| 用途 | 按条件筛选列表 |

```javascript
const phones = products.filter(p => p.category === "手机" && p.price < 6000);
```

---

## 6. 链式调用：filter + map（高频组合）

```javascript
const products = [
  { title: "iPhone 15", category: "手机", price: 7999 },
  { title: "小米 14", category: "手机", price: 3999 },
  { title: "机械键盘", category: "外设", price: 299 }
];

const result = products
  .filter(p => p.category === "手机")   // 先筛出手机
  .map(p => p.title);                   // 再取标题

console.log(result);   // ["iPhone 15", "小米 14"]
```

> **处理接口返回数据的标准姿势**：`filter` 筛 → `map` 变形 → 渲染。

### 和 Java Stream 对照（你会很熟）

| JS 数组方法 | Java Stream | 说明 |
|------------|-------------|------|
| `arr.map(fn)` | `stream.map(fn).collect(...)` | 转换 |
| `arr.filter(fn)` | `stream.filter(fn).collect(...)` | 过滤 |
| `arr.forEach(fn)` | `stream.forEach(fn)` | 遍历消费 |
| 链式调用 | 链式调用 | 思路一样 |

> 差别：Java Stream 是**惰性**的（不 collect 不执行），JS 数组方法**立即执行**并返回结果。

---

## 7. 对象：读、增、删

```javascript
const user = {
  name: "tom",
  age: 25
};

// 读
console.log(user.name);        // tom（点语法，最常用）
console.log(user["age"]);      // 25（方括号，属性名是变量时用）

// 增 / 改
user.email = "tom@demo.com";   // 属性不存在就是新增
user.age = 26;                 // 已存在就是修改

// 删
delete user.age;

console.log(user);   // { name: "tom", email: "tom@demo.com" }
```

| 操作 | 写法 | 注意 |
|------|------|------|
| 读 | `obj.key` / `obj["key"]` | 属性名是变量时只能用方括号 |
| 增 / 改 | `obj.key = value` | 存在即改，不存在即增 |
| 删 | `delete obj.key` | 很少用，知道即可 |
| 判断存在 | `"key" in obj` | 了解 |

```javascript
const key = "name";
console.log(user[key]);    // tom ← 方括号里放变量
```

---

## 8. 解构赋值：从对象/数组里"拆"出变量（了解）

### 对象解构

```javascript
const user = { name: "tom", age: 25, email: "tom@demo.com" };

const { name, age } = user;       // 一次取出两个属性
console.log(name, age);           // tom 25

const { name: userName } = user;  // 重命名：把 name 赋给 userName
console.log(userName);            // tom
```

### 数组解构

```javascript
const nums = [10, 20, 30];
const [first, second] = nums;
console.log(first, second);   // 10 20
```

### 默认值

```javascript
const { city = "北京" } = user;   // user 里没有 city，就用默认值
console.log(city);                // 北京
```

> **用途**：函数参数解构、从接口返回值里快速取字段。看懂即可，不要求熟练默写。

---

## 9. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ push / pop | 改原数组，末尾增删 |
| ✅ forEach | 只遍历，无返回值，用于副作用 |
| ✅ map | 一个变一个，返回新数组 |
| ✅ filter | 按条件筛选，返回新数组 |
| ✅ 链式调用 | `filter(...).map(...)` 处理接口数据 |
| ✅ map/filter 不改原数组 | push/pop 才改 |
| ✅ 对象操作 | 点语法读写，赋值即增改，delete 删除 |
| ✅ 解构 | `const { name } = user`，了解即可 |
