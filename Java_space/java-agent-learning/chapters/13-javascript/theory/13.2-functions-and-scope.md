# 13.2 函数与作用域：普通函数、箭头函数、闭包

> **学习目标**
> - 会写普通函数和箭头函数（后续回调里箭头函数用得最多）
> - 理解函数作用域和块级作用域
> - 知道闭包是什么（概念级，不深挖）
> - 记住一个实用提醒：对象方法别用箭头函数

---

## 1. 三种函数写法

### 写法一：函数声明（最传统）

```javascript
function add(a, b) {
  return a + b;
}

console.log(add(1, 2));   // 3
```

### 写法二：函数表达式（把函数当值赋给变量）

```javascript
const add = function (a, b) {
  return a + b;
};
```

> JS 里函数是"**一等公民**"——可以像数字一样赋给变量、当参数传、当返回值。Java 8 的 Lambda 也是这个思路，但 JS 早得多。

### 写法三：箭头函数（重点，后续最常用）

```javascript
const add = (a, b) => {
  return a + b;
};

// 函数体只有一句 return 时，可以省略 {} 和 return
const add2 = (a, b) => a + b;

// 只有一个参数时，括号也能省
const double = n => n * 2;

console.log(add2(1, 2));   // 3
console.log(double(4));    // 8
```

### 箭头函数简化规则

| 情况 | 写法 |
|------|------|
| 多个参数 | `(a, b) => a + b` |
| 一个参数 | `n => n * 2`（括号可省） |
| 零个参数 | `() => 42`（括号不能省） |
| 函数体一句表达式 | 省略 `{}` 和 `return` |
| 函数体多行 | `(a, b) => { ...; return ...; }` |

> **对照 Java Lambda**：`(a, b) -> a + b` 和 `(a, b) => a + b` 几乎一模一样，只是箭头符号不同（Java 用 `->`，JS 用 `=>`）。

## 2. 参数与返回值：JS 很随意

```javascript
function greet(name) {
  return "你好, " + name;
}

console.log(greet());          // 你好, undefined（少传就是 undefined）
console.log(greet("tom", 18)); // 你好, tom（多传的直接忽略）
```

| 特点 | JS | Java |
|------|-----|------|
| 参数类型 | 不声明 | 必须声明 |
| 参数个数 | 少传→undefined，多传→忽略 | 必须匹配（重载除外） |
| 返回值 | 不写 `return` 就是 `undefined` | 必须匹配返回类型或 void |
| 默认参数 | `function f(a = 1) {}` | 无（要重载/变长参数） |

```javascript
function greet(name = "陌生人") {
  return "你好, " + name;
}
console.log(greet());        // 你好, 陌生人
```

## 3. 作用域：变量在哪里能用

### 三种作用域

```
全局作用域：函数外声明的，哪里都能用
函数作用域：函数内声明的，函数内能用
块级作用域：{} 内用 let/const 声明的，出了 {} 就没了
```

```javascript
const global = "全局";

function test() {
  const local = "函数内";
  console.log(global);       // ✅ 能访问外层
  console.log(local);        // ✅
}

test();
console.log(local);          // ❌ ReferenceError（函数外拿不到）
```

### 块级作用域（let/const 的规矩）

```javascript
{
  let a = 1;
  const b = 2;
}
console.log(a);   // ❌ 出了 {} 就没了
```

```javascript
for (let i = 0; i < 3; i++) {
  // 每次循环的 i 都是独立的
}
console.log(i);   // ❌ 循环外拿不到
```

> 这就是为什么规范要求别用 `var`：`var` 会无视 `{}` 边界，泄漏到整个函数里。

### 作用域链（理解即可）

**内层能访问外层，外层不能访问内层**——像俄罗斯套娃，里面知道外面，外面不知道里面。

```javascript
const x = 1;

function outer() {
  const y = 2;

  function inner() {
    const z = 3;
    console.log(x, y, z);   // ✅ 1 2 3，内层能拿所有外层
  }

  inner();
  // console.log(z);         // ❌ 拿不到内层的 z
}

outer();
```

## 4. 闭包：函数"记住了"它出生的环境（了解即可）

### 白话理解

闭包 = **函数 + 它定义时所在的环境**。函数被带到别处执行时，仍然能访问当初那个环境里的变量——像随身带着自己的"出生地"。

```javascript
function createCounter() {
  let count = 0;              // 外层函数的局部变量

  return function () {        // 返回一个内层函数
    count++;                  // 内层函数用到了外层的 count
    return count;
  };
}

const counter = createCounter();
console.log(counter());   // 1
console.log(counter());   // 2
console.log(counter());   // 3
```

### 为什么能这样？

正常情况下，`createCounter()` 执行完，它的局部变量 `count` 应该被销毁。但**因为返回的内层函数还在引用它**，JS 会把这个环境保留下来——这就是闭包。

### 实际用处（知道即可）

| 场景 | 说明 |
|------|------|
| 计数器 / 私有变量 | 上面的例子，`count` 外部改不了 |
| 回调里保存状态 | 事件处理函数记住点击次数等 |

> 本阶段**理解这个计数器例子就够了**，不用研究内存泄漏、循环里的闭包等细节，后面遇到再查。

## 5. 一个实用提醒：对象方法别用箭头函数

箭头函数有一个特性：**没有自己的 `this`**（`this` 指向外层）。现在不用深究 `this`，只要记住一条规范：

```javascript
const user = {
  name: "tom",

  // ✅ 对象方法用普通函数
  sayHi: function () {
    console.log("我是 " + this.name);
  },

  // ❌ 箭头函数拿不到这个对象的 this
  sayHiWrong: () => {
    console.log("我是 " + this.name);   // undefined
  }
};

user.sayHi();        // 我是 tom
user.sayHiWrong();   // 我是 undefined
```

> **规范**：**回调参数**（map/filter/setTimeout）用箭头函数；**对象的方法**用普通函数。等以后系统学 `this` 再深入。

## 6. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 三种写法 | 函数声明、函数表达式、箭头函数 |
| ✅ 箭头函数 | `(a, b) => a + b`，单参数省括号，单表达式省 return |
| ✅ 参数随意 | 少传 undefined，多传忽略，可设默认值 |
| ✅ 作用域链 | 内层能访问外层，反之不行 |
| ✅ 块级作用域 | let/const 出 `{}` 就失效 |
| ✅ 闭包 | 函数记住了定义时的环境（计数器例子） |
| ✅ 对象方法 | 用普通函数，别用箭头函数 |
