# 13.5 DOM 基础：选中元素、改内容、改属性

> **学习目标**
> - 理解 DOM 是什么（JS 操作页面的桥梁）
> - 会用 getElementById / querySelector 选中元素
> - 会用 innerText / innerHTML 修改内容
> - 会读取和修改标签属性、表单值

---

## 1. 白话理解：DOM 是浏览器搭好的"页面积木树"

浏览器拿到 HTML 后，会把它解析成一棵**树**，每个标签都是一个节点：

```
document
└── html
    ├── head
    └── body
        ├── h1        "登录"
        ├── input     id="username"
        ├── input     id="password"
        └── button    "提交"
```

JS 通过 `document` 这个入口，就能找到树上的任意节点，然后**改文字、改属性、绑事件**。

> **一句话**：HTML 是页面的"图纸"，DOM 是浏览器按图纸搭好的"积木"，JS 负责动积木。

---

## 2. 选中元素：先找到，才能操作

### 2.1 getElementById：按 id 找（最直接）

```html
<input id="username" type="text">
```

```javascript
const input = document.getElementById("username");
console.log(input);          // <input id="username" type="text">
```

- 返回**一个元素**；找不到返回 `null`
- id 在页面里应该唯一

### 2.2 querySelector：按 CSS 选择器找（最常用）

```javascript
document.querySelector("#username");        // 按 id
document.querySelector(".item");            // 按 class，取第一个
document.querySelector("input[type='password']");  // 按属性
document.querySelector("#loginForm button");       // 按层级
```

| 选择器写法 | 含义 |
|-----------|------|
| `#username` | id 为 username |
| `.item` | class 包含 item |
| `input` | 所有 input 中的第一个 |
| `#form button` | id=form 里的 button |

> **选择建议**：能用 id 就用 `getElementById`；需要复杂选择（class、层级、属性）用 `querySelector`。两者都只返回**第一个**匹配元素。

### 2.3 找不到会怎样

```javascript
const el = document.getElementById("notExist");
console.log(el);            // null

el.innerText = "x";         // ❌ TypeError: Cannot read properties of null
```

> **排查口诀**：看到 `Cannot read properties of null`，先检查 **id 拼写** 和 **script 是否在元素之前执行**。

## 3. 修改内容：innerText vs innerHTML

```html
<div id="box"></div>
```

```javascript
const box = document.getElementById("box");

box.innerText = "纯文本内容";
box.innerHTML = "<strong>加粗内容</strong>";
```

| 属性 | 作用 | 会不会解析 HTML |
|------|------|----------------|
| `innerText` | 改文字内容 | ❌ 原样显示 |
| `innerHTML` | 改内部 HTML | ✅ 会解析标签 |

**效果区别**：

```javascript
box.innerText = "<strong>你好</strong>";
// 页面显示：<strong>你好</strong>

box.innerHTML = "<strong>你好</strong>";
// 页面显示：**你好**（加粗）
```

> ⚠️ **安全提醒**：`innerHTML` 会把字符串当 HTML 执行。**不要把用户输入直接塞进 innerHTML**（可能被注入脚本）。展示用户输入一律用 `innerText`。

## 4. 属性操作

### 4.1 通用属性：getAttribute / setAttribute

```html
<a id="link" href="https://example.com">链接</a>
```

```javascript
const link = document.getElementById("link");

console.log(link.getAttribute("href"));       // https://example.com
link.setAttribute("href", "https://example.org");
link.setAttribute("target", "_blank");
```

### 4.2 表单值：用 value 属性

```html
<input id="username" type="text" value="默认值">
```

```javascript
const input = document.getElementById("username");

console.log(input.value);      // 默认值
input.value = "tom";           // 修改输入框内容
```

> **区分**：普通标签属性用 `getAttribute/setAttribute`；**输入框当前输入的内容用 `.value`**，这是最常用的。

### 4.3 常用直接属性

```javascript
const btn = document.getElementById("submitBtn");

btn.disabled = true;           // 禁用按钮
btn.innerText = "提交中...";    // 改按钮文字
```

| 操作 | 写法 |
|------|------|
| 读输入值 | `input.value` |
| 改输入值 | `input.value = "..."` |
| 禁用 | `button.disabled = true` |
| 改文字 | `element.innerText = "..."` |
| 读普通属性 | `element.getAttribute("href")` |
| 改普通属性 | `element.setAttribute("href", "...")` |

## 5. 一个最小综合例子

```html
<h2 id="title">原始标题</h2>
<input id="nameInput" type="text" placeholder="请输入名字">
<button id="changeBtn">修改标题</button>

<script>
  const title = document.getElementById("title");
  const nameInput = document.getElementById("nameInput");
  const btn = document.getElementById("changeBtn");

  btn.onclick = function () {
    const name = nameInput.value.trim();
    title.innerText = name ? "你好，" + name : "请输入名字";
  };
</script>
```

> 这段已经具备"输入 → 点击 → 改页面"的完整链路，事件绑定下一节详细讲。

## 6. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ DOM | 浏览器解析 HTML 得到的节点树，JS 通过 document 操作 |
| ✅ getElementById | 按 id 找一个元素，找不到返回 null |
| ✅ querySelector | 按 CSS 选择器找第一个匹配元素 |
| ✅ innerText | 改纯文本，不解析 HTML |
| ✅ innerHTML | 改 HTML，会解析标签（注意 XSS） |
| ✅ 表单值 | 用 `.value`，不是 innerText |
| ✅ 普通属性 | getAttribute / setAttribute |
