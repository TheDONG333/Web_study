# 13.1 变量与类型：let / const / var 和 Java 差在哪

> **学习目标**
> - 掌握 let / const / var 的区别和使用规范（本章重点）
> - 理解 JS 的弱类型，认识 5 种基本类型和引用类型
> - 会用 `===` 而不是 `==`，知道常见的真假值
> - 快速过一遍运算符、条件、循环（逻辑和 Java 一致）

---

## 1. 白话理解：JS 和 Java 的第一印象差异

你写 Java 时，变量像"**贴了标签的盒子**"：盒子只能装声明过的类型，装错编译就报错。

```java
int age = 18;        // 只能装整数
String name = "tom"; // 只能装字符串
```

JS 的变量像"**万能收纳袋**"：同一个变量，先装数字、再装字符串都行，类型由**值**决定，不由声明决定。

```javascript
let x = 18;          // 现在是数字
x = "十八";           // 改成字符串，完全合法
```

这就是**弱类型 / 动态类型**。灵活，但也更容易出 bug——所以后面要养成用 `===`、写清楚变量含义的习惯。

> **一句话**：Java 是"类型说了算"，JS 是"值说了算"。

## 2. let / const / var：三兄弟怎么选

### 三种声明方式对比（重点）

| | `var` | `let` | `const` |
|---|-------|-------|---------|
| 作用域 | **函数级**（会漏出代码块） | **块级** `{}` | **块级** `{}` |
| 能否重新赋值 | ✅ | ✅ | ❌ 初始化后不能改指向 |
| 能否重复声明 | ✅（会覆盖） | ❌ 报错 | ❌ 报错 |
| 是否提升（hoisting） | ✅ 提升为 undefined | ❌（有暂时性死区） | ❌ |
| 现在还用吗 | **基本不用** | 需要改值时用 | **默认首选** |

### 用代码感受 var 的坑

```javascript
if (true) {
  var a = 1;      // var 是函数级，漏到块外面
  let b = 2;      // let 是块级，出了 {} 就没了
}
console.log(a);   // 1  ← 泄漏了
console.log(b);   // ❌ ReferenceError: b is not defined
```

再比如，`var` 允许重复声明，一不小心就把前面的值覆盖了：

```javascript
var name = "tom";
var name = "jerry";   // 不报错，tom 被悄悄覆盖
```

### 使用规范（背下来）

```
默认用 const
需要重新赋值时用 let
永远不用 var
```

```javascript
const PI = 3.14;          // 不会变的配置、引用
let count = 0;            // 会变的计数器
count = count + 1;        // ✅ let 可以重新赋值

const user = { name: "tom" };
user.name = "jerry";      // ✅ 可以改对象内部属性！
user = {};                // ❌ const 不允许改指向
```

> **const 锁的是"指向"，不是"内容"**：和 Java 的 `final` 一样——引用不能换，但对象里的字段照样能改。

### 和 Java 对照

| | Java | JavaScript |
|---|------|-----------|
| 块级作用域 | ✅ 一直是 | `let` / `const` 是，`var` 不是 |
| 不可重新赋值 | `final` | `const` |
| 类型声明 | 必须有（`int`/`String`） | 没有，类型由值决定 |
| 变量提升 | 无 | `var` 有（坑），`let/const` 无 |
| 重复声明 | 同作用域报错 | `let/const` 报错，`var` 允许 |

## 3. 弱类型与数据类型

### 五种基本类型（原始类型）

| 类型 | 例子 | 白话 |
|------|------|------|
| `number` | `18`、`3.14`、`NaN` | **整数和小数不分家**，都是 number |
| `string` | `"tom"`、`'tom'`、`` `tom` `` | 单双引号、反引号都行 |
| `boolean` | `true` / `false` | 和 Java 一样 |
| `null` | `null` | **主动**表示"空" |
| `undefined` | `undefined` | **还没赋值**，或属性不存在 |

> 注意：JS 没有 `int` / `double` / `float` 的区分，所有数字都是 `number`（底层是 IEEE 754 双精度）。`0.1 + 0.2 !== 0.3` 就是这个原因——涉及金额计算时后端算，别在前端较真。

### null 和 undefined 的区别（常问）

```javascript
let a;              // 声明了但没赋值 → undefined
let b = null;       // 主动赋值为空 → null

const user = { name: "tom" };
console.log(user.age);   // undefined（属性不存在）
```

| | undefined | null |
|---|-----------|------|
| 来源 | 系统默认（没赋值） | 开发者主动设置 |
| 白话 | "我还没有值" | "我故意是空的" |
| `typeof` | `"undefined"` | `"object"`（历史遗留 bug，记住即可） |

### 引用类型：对象和数组

```javascript
const user = { name: "tom", age: 25 };   // 对象：键值对
const nums = [1, 2, 3];                  // 数组：有序列表
```

- 数组本质也是对象，`typeof []` 返回 `"object"`，判断数组要用 `Array.isArray([])`
- 对象和数组存的是**引用**，赋值时传的是地址（和 Java 对象一样）

```javascript
const a = { x: 1 };
const b = a;        // b 和 a 指向同一个对象
b.x = 99;
console.log(a.x);   // 99  ← 改 b 就是改 a
```

### 弱类型会带来什么

```javascript
console.log("1" + 1);      // "11"   ← + 遇到字符串就拼接
console.log("5" - 1);      // 4      ← - 会偷偷转成数字
console.log(1 == "1");     // true   ← == 会做类型转换（坑！）
console.log(1 === "1");    // false  ← === 类型不同直接 false
```

> **规范**：判断相等**一律用 `===` / `!==`**，除非你明确知道自己在做什么。

### 常见的"假值"（falsy）

JS 在 `if` 里会自动把值转成布尔。下面这些都被当成 `false`：

```
false、0、""（空字符串）、null、undefined、NaN
```

其他都是 `true`（包括 `"0"`、`[]`、`{}`——注意，空数组/空对象是真值！）。

```javascript
if (user.name) {           // 有值才进来，常用写法
  console.log("有名字");
}
```

## 4. 运算符、条件、循环（快速过）

### 运算符

| 类别 | 写法 | 注意 |
|------|------|------|
| 算术 | `+ - * / %` | `/` 结果是小数，不是整除 |
| 比较 | `=== !== > < >= <=` | **用三个等号** |
| 逻辑 | `&& \|\| !` | 和 Java 一样短路 |
| 三元 | `条件 ? 值1 : 值2` | 和 Java 一样 |
| 自增 | `i++` / `++i` | 和 Java 一样 |

```javascript
const age = 20;
const type = age >= 18 ? "成年" : "未成年";
console.log(type);        // 成年
```

### 条件

```javascript
if (age >= 18) {
  console.log("成年");
} else if (age >= 12) {
  console.log("青少年");
} else {
  console.log("儿童");
}
```

> JS 里 `if` 的条件**不要求是 boolean**，任何值都会自动转真假（见上面的 falsy 列表）。Java 必须写布尔表达式。

### 循环

```javascript
// 经典 for（和 Java 几乎一样）
for (let i = 0; i < 3; i++) {
  console.log(i);          // 0 1 2
}

// for...of：直接拿元素（处理数组最常用）
const fruits = ["苹果", "香蕉", "橙子"];
for (const fruit of fruits) {
  console.log(fruit);
}

// while
let n = 0;
while (n < 3) {
  n++;
}
```

> `for...of` 相当于 Java 的增强 for：`for (String fruit : fruits)`。数组遍历还有个更常用的 `forEach`，下一节讲。

## 5. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 默认 const，需要改值用 let | `var` 有作用域泄漏，别用 |
| ✅ const 锁指向不锁内容 | 对象属性照样能改（同 Java final） |
| ✅ 5 种基本类型 | number/string/boolean/null/undefined |
| ✅ null vs undefined | 主动为空 vs 还没赋值 |
| ✅ 弱类型 | 类型自动转换，比较一律用 `===` |
| ✅ falsy 列表 | `false 0 "" null undefined NaN` 为假 |
| ✅ 循环 | 逻辑同 Java，数组遍历用 `for...of` |
