# 13.6 事件绑定与表单操作：让页面"动起来"

> **学习目标**
> - 会用 onclick 绑定点击事件
> - 会用 onsubmit 拦截表单提交
> - 会获取输入框、下拉框的值
> - 会做最基本的表单校验和错误提示
> - 简单了解事件冒泡（不深入）

---

## 1. 白话理解：事件 = "发生了什么" + "然后做什么"

网页上的每个操作都是一个**事件**：点击、提交、输入、滚动……你可以提前告诉浏览器："**当用户点击这个按钮时，执行这段代码**。"

```javascript
const btn = document.getElementById("submitBtn");

btn.onclick = function () {
  console.log("按钮被点击了");
};
```

- `onclick`：事件类型（点击）
- `function () { ... }`：事件处理函数（发生了什么之后要执行的代码）

> Java 对照：类似 GUI 里的 `button.addActionListener(e -> ...)`，思路完全一样——**注册回调**。

## 2. 点击事件 onclick

### 2.1 属性赋值写法（本阶段用这种）

```html
<button id="btn">点我</button>

<script>
  const btn = document.getElementById("btn");

  btn.onclick = function () {
    console.log("你点了我");
  };
</script>
```

### 2.2 箭头函数写法（更短）

```javascript
btn.onclick = () => {
  console.log("你点了我");
};
```

> 回调里用箭头函数很常见（回忆 13.2：回调参数适合箭头函数）。

### 2.3 补充：addEventListener（了解）

```javascript
btn.addEventListener("click", () => {
  console.log("点击");
});
```

效果和 `onclick` 类似，优势是**可以绑多个处理函数**、能精细控制。本阶段用 `onclick` 足够，看到 `addEventListener` 认识即可。

## 3. 表单提交事件 onsubmit（重点）

### 3.1 为什么表单提交会"刷新页面"

`<form>` 的默认行为是：提交后**跳转/刷新页面**。对自测页面来说，一刷新输入就没了，控制台也断了。

所以必须拦截默认行为：

```html
<form id="loginForm">
  <input id="username" type="text">
  <input id="password" type="password">
  <button type="submit">提交</button>
</form>

<script>
  const form = document.getElementById("loginForm");

  form.onsubmit = function (event) {
    event.preventDefault();        // ⭐ 阻止页面刷新
    console.log("表单提交被拦截了");
  };
</script>
```

### 3.2 关键点

| 写法 | 作用 |
|------|------|
| `form.onsubmit = function (event) {...}` | 监听表单提交 |
| `event.preventDefault()` | **阻止默认刷新**（必写） |
| `return false` | 也能阻止，但推荐用 preventDefault |

> **为什么绑在 form 上而不是 button 上？** 因为用户按**回车**也能提交表单，绑在 `onsubmit` 上两种方式都能接住。

## 4. 获取表单的值

### 4.1 输入框

```html
<input id="username" type="text">
```

```javascript
const username = document.getElementById("username").value;
```

### 4.2 下拉框

```html
<select id="role">
  <option value="user">普通用户</option>
  <option value="admin">管理员</option>
</select>
```

```javascript
const role = document.getElementById("role").value;   // "user" 或 "admin"
```

> 下拉框拿到的是选中项的 **value**（不是显示的文字）。

### 4.3 去掉首尾空格

```javascript
const username = document.getElementById("username").value.trim();
```

> 用户很容易多敲空格，校验前先 `trim()`。

## 5. 表单校验 + 错误提示

### 白话理解

校验就是"**提交前先检查**"：用户名不能空、密码不能太短。不通过就提示用户，通过才继续。

```html
<form id="loginForm">
  <input id="username" type="text" placeholder="用户名">
  <input id="password" type="password" placeholder="密码">
  <button type="submit">提交</button>
  <p id="message"></p>
</form>

<script>
  const form = document.getElementById("loginForm");
  const message = document.getElementById("message");

  form.onsubmit = function (event) {
    event.preventDefault();

    const username = document.getElementById("username").value.trim();
    const password = document.getElementById("password").value;

    if (!username) {
      message.innerText = "请输入用户名";
      return;                         // 校验不通过，直接结束
    }

    if (password.length < 6) {
      message.innerText = "密码至少 6 位";
      return;
    }

    message.innerText = "提交成功";
    console.log("用户名:", username);
    console.log("密码:", password);
  };
</script>
```

### 校验流程

```
用户点击提交
      │
      ▼
onsubmit 触发 → preventDefault 阻止刷新
      │
      ▼
依次检查各字段
      ├── 不通过 → 显示错误提示，return
      └── 全部通过 → 打印/发送数据
```

## 6. 事件冒泡（了解即可，不深入）

### 白话理解

点击一个子元素，事件会**从子元素向上"冒泡"**，依次触发父元素的同类事件。

```html
<div id="outer">
  <button id="inner">点我</button>
</div>

<script>
  document.getElementById("outer").onclick = () => console.log("outer");
  document.getElementById("inner").onclick = () => console.log("inner");
</script>
```

点击按钮，控制台输出：

```
inner
outer
```

- 先触发按钮自己的，再冒泡到父元素
- 不想让父元素触发，可以 `event.stopPropagation()`

> **本阶段知道"事件会往上冒泡"即可**，不需要学事件委托、捕获阶段等进阶内容。

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ onclick | 绑定点击事件 |
| ✅ onsubmit | 绑定表单提交事件 |
| ✅ preventDefault | 阻止表单刷新页面，必写 |
| ✅ 取值 | 输入框/下拉框都用 `.value` |
| ✅ trim | 校验前去掉首尾空格 |
| ✅ 校验流程 | 不通过就提示并 return |
| ✅ 事件冒泡 | 子元素事件会向上传递，了解即可 |
