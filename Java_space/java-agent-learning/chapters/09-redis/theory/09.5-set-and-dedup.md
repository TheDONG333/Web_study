# 09.5 Set：去重、共同好友、标签

> **学习目标**
> - 掌握 sadd / smembers / sismember / sinter / sdiff
> - 理解"自动去重"和"集合运算"能变出哪些业务能力
> - 会在 Java 里用 opsForSet 完成同样操作

---

## 1. 白话理解：Set 是"自动去重"的集合

Set 和 Java 的 `HashSet` 一样：**无序、不重复**。塞 100 次同样的值，里面也只有 1 个——**去重是它天生的能力，不用你写任何判断**。

```
sadd tags:100 "数码"
sadd tags:100 "数码"      # 塞第二次 → 加不进去（返回 0）
smembers tags:100         # 只有 1 个 "数码"
```

> **记忆**：想"这东西有没有重复过关"，脑子里第一个蹦出 Set。

---

## 2. 核心命令（redis-cli）

```bash
# ① 添加 / 查看全部成员
sadd friends:1 "张三" "李四" "王五"
smembers friends:1                # 1) "张三" 2) "李四" 3) "王五"（顺序不保证！）

# ② 判断是否在集合中（去重的核心判断）
sismember friends:1 "张三"         # (integer) 1  ← 在
sismember friends:1 "赵六"         # (integer) 0  ← 不在

# ③ 交集：两个人的共同好友
sadd friends:2 "李四" "王五" "赵六"
sinter friends:1 friends:2         # 1) "李四" 2) "王五"

# ④ 差集：在 friends:1 但不在 friends:2 里的人
sdiff friends:1 friends:2          # 1) "张三"

# ⑤ 并集（延伸）：两个人的所有好友合起来
sunion friends:1 friends:2         # 张三 李四 王五 赵六
```

| 命令 | 白话 | 数学含义 |
|------|------|---------|
| sadd / smembers | 添加 / 全看 | —— |
| sismember | 在不在？ | 属于 |
| sinter | 都在的 | 交集 A∩B |
| sdiff | 我有他没有的 | 差集 A−B |
| sunion | 合起来（延伸） | 并集 A∪B |

## 3. 三个高频场景

### 场景一：去重（抽奖 / 每日 UV）

**白话**：防止同一个用户重复参与，不用建表查重——Redis 一句 `sismember` 就问清楚了。

```bash
sismember lottery:2026 "user:1001"    # 0 → 没抽过，放行
sadd lottery:2026 "user:1001"         # 记下来
sismember lottery:2026 "user:1001"    # 1 → 抽过了，拒绝
```

> 想知道"今天来了多少不同的用户"？Redis 的 `scard`（成员数量）直接给答案。

### 场景二：共同好友 / 共同关注（社交经典题）

```bash
sinter friends:1 friends:2            # "你和他的共同好友"
sdiff  friends:1 friends:2            # "我关注了他没关注" → 推荐关注
sinter tags:user:1 tags:product:9     # 用户兴趣标签 ∩ 商品标签 → 精准推荐
```

> **面试高频**：为什么不用 MySQL？——SQL 算交集要 `JOIN` 大表，Redis 的集合运算在内存里毫秒级完成。

### 场景三：标签系统

```bash
sadd tags:product:9 "数码" "礼物" "热销"      # 给商品打标签
sadd tags:product:10 "数码" "新品"
smembers tags:product:9                      # 看商品所有标签
sinter tags:user:1 tags:product:9            # 用户偏好 ∩ 商品标签
```

## 4. Java 里怎么写（opsForSet）

```java
@Autowired
private StringRedisTemplate redis;

String key = "friends:1";

// 添加（可一次加多个）
redis.opsForSet().add(key, "张三", "李四", "王五");

// 判断是否存在
Boolean has = redis.opsForSet().isMember(key, "张三");     // true

// 查看全部成员
Set<String> members = redis.opsForSet().members(key);

// 交集 / 差集
Set<String> common = redis.opsForSet().intersect(key, "friends:2");
Set<String> onlyMine = redis.opsForSet().difference(key, "friends:2");

// 成员个数
Long count = redis.opsForSet().size(key);
```

| 命令 | Java API |
|------|---------|
| `sadd k v` | `opsForSet().add(k, v)` |
| `smembers k` | `opsForSet().members(k)` |
| `sismember k v` | `opsForSet().isMember(k, v)` |
| `sinter k1 k2` | `opsForSet().intersect(k1, k2)` |
| `sdiff k1 k2` | `opsForSet().difference(k1, k2)` |

## 5. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ Set 天生去重 | 同一值塞多次只留一个，不用写判断 |
| ✅ sismember 查重最快 | 抽奖防重复、签到防重复 |
| ✅ sinter/sdiff/sunion | 共同好友、推荐关注、标签匹配 |
| ✅ 无序 | 顺序不保证，要顺序请用 List / ZSet |
| ✅ 什么时候用 | 只关心"在不在、重不重复"，不关心顺序和分数 |
