## 1. 为什么需要 Redis？—— 先想清楚"它替代了谁"

### 白话理解

MySQL 是"**仓库**"：数据放硬盘，容量大、可靠，但每次取货都要走一趟（磁盘 IO + SQL 解析），快也快不到哪去——每秒几千次查询基本到顶了。

Redis 是"**手边的抽屉**"：数据放**内存**，取东西伸手就来——每秒十万级读写。

```
用户的请求 ──▶ Redis（内存，微秒级）──命中──▶ 直接返回
                  │
                没命中
                  ▼
              MySQL（硬盘，毫秒级）──▶ 返回，并顺手塞进 Redis 备用
```

但"快"只是它的一半价值，另一半是它**自带数据结构**：计数器、排行榜、去重、消息队列……这些用 MySQL 做又慢又麻烦，用 Redis 就是一条命令。

| 对比 | MySQL | Redis |
|------|-------|-------|
| 存储位置 | 硬盘 | 内存 |
| 速度 | 毫秒级 | 微秒级 |
| 数据特点 | 完整、持久、可复杂查询 | 快、可过期、适合临时/高频数据 |
| 典型分工 | **存家底**（订单、用户） | **存临时的、热的、要快的数据** |

> **一句话定位**：Redis 不是替代 MySQL，而是**站在 MySQL 前面的加速层和工具层**。数据丢了不心疼的（验证码、排行榜、缓存）放 Redis；丢了会出大事的（订单）必须落 MySQL。

## 2. 启动 Redis：装好 + 连上

### Windows 上二选一

**方式 A：Windows 免安装版（最省事）**
下载 [tporadowski/redis](https://github.com/tporadowski/redis/releases) 的 zip 包 → 解压 → 双击 `redis-server.exe`（这个黑窗口**别关**，关了 Redis 就停了）→ 另开一个窗口双击 `redis-cli.exe`。

**方式 B：Docker（如果装了 Docker Desktop）**

```bash
docker run -d --name my-redis -p 6379:6379 redis:7
```

### 连上之后先打个招呼

```bash
redis-cli          # 进入命令行（Windows 双击 redis-cli.exe）

127.0.0.1:6379> ping        # 心跳测试
PONG                        # ✅ 通了
```

> **可选**：装个图形化工具（RedisInsight / Another Redis Desktop Manager），数据一目了然，初期很有帮助。

## 3. key 通用命令：不管什么类型都用得上

### 白话理解

Redis 里所有数据都是 `key → value`，key 是"门牌号"，value 才是各种数据类型。下面这些命令**和数据类型无关**，任何 key 都能用：

| 命令 | 作用 | 例子 | 结果 |
|------|------|------|------|
| `set` / `get` | 存 / 取（最基础） | `set name tom` → `get name` | `"tom"` |
| `del key` | 删除 | `del name` | `(integer) 1`（删了几个） |
| `exists key` | 是否存在 | `exists name` | `1` 存在 / `0` 不存在 |
| `expire key 60` | **设置过期时间（秒）** | `expire name 60` | `1` |
| `ttl key` | **看还剩多少秒过期** | `ttl name` | `56`；`-1` 永不过期；`-2` 不存在 |
| `type key` | 看是什么类型 | `type name` | `string` |
| `keys *` | 列出所有 key | —— | ⚠️ 生产**禁用**（会阻塞），学习时随便用 |

### key 的命名习惯（很重要，从第一天就养成）

```
业务:数据:唯一标识
sms:code:13800138000      ← 短信验证码
user:info:1001            ← 用户信息
rank:sale:2026-09-24      ← 今日销量榜
```

冒号分层的好处：见名知意、方便按前缀批量管理。

```bash
127.0.0.1:6379> set sms:code:13800138000 8848
OK
127.0.0.1:6379> expire sms:code:13800138000 60    # 60 秒后自动删除
(integer) 1
127.0.0.1:6379> ttl sms:code:13800138000
(integer) 58                                       # 还剩 58 秒
```

> **过期时间是 Redis 的招牌能力**：验证码、限流、临时缓存全靠它，不用你写定时任务去清理——到点自动消失。

## 4. 五种基本类型：一张表看清各自地盘

| 类型 | 白话理解 | 最典型的场景 | 对应章节 |
|------|---------|-------------|---------|
| **String** | 一个 key 一个值 | 验证码、限流、计数器、分布式 ID | 09.2 |
| **Hash** | 一个 key 挂一张小表 | 存用户/商品对象，部分字段更新 | 09.3 |
| **List** | 两头开口的管道（有顺序、可重复） | 简单消息队列、最新消息列表 | 09.4 |
| **Set** | 不重复的集合 | 去重、共同好友、标签 | 09.5 |
| **ZSet** ⭐ | 带了"分数"的 Set，自动排序 | **排行榜**、热搜、延时任务 | 09.6 |

还有三个"了解即可"的：BitMap、HyperLogLog、Geo（09.7 只讲用途，命令用时再查）。

## 5. Java 怎么连 Redis：spring-boot-starter-data-redis

### 白话理解

在 Java 里你不需要手敲 redis 命令，Spring 提供了"**遥控器**"：`StringRedisTemplate`——方法名和命令一一对应（`set` 对 `opsForValue().set`）。

**① 加依赖**（在 Boot 项目 pom 里）：

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
```

**② 配置连接**（application.yml）：

```yaml
spring:
  data:
    redis:
      host: localhost
      port: 6379
      # password: 123456    # 没设密码就不用写
```

**③ 注入遥控器直接用**：

```java
@RestController
public class DemoController {

    @Autowired
    private StringRedisTemplate redis;      // 字符串遥控器（最常用）

    @GetMapping("/demo")
    public String demo() {
        redis.opsForValue().set("name", "tom");                    // = set name tom
        redis.opsForValue().set("code", "8848", Duration.ofSeconds(60)); // = setex
        return redis.opsForValue().get("name");                    // = get name → tom
    }
}
```

> **为什么用 StringRedisTemplate 而不是 RedisTemplate？** RedisTemplate 默认用 JDK 序列化，往 Redis 里存的东西会变成乱码一样的二进制；StringRedisTemplate 存的是人能看懂的字符串，初学者一律先用它。

### 命令 → Java API 对照（后面每节都会补充）

| redis-cli 命令 | Java（StringRedisTemplate） |
|---------------|----------------------------|
| `set k v` | `redis.opsForValue().set(k, v)` |
| `set k v ex 60` | `redis.opsForValue().set(k, v, Duration.ofSeconds(60))` |
| `get k` | `redis.opsForValue().get(k)` |
| `del k` | `redis.delete(k)` |
| `expire k 60` | `redis.expire(k, Duration.ofSeconds(60))` |
| `ttl k` | `redis.getExpire(k)` |

## 6. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ Redis = 内存数据库 | 快 + 数据结构丰富，站在 MySQL 前面做加速和工具 |
| ✅ key 命名用冒号分层 | `业务:数据:标识`，见名知意 |
| ✅ expire / ttl | Redis 的招牌能力，验证码/限流的地基 |
| ✅ 五种基本类型各管一摊 | String 计数、Hash 存对象、List 队列、Set 去重、ZSet 排行榜 |
| ✅ Java 用 StringRedisTemplate | 方法名几乎和命令一一对应，不用手写协议 |
