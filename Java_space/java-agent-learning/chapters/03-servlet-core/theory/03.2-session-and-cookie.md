## 1. 「白话篇」为什么需要 Session 和 Cookie？

### 1.1 问题：HTTP 是没有记忆的

你登录了淘宝，浏览了几个商品，加入购物车——服务器怎么能一直记得"你是你"？

**答案是不能**，因为 HTTP 协议是**无状态**的：

```
请求1：你是谁？ █ 请给出用户名密码 → "我是张三"
请求2：你是谁？ █ 上次不是说了吗！  → "我是...还得再说一遍？"
请求3：你是谁？ █ 😤
```

每次请求都是独立的，服务器默认不记得你上一秒干了什么。

### 1.2 解决方案：给你一个号码牌

上银行办业务：
1. 你第一次去，出示身份证（输入用户名密码登录）
2. 银行在系统里记录了你的信息，然后给你一个**号码牌**（Cookie）
3. 你之后每次来，递上号码牌，银行就知道你是谁了（后续请求自动带 Cookie）

```
浏览器（你）                                  服务器（银行）
    │                                             │
    ├── 请求：POST /login（用户名 + 密码）────────▶ │
    │                                             ├─ 验证通过
    │                                             ├─ 创建 Session（张三的信息）
    │   ◀── 响应：Set-Cookie: JSESSIONID=abc123 ──┤
    │                                             │
    ├── 请求：GET /cart（自动带 Cookie: abc123）─▶ │
    │                                             ├─ 根据 abc123 找到 Session
    │   ◀── 响应：购物车数据（张三的）─────────────┤
    │                                             │
    ├── 请求：GET /order（自动带 Cookie: abc123）─▶ │
    │   ◀── 响应：订单数据（张三的）───────────────┤
```

> **白话总结**：
> - **Cookie** = 银行给你的号码牌（存在你手里，浏览器保存）
> - **Session** = 银行系统里关于你的记录（存在服务器端）
> - Cookie 里存 Session 的编号（SessionId），服务器通过这个编号找到你的 Session
> - 这套机制就叫"会话跟踪"——让无状态的 HTTP 有了"记忆"

## 2. Cookie：存在浏览器端的小数据

### 2.1 Cookie 的本质

> **Cookie 就是一小段文本数据（最大 4KB），服务器通过 HTTP 响应头（`Set-Cookie`）让浏览器保存，浏览器在后续请求中通过请求头（`Cookie`）自动发回。**

```
HTTP 响应头：
  Set-Cookie: username=zhangsan; Path=/; Max-Age=3600
  Set-Cookie: theme=dark; Path=/; HttpOnly

HTTP 请求头（浏览器自动携带）：
  Cookie: username=zhangsan; theme=dark
```

### 2.2 Cookie 的创建和回送

```java
@WebServlet("/cookie/login")
public class CookieLoginServlet extends HttpServlet {
    protected void doPost(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        req.setCharacterEncoding("UTF-8");
        String username = req.getParameter("username");
        String password = req.getParameter("password");

        // 模拟登录验证
        if ("admin".equals(username) && "123456".equals(password)) {

            // ========== ① 创建 Cookie ==========
            Cookie userCookie = new Cookie("username", username);
            Cookie loginTimeCookie = new Cookie("loginTime",
                    String.valueOf(System.currentTimeMillis()));

            // ========== ② 设置 Cookie 属性 ==========
            userCookie.setMaxAge(7 * 24 * 60 * 60);   // 存活 7 天（单位：秒）
            userCookie.setPath("/demo");               // 只在 /demo 路径下发送
            // userCookie.setDomain(".example.com");   // 所有子域名共享这个 Cookie
            // userCookie.setHttpOnly(true);          // 禁止 JavaScript 读取（防 XSS）
            // userCookie.setSecure(true);            // 只用 HTTPS 传输

            loginTimeCookie.setMaxAge(7 * 24 * 60 * 60);

            // ========== ③ 把 Cookie 发回浏览器 ==========
            resp.addCookie(userCookie);
            resp.addCookie(loginTimeCookie);

            resp.setContentType("text/html;charset=UTF-8");
            resp.getWriter().write("<h2>登录成功！Cookie 已设置</h2>");
        } else {
            resp.getWriter().write("<h2>登录失败</h2>");
        }
    }
}
```

### 2.3 Cookie 的读取

```java
@WebServlet("/cookie/welcome")
public class CookieWelcomeServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        resp.setContentType("text/html;charset=UTF-8");
        PrintWriter out = resp.getWriter();

        // ========== ① 获取所有 Cookie ==========
        Cookie[] cookies = req.getCookies();

        String username = null;
        String loginTime = null;

        // ========== ② 遍历查找需要的 Cookie ==========
        if (cookies != null) {
            for (Cookie cookie : cookies) {
                if ("username".equals(cookie.getName())) {
                    username = cookie.getValue();
                } else if ("loginTime".equals(cookie.getName())) {
                    loginTime = cookie.getValue();
                }
            }
        }

        // ========== ③ 使用 Cookie 中的数据 ==========
        if (username != null && loginTime != null) {
            long time = Long.parseLong(loginTime);
            String timeStr = new java.text.SimpleDateFormat("yyyy-MM-dd HH:mm:ss")
                    .format(new java.util.Date(time));

            out.println("<h2>欢迎回来，" + username + "！</h2>");
            out.println("<p>您上次登录时间：" + timeStr + "</p>");
        } else {
            out.println("<h2>欢迎新用户！</h2>");
            out.println("<p><a href='login.html'>去登录</a></p>");
        }
    }
}
```

### 2.4 Cookie 的修改与删除

```java
@WebServlet("/cookie/manage")
public class CookieManageServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        String action = req.getParameter("action");

        if ("update".equals(action)) {
            // ========== 修改 Cookie：创建一个同名的、新值的 Cookie 即可 ==========
            Cookie cookie = new Cookie("username", "new_value");
            cookie.setMaxAge(7 * 24 * 60 * 60);
            cookie.setPath("/demo");
            resp.addCookie(cookie);
            resp.getWriter().write("Cookie 已更新");

        } else if ("delete".equals(action)) {
            // ========== 删除 Cookie：同名 + setMaxAge(0) = 立即过期 ==========
            Cookie cookie = new Cookie("username", "");  // 值无所谓
            cookie.setMaxAge(0);                          // 0 秒存活 = 立即过期
            cookie.setPath("/demo");                      // 路径必须和创建时一致！
            resp.addCookie(cookie);
            resp.getWriter().write("Cookie 已删除");

        }
    }
}
```

> ⚠️ **关键理解**：修改和删除 Cookie 的原理都是"创建一个同名 Cookie 覆盖旧值"。
> - 修改：同名 + 新值 + 新的有效期
> - 删除：同名 + `setMaxAge(0)`
>
> **删除时要确保 path 和创建时一致**，否则浏览器会认为这是两个不同的 Cookie。

### 2.5 Cookie 的安全属性详解

```java
// 创建一个"安全"的 Cookie
Cookie safeCookie = new Cookie("token", "your_jwt_token_here");

// ① HttpOnly：禁止 JavaScript 通过 document.cookie 读取
//   这是防 XSS（跨站脚本攻击）的关键措施
safeCookie.setHttpOnly(true);

// ② Secure：只通过 HTTPS 传输 Cookie
//   防中间人攻击（MITM），HTTP 连接下不会发送
safeCookie.setSecure(true);

// ③ Max-Age：Cookie 的存活时间（秒）
//   0 = 立即删除，正数 = 存活 N 秒，负数 = 浏览器关闭时删除（会话 Cookie）
safeCookie.setMaxAge(60 * 60 * 24);  // 1 天

// ④ Path：控制 Cookie 的发送范围
//   只有请求 URL 的路径以 Path 开头，浏览器才会携带此 Cookie
safeCookie.setPath("/demo/user");    // 只在 /demo/user 及子路径下发送

// ⑤ Domain：控制 Cookie 的域名范围
//   默认是当前域名，设为 ".example.com" 则所有子域共享
// safeCookie.setDomain(".example.com");

// ⑥ SameSite（Servlet API 没有直接支持，但可以通过 Set-Cookie 头手动设置）
// 防止 CSRF 攻击
resp.setHeader("Set-Cookie", "token=abc; SameSite=Strict");
```

| 安全属性 | 作用 | 防护目标 |
|---------|------|---------|
| `HttpOnly` | 禁止 JS 读取 Cookie | XSS（跨站脚本攻击） |
| `Secure` | 只通过 HTTPS 传输 | MITM（中间人攻击） |
| `SameSite=Strict` | 跨站点请求不携带 Cookie | CSRF（跨站请求伪造） |
| `Max-Age` | 控制 Cookie 存活时间 | 防止 Cookie 永久存在 |

### 2.6 Cookie 的完整属性总结

| 属性 | 方法 | 说明 |
|------|------|------|
| name | `Cookie(String name, String value)` | 构造函数设置，不可改 |
| value | `setValue(String)` / `getValue()` | Cookie 的值 |
| maxAge | `setMaxAge(int)` / `getMaxAge()` | 存活秒数：0=删除，负数=会话级，正数=存活N秒 |
| path | `setPath(String)` / `getPath()` | 发送路径范围 |
| domain | `setDomain(String)` / `getDomain()` | 域名范围 |
| secure | `setSecure(boolean)` / `getSecure()` | 是否 HTTPS only |
| httpOnly | `setHttpOnly(boolean)` / `isHttpOnly()` | 是否禁止 JS 访问 |
| comment | `setComment(String)` | 注释（浏览器一般不使用） |

### 2.7 完整 Cookie 演示：记住用户名

```java
/**
 * 登录页面 —— 演示"记住用户名"功能
 * 首次访问：输入用户名+密码，勾选"记住用户名"
 * 再次访问：用户名自动填充
 */
@WebServlet("/cookie/remember-me")
public class RememberMeServlet extends HttpServlet {

    // GET 请求：显示登录页，如果之前勾选过"记住我"则预填用户名
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        resp.setContentType("text/html;charset=UTF-8");
        PrintWriter out = resp.getWriter();

        // 读取 Cookie 中的用户名
        String savedUsername = "";
        Cookie[] cookies = req.getCookies();
        if (cookies != null) {
            for (Cookie c : cookies) {
                if ("savedUsername".equals(c.getName())) {
                    savedUsername = c.getValue();
                }
            }
        }

        // 生成表单
        out.println("<!DOCTYPE html><html><head><meta charset='UTF-8'><title>登录</title></head><body>");
        out.println("<h2>用户登录</h2>");
        out.println("<form action='/demo/cookie/remember-me' method='post'>");
        out.println("用户名：<input type='text' name='username' value='" + savedUsername + "'><br><br>");
        out.println("密码：<input type='password' name='password'><br><br>");
        out.println("<input type='checkbox' name='rememberMe' value='true'>记住用户名<br><br>");
        out.println("<button type='submit'>登录</button>");
        out.println("</form></body></html>");
    }

    // POST 请求：处理登录
    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        req.setCharacterEncoding("UTF-8");
        String username = req.getParameter("username");
        String password = req.getParameter("password");
        String rememberMe = req.getParameter("rememberMe");  // checkbox 选中则为 "true"

        // 模拟登录验证
        if ("admin".equals(username) && "123456".equals(password)) {
            // 登录成功

            // 如果勾选了"记住我"，设置一个长期 Cookie
            if ("true".equals(rememberMe)) {
                Cookie cookie = new Cookie("savedUsername", username);
                cookie.setMaxAge(30 * 24 * 60 * 60);  // 记住 30 天
                cookie.setPath("/demo");
                resp.addCookie(cookie);
            } else {
                // 没有勾选 — 删除之前的 Cookie
                Cookie cookie = new Cookie("savedUsername", "");
                cookie.setMaxAge(0);
                cookie.setPath("/demo");
                resp.addCookie(cookie);
            }

            resp.setContentType("text/html;charset=UTF-8");
            resp.getWriter().write("<h2>登录成功！</h2><p>欢迎，" + username + "</p>"
                    + "<p><a href='/demo/cookie/remember-me'>返回登录页（看看用户名记住了没）</a></p>");

        } else {
            resp.getWriter().write("<h2>登录失败</h2><a href='/demo/cookie/remember-me'>重试</a>");
        }
    }
}
```

## 3. Session：存在服务器端的用户数据

### 3.1 Session 的本质

> **Session 是一个存在服务器端的"存储空间"，每个用户独享一份。服务器通过 SessionId 来识别"这个请求属于谁"。**

```
服务器内存中：
┌────────────────────┐
│ abc123 → Session 1 │   ← 张三的 Session
│   userName: 张三    │
│   loginTime: xxx   │
│   cart: [...]      │
├────────────────────┤
│ def456 → Session 2 │   ← 李四的 Session
│   userName: 李四    │
│   loginTime: yyy   │
│   cart: [...]      │
└────────────────────┘
```

### 3.2 Session 的获取和数据存取

```java
@WebServlet("/session/login")
public class SessionLoginServlet extends HttpServlet {
    protected void doPost(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        req.setCharacterEncoding("UTF-8");
        String username = req.getParameter("username");
        String password = req.getParameter("password");

        resp.setContentType("text/html;charset=UTF-8");
        PrintWriter out = resp.getWriter();

        if ("admin".equals(username) && "123456".equals(password)) {

            // ========== ① 获取当前用户的 Session ==========
            // 如果没有 Session，自动创建一个新的
            HttpSession session = req.getSession();
            // 等价于 req.getSession(true);

            // ========== ② 向 Session 中存数据（想存什么都行）==========
            session.setAttribute("username", username);
            session.setAttribute("loginTime", System.currentTimeMillis());
            session.setAttribute("isLogin", true);

            // Session 中可以存对象
            session.setAttribute("user", new UserDTO(1, username, "admin@example.com"));

            out.println("<h2>登录成功！Session 已创建</h2>");
            out.println("<p>SessionId：" + session.getId() + "</p>");
            out.println("<p><a href='/demo/session/home'>进入个人中心</a></p>");

        } else {
            out.println("<h2>登录失败</h2>");
        }
    }
}

// ========== 辅助 DTO 类 ==========
class UserDTO {
    private int id;
    private String username;
    private String email;
    // 构造方法、getter/setter 省略
    public UserDTO(int id, String username, String email) {
        this.id = id; this.username = username; this.email = email;
    }
    @Override
    public String toString() {
        return "UserDTO{id=" + id + ", username='" + username + "', email='" + email + "'}";
    }
}
```

### 3.3 Session 数据的读取和删除

```java
@WebServlet("/session/home")
public class SessionHomeServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        resp.setContentType("text/html;charset=UTF-8");
        PrintWriter out = resp.getWriter();

        // ========== ① 获取 Session（不创建新的）==========
        HttpSession session = req.getSession(false);  // false = 没有就返回 null

        if (session == null) {
            out.println("<h2>未登录，请先登录</h2>");
            out.println("<a href='login.html'>去登录</a>");
            return;
        }

        // ========== ② 从 Session 中取数据 ==========
        String username = (String) session.getAttribute("username");
        Long loginTime = (Long) session.getAttribute("loginTime");
        Boolean isLogin = (Boolean) session.getAttribute("isLogin");
        UserDTO user = (UserDTO) session.getAttribute("user");

        // ========== ③ 使用 Session 中的数据 ==========
        if (isLogin != null && isLogin) {
            out.println("<h2>个人中心</h2>");
            out.println("<p>用户名：" + username + "</p>");
            out.println("<p>用户信息：" + user + "</p>");
            out.println("<p>SessionId：" + session.getId() + "</p>");
            out.println("<p>Session 创建时间：" +
                new java.util.Date(session.getCreationTime()) + "</p>");
            out.println("<p>上次访问时间：" +
                new java.util.Date(session.getLastAccessedTime()) + "</p>");
            out.println("<p><a href='/demo/session/logout'>退出登录</a></p>");
        } else {
            out.println("<h2>未登录</h2>");
        }
    }
}
```

### 3.4 Session 的销毁（退出登录）

```java
@WebServlet("/session/logout")
public class SessionLogoutServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        HttpSession session = req.getSession(false);

        if (session != null) {
            // ========== 方式一：只删除某个属性 ==========
            session.removeAttribute("username");
            session.removeAttribute("loginTime");
            session.removeAttribute("isLogin");

            // ========== 方式二：销毁整个 Session ==========
            session.invalidate();  // Session 彻底销毁，所有数据清空

            System.out.println("Session 已销毁");
        }

        resp.setContentType("text/html;charset=UTF-8");
        resp.getWriter().write("<h2>已退出登录</h2><a href='login.html'>重新登录</a>");
    }
}
```

### 3.5 Session 的配置参数

在 `web.xml` 中配置：

```xml
<web-app>
    <!-- Session 过期时间（分钟），0 或负数表示永不过期 -->
    <session-config>
        <session-timeout>30</session-timeout>  <!-- 30 分钟 -->
    </session-config>

    <!-- 也可以通过 CookieConfig 控制 JSESSIONID Cookie 的属性 -->
    <session-config>
        <session-timeout>30</session-timeout>
        <cookie-config>
            <name>MY_SESSION_ID</name>           <!-- 自定义 SessionID Cookie 名 -->
            <path>/</path>
            <http-only>true</http-only>          <!-- JSESSIONID 也应该是 HttpOnly -->
            <secure>true</secure>
            <!-- <domain>.example.com</domain> -->
        </cookie-config>
    </session-config>
</web-app>
```

或者在 Java 代码中设置：

```java
HttpSession session = req.getSession();

// 单独修改这个 Session 的过期时间（秒）
session.setMaxInactiveInterval(60 * 30);  // 30 分钟

// 查询过期时间
int seconds = session.getMaxInactiveInterval();
```

## 4. Cookie 和 Session 的联动机制

### 4.1 完整的协作流程

```
浏览器第一次请求：
    浏览器                                  服务器
    ─── GET /index ────────────────────▶
                                          req.getSession() → 没找到 JSESSIONID Cookie
                                          → 创建一个新 Session
    ◀── 响应：Set-Cookie: JSESSIONID=abc123; Path=/; HttpOnly
                                          → 把 SessionId 放在 Cookie 里返回
    浏览器保存 Cookie

浏览器后续请求（同一次会话）：
    ─── GET /cart ────────────────────▶
    Cookie: JSESSIONID=abc123（浏览器自动发送）
                                          → 根据 abc123 找到 Session
                                          → 从 Session 中取用户数据
    ◀── 响应：购物车数据
```

### 4.2 底层代码验证

```java
@WebServlet("/session/trace")
public class SessionTraceServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        resp.setContentType("text/html;charset=UTF-8");
        PrintWriter out = resp.getWriter();

        out.println("<h2>Cookie 与 Session 联动验证</h2>");

        // ① 查看请求中携带的 JSESSIONID
        out.println("<h3>请求中的 Cookie：</h3>");
        Cookie[] cookies = req.getCookies();
        if (cookies != null) {
            for (Cookie c : cookies) {
                out.println("<p>" + c.getName() + " = " + c.getValue() + "</p>");
            }
        } else {
            out.println("<p>（无 Cookie）</p>");
        }

        // ② 获取 Session
        HttpSession session = req.getSession();

        // ③ 验证：Session.getId() 应该和 JSESSIONID Cookie 的值一样
        out.println("<h3>当前 Session：</h3>");
        out.println("<p>SessionId：" + session.getId() + "</p>");
        out.println("<p>Session 创建时间：" + new java.util.Date(session.getCreationTime()) + "</p>");
        out.println("<p>是否是新创建的：" + session.isNew() + "</p>");

        // ④ 记录访问次数（存到 Session 中）
        Integer visitCount = (Integer) session.getAttribute("visitCount");
        if (visitCount == null) {
            visitCount = 1;
        } else {
            visitCount++;
        }
        session.setAttribute("visitCount", visitCount);
        out.println("<p>这是您第 <b>" + visitCount + "</b> 次访问本页面</p>");
    }
}
```

### 4.3 如果浏览器禁用了 Cookie，Session 怎么工作？

> 如果浏览器禁用 Cookie，`JSESSIONID` 无法通过 Cookie 传递，每次 `req.getSession()` 都会创建一个**新的** Session（旧 Session 找不到了）。

**解决方案：URL 重写**

```java
// 在返回的 HTML 中的所有链接上手动追加 JSESSIONID
String url = resp.encodeURL("/demo/cart");
// 如果 Cookie 工作正常 → 返回 "/demo/cart" 不变
// 如果 Cookie 被禁用 → 返回 "/demo/cart;jsessionid=abc123"

out.println("<a href='" + url + "'>购物车</a>");

// 重定向时也要用 encodeRedirectURL
String redirectUrl = resp.encodeRedirectURL("/demo/home");
resp.sendRedirect(redirectUrl);
```

> ⚠️ URL 重写会使 URL 变得很长很丑，而且 SessionId 暴露在 URL 中有安全风险。现代项目一般不支持 Cookie 禁用场景。

## 5. Session 的生命周期与钝化/活化

### 5.1 Session 的四种终止方式

| 方式 | 触发 | 说明 |
|------|------|------|
| **超时** | 超过 `maxInactiveInterval` 没有请求 | 最常见，默认 30 分钟（Tomcat） |
| **手动销毁** | 调用 `session.invalidate()` | 退出登录时调用 |
| **服务器关闭** | Tomcat 正常关闭 | Session 可能被持久化（钝化） |
| **JSESSIONID Cookie 丢失** | 用户换了浏览器 / 清 Cookie | 旧 Session 找不到了，自动创建新的 |

### 5.2 Session 的钝化与活化（面试高频）

> **钝化（Passivation）**：Tomcat 正常关闭或 Session 过多时，把内存中的 Session 对象序列化到硬盘
> **活化（Activation）**：Tomcat 重新启动后，从硬盘读取之前保存的 Session 对象，恢复到内存中

```
正常运行时：
  ┌── 内存 ──┐
  │ Session  │
  └──────────┘

Tomcat 正常关闭：
  ┌── 内存 ──┐     序列化      ┌── 硬盘 ──────────┐
  │ Session  │  ────────▶     │ SESSIONS.ser 文件 │
  └──────────┘                └──────────────────┘
  
Tomcat 重新启动：
  ┌── 硬盘 ──────────┐     反序列化      ┌── 内存 ──┐
  │ SESSIONS.ser 文件 │  ────────▶      │ Session  │
  └──────────────────┘                  └──────────┘
```

**钝化的前提条件：**

```java
// ① Session 中的对象必须实现 Serializable 接口
public class UserDTO implements java.io.Serializable {
    private static final long serialVersionUID = 1L;
    private int id;
    private String username;
    // ...
}

// ② 钝化文件的位置（Tomcat）
// work/Catalina/localhost/应用名/SESSIONS.ser
```

> **白话**：
> - **钝化** = 服务器正常关机时，把内存中的 Session 存到硬盘上，防止数据丢失
> - **活化** = 服务器重启后，从硬盘上把 Session 读回来，用户再次访问时感觉不到服务器重启过
> - 如果你的 Session 中存的对象没有实现 `Serializable`，钝化时就可能报 `NotSerializableException`，导致 Session 丢失

## 6. Cookie vs Session 完整对比

| 对比维度 | Cookie | Session |
|---------|--------|---------|
| **存储位置** | 浏览器（客户端） | 服务器（内存/硬盘） |
| **安全性** | 低（存在用户电脑上，可被查看和篡改） | 高（存在服务器上） |
| **容量** | 4KB / 每个域名 20 个左右 | 理论上无限制（受服务器内存影响） |
| **性能** | 每次请求都发给服务器（增加网络开销） | 服务器内查找（内存操作，快） |
| **数据类型** | 只能存字符串 | 可以存任意 Java 对象 |
| **生命周期** | 可设置长期有效（数天到数年） | 默认 30 分钟无操作即过期 |
| **跨域** | 可通过 Domain 属性跨子域 | 不能（SessionId 传输受 Cookie 限制） |
| **禁用后** | 用户可手动禁用 | 依赖 Cookie 传 SessionId（或 URL 重写） |

> **使用原则**：
> - 用户身份验证、敏感数据 → **Session**
> - 用户偏好（主题、语言）、不敏感的标识 → **Cookie**
> - 记住用户名、网站访客统计 → **Cookie**

---

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ HTTP 是无状态的 | 用 Cookie + Session 实现"记忆"——Cookie 是号码牌，Session 是后台记录 |
| ✅ Cookie 存在浏览器端 | 容量小（4KB），可被用户查看，设置 HttpOnly 可禁止 JS 读取 |
| ✅ Session 存在服务器端 | 可存对象，安全；通过 JSESSIONID Cookie 与浏览器绑定 |
| ✅ `req.getSession()` 自动查 Cookie 中的 JSESSIONID | 如果没找到就创建新 Session |
| ✅ `session.invalidate()` 彻底销毁 Session | 退出登录时必调 |
| ✅ 删除 Cookie 用同名 + `setMaxAge(0)` | 且 path 必须和创建时保持一致 |
| ✅ Session 中存的对象必须实现 Serializable | 否则服务器重启时可能丢失 |
