# 03.3 MVC 三层架构：分层思想与解耦设计

> **学习目标**
> - 理解"为什么需要分层"——从单体 Servlet 的痛点出发

> - 看懂 Spring Boot 项目背后和 MVC 三层架构的对应关系
> - 能够用纯 Servlet 手写出一个三层架构的 CRUD 项目骨架

## 1. 「白话篇」为什么需要分层？

### 1.1 把所有代码写在一个 Servlet 里的灾难

假设你在做一个用户管理模块，把所有逻辑都塞进一个 Servlet：

```java
@WebServlet("/user/*")
public class MonolithicUserServlet extends HttpServlet {
    // 一个 Servlet 里：处理路由 + 获取参数 + 校验 + 业务逻辑 + 查数据库 + 拼 JSON + 返回响应
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) {
        // 路由判断
        String path = req.getPathInfo();
        if ("/list".equals(path)) {
            // 查数据库的 SQL 直接写在这里
            String sql = "SELECT * FROM users WHERE deleted = 0 AND name LIKE ? ...";
            // 拼 JSON
            StringBuilder json = new StringBuilder("[");
            // ... 200 行拼 JSON 代码 ...
            // 乱成一锅粥
        } else if ("/detail".equals(path)) {
            // 又是 200 行 ...
        }
    }
}
```

**问题：**
- 一个类几千行，改一个功能要翻半个天
- SQL、HTML、业务逻辑全混在一起
- 修改数据库逻辑可能影响接口返回格式
- 无法复用（另一个 Servlet 也要查用户，只能复制粘贴 SQL）

### 1.2 分层的本质：各司其职

就像公司里：

| 角色 | 职责 | 对应代码层 | 典型类名 |
|------|------|-----------|---------|
| 前台接待 | 接收客人请求，转发给相关部门 | **Controller**（表现层） | UserController / UserServlet |
| 业务经理 | 协调流程、制定规则、做判断 | **Service**（业务逻辑层） | UserService / UserServiceImpl |
| 仓库管理员 | 存取货品，只负责入库出库 | **Dao**（数据访问层） | UserDao / UserDaoImpl |
| 货品本身 | 在各个层之间传递的数据 | **Model**（实体/模型） | User / UserDTO |

> **白话**：
> - 前台（Controller）只管接客，不碰仓库
> - 经理（Service）只管业务规则，不搬箱子
> - 仓库（Dao）只管存取数据，不管"这个用户能不能注册"
>
> 每一层只做自己的事，**通过接口互相调用，而不是直接依赖实现类**——这就是"分层"的核心思想。

## 2. MVC 三层架构的全景图

### 2.1 请求从浏览器出发，数据流经过各层

```
浏览器
  │
  │ HTTP 请求
  ▼
┌─────────────────────────────────────────────────────────┐
│                    表现层（Controller）                   │
│  职责：接收 HTTP 参数，校验，调用 Service，返回响应        │
│  UserServlet.doPost()                                   │
│    ├─ 获取请求参数（req.getParameter(...)）               │
│    ├─ 基本参数校验                                       │
│    ├─ 调用 Service                                      │
│    ├─ 根据 Service 返回结果决定状态码                      │
│    └─ 输出响应（JSON / HTML / 转发 / 重定向）              │
└───────────────────┬─────────────────────────────────────┘
                    │ 调用
                    ▼
┌─────────────────────────────────────────────────────────┐
│                   业务逻辑层（Service）                    │
│  职责：处理业务规则，组装数据，调用 DAO，事务管理            │
│  UserServiceImpl.register(User)                         │
│    ├─ 检查用户名是否已存在                                 │
│    ├─ 密码加密（MD5 / BCrypt）                            │
│    ├─ 调用 DAO 保存用户                                   │
│    ├─ 调用 DAO 创建默认角色                                │
│    └─ 返回结果给 Controller                              │
└───────────────────┬─────────────────────────────────────┘
                    │ 调用
                    ▼
┌─────────────────────────────────────────────────────────┐
│                   数据访问层（Dao）                        │
│  职责：与数据库交互，CRUD 操作，只关心数据存取               │
│  UserDaoImpl.save(User)                                 │
│    ├─ INSERT INTO users VALUES (...)                    │
│    └─ 返回自增 ID 或受影响行数                             │
└───────────────────┬─────────────────────────────────────┘
                    │ JDBC / MyBatis / JPA
                    ▼
                ┌─────────┐
                │ 数据库   │
                └─────────┘
```

### 2.2 各层的核心关键字

| 层 | 只能调用 | 只能被调用 | 不能做的事 |
|------|---------|-----------|-----------|
| **Controller** | Service | 用户请求 | 不能直接操作数据库，不能包含复杂业务逻辑 |
| **Service** | Dao | Controller | 不能处理 HTTP 请求参数 |
| **Dao** | 数据库 | Service | 不能包含业务逻辑（如"密码不能太简单"） |

### 3.3 Dao 层：只负责数据存取

```java
package com.example.mvc.dao;

import com.example.mvc.entity.User;
import java.util.*;

/**
 * 用户数据访问接口
 * 只定义"做什么"，不关心"怎么做"
 * 这就是面向接口编程——如果以后换数据库（MySQL → MongoDB），
 * 只需换个实现类，Service 层一行代码都不用改
 */
public interface UserDao {

    /** 保存用户，返回自增 ID */
    int save(User user);

    /** 根据 ID 查询用户 */
    User findById(int id);

    /** 根据用户名查询用户 */
    User findByUsername(String username);

    /** 查询所有用户（支持关键词搜索）*/
    List<User> findAll(String keyword);

    /** 更新用户 */
    int update(User user);

    /** 删除用户（根据 ID）*/
    int deleteById(int id);

    /** 统计用户总数 */
    int count();
}
```

```java
package com.example.mvc.dao.impl;

import com.example.mvc.dao.UserDao;
import com.example.mvc.entity.User;
import java.sql.*;
import java.util.*;

/**
 * 用户数据访问层实现 —— 用 JDBC 操作 MySQL
 * 这里只写 SQL，不包含任何业务逻辑
 */
public class UserDaoImpl implements UserDao {

    @Override
    public int save(User user) {
        String sql = "INSERT INTO users (username, password, email, phone) VALUES (?, ?, ?, ?)";
        try (Connection conn = DBUtil.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)) {

            ps.setString(1, user.getUsername());
            ps.setString(2, user.getPassword());
            ps.setString(3, user.getEmail());
            ps.setString(4, user.getPhone());
            ps.executeUpdate();

            // 获取自增 ID
            ResultSet rs = ps.getGeneratedKeys();
            if (rs.next()) {
                return rs.getInt(1);
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return -1;
    }

    @Override
    public User findById(int id) {
        String sql = "SELECT * FROM users WHERE id = ? AND deleted = 0";
        try (Connection conn = DBUtil.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setInt(1, id);
            ResultSet rs = ps.executeQuery();
            if (rs.next()) {
                return mapRow(rs);
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return null;
    }

    @Override
    public User findByUsername(String username) {
        String sql = "SELECT * FROM users WHERE username = ? AND deleted = 0";
        try (Connection conn = DBUtil.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, username);
            ResultSet rs = ps.executeQuery();
            if (rs.next()) {
                return mapRow(rs);
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return null;
    }

    @Override
    public List<User> findAll(String keyword) {
        List<User> list = new ArrayList<>();
        String sql = "SELECT * FROM users WHERE deleted = 0";

        // 模糊搜索：如果有关键词，添加到 SQL 条件中
        if (keyword != null && !keyword.trim().isEmpty()) {
            sql += " AND (username LIKE ? OR email LIKE ?)";
        }
        sql += " ORDER BY id DESC";

        try (Connection conn = DBUtil.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {

            if (keyword != null && !keyword.trim().isEmpty()) {
                String pattern = "%" + keyword.trim() + "%";
                ps.setString(1, pattern);
                ps.setString(2, pattern);
            }

            ResultSet rs = ps.executeQuery();
            while (rs.next()) {
                list.add(mapRow(rs));
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return list;
    }

    @Override
    public int update(User user) {
        String sql = "UPDATE users SET username=?, email=?, phone=? WHERE id=? AND deleted=0";
        try (Connection conn = DBUtil.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {

            ps.setString(1, user.getUsername());
            ps.setString(2, user.getEmail());
            ps.setString(3, user.getPhone());
            ps.setInt(4, user.getId());
            return ps.executeUpdate();  // 返回受影响行数
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return 0;
    }

    @Override
    public int deleteById(int id) {
        // 软删除：只改 deleted 标记，不真正删除数据
        String sql = "UPDATE users SET deleted = 1 WHERE id = ?";
        try (Connection conn = DBUtil.getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setInt(1, id);
            return ps.executeUpdate();
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return 0;
    }

    @Override
    public int count() {
        String sql = "SELECT COUNT(*) FROM users WHERE deleted = 0";
        try (Connection conn = DBUtil.getConnection();
             Statement stmt = conn.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {
            if (rs.next()) {
                return rs.getInt(1);
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
        return 0;
    }

    // ====== 辅助方法：把 ResultSet 一行数据映射为 User 对象 ======
    private User mapRow(ResultSet rs) throws SQLException {
        User user = new User();
        user.setId(rs.getInt("id"));
        user.setUsername(rs.getString("username"));
        user.setPassword(rs.getString("password"));
        user.setEmail(rs.getString("email"));
        user.setPhone(rs.getString("phone"));
        return user;
    }
}
```

### 3.4 Service 层：放业务逻辑

```java
package com.example.mvc.service;

import com.example.mvc.entity.User;
import java.util.*;

/**
 * 用户业务接口
 * 定义和 Controller 之间的"合同"——Controller 只管调这些方法
 */
public interface UserService {

    /** 注册用户，返回注册结果信息 */
    String register(User user);

    /** 用户登录，返回登录结果信息 */
    String login(String username, String password);

    /** 查询所有用户 */
    List<User> findAll(String keyword);

    /** 根据 ID 查询用户 */
    User findById(int id);

    /** 更新用户信息 */
    String update(User user);

    /** 删除用户 */
    String delete(int id);

    /** 获取总用户数 */
    int getTotalCount();
}
```

```java
package com.example.mvc.service.impl;

import com.example.mvc.dao.UserDao;
import com.example.mvc.dao.impl.UserDaoImpl;
import com.example.mvc.entity.User;
import com.example.mvc.service.UserService;
import java.util.*;

/**
 * 用户业务逻辑实现
 * 这里放的是真正的业务规则，不是 SQL、不是 HTTP 处理
 */
public class UserServiceImpl implements UserService {

    // ★ 通过接口引用 Dao，而不是直接 new 实现类
    //   这样以后要换数据库实现，只需要改这一行
    private final UserDao userDao = new UserDaoImpl();

    @Override
    public String register(User user) {
        // ====== 业务规则1：用户名不能为空 ======
        if (user.getUsername() == null || user.getUsername().trim().isEmpty()) {
            return "用户名不能为空";
        }

        // ====== 业务规则2：用户名长度必须在 3-20 之间 ======
        if (user.getUsername().length() < 3 || user.getUsername().length() > 20) {
            return "用户名长度必须在 3-20 个字符之间";
        }

        // ====== 业务规则3：密码不能太短 ======
        if (user.getPassword() == null || user.getPassword().length() < 6) {
            return "密码长度不能少于 6 位";
        }

        // ====== 业务规则4：用户名不能重复 ======
        User existUser = userDao.findByUsername(user.getUsername());
        if (existUser != null) {
            return "用户名已存在";
        }

        // ====== 业务规则5：密码加密（这里简化用 MD5，实际应用 BCrypt）======
        user.setPassword(md5(user.getPassword()));

        // ====== 调用 Dao 保存数据 ======
        int id = userDao.save(user);
        if (id > 0) {
            return "注册成功";
        } else {
            return "注册失败，请重试";
        }
    }

    @Override
    public String login(String username, String password) {
        // ====== 业务规则：查询用户 + 校验密码 ======
        User user = userDao.findByUsername(username);
        if (user == null) {
            return "用户不存在";
        }
        if (!user.getPassword().equals(md5(password))) {
            return "密码错误";
        }
        return "登录成功";
    }

    @Override
    public List<User> findAll(String keyword) {
        return userDao.findAll(keyword);
    }

    @Override
    public User findById(int id) {
        return userDao.findById(id);
    }

    @Override
    public String update(User user) {
        User existUser = userDao.findById(user.getId());
        if (existUser == null) {
            return "用户不存在";
        }
        // 检查新用户名是否被其他人占用
        User nameHolder = userDao.findByUsername(user.getUsername());
        if (nameHolder != null && nameHolder.getId() != user.getId()) {
            return "用户名已被占用";
        }
        int rows = userDao.update(user);
        return rows > 0 ? "更新成功" : "更新失败";
    }

    @Override
    public String delete(int id) {
        User existUser = userDao.findById(id);
        if (existUser == null) {
            return "用户不存在";
        }
        int rows = userDao.deleteById(id);
        return rows > 0 ? "删除成功" : "删除失败";
    }

    @Override
    public int getTotalCount() {
        return userDao.count();
    }

    // MD5 加密（简化版，生产环境请用 BCrypt）
    private String md5(String input) {
        try {
            java.security.MessageDigest md = java.security.MessageDigest.getInstance("MD5");
            byte[] digest = md.digest(input.getBytes("UTF-8"));
            StringBuilder sb = new StringBuilder();
            for (byte b : digest) {
                sb.append(String.format("%02x", b));
            }
            return sb.toString();
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }
}
```

### 3.5 Controller 层：对接 HTTP 请求

```java
package com.example.mvc.controller;

import com.example.mvc.entity.Result;
import com.example.mvc.entity.User;
import com.example.mvc.service.UserService;
import com.example.mvc.service.impl.UserServiceImpl;
import javax.servlet.*;
import javax.servlet.http.*;
import javax.servlet.annotation.*;
import java.io.*;
import java.util.*;

/**
 * 用户控制器 —— 处理来自前端的 HTTP 请求
 * 职责：获取参数 → 调用 Service → 返回响应
 * 不包含任何业务逻辑和 SQL！
 */
@WebServlet("/api/user/*")   // 所有 /api/user/* 的请求都进入这个 Servlet
public class UserController extends HttpServlet {

    // ★ Controller 依赖 Service 接口，不依赖具体实现
    private final UserService userService = new UserServiceImpl();

    @Override
    protected void service(HttpServletRequest req, HttpServletResponse resp)
            throws ServletException, IOException {
        // 统一设置编码和响应格式
        req.setCharacterEncoding("UTF-8");
        resp.setContentType("application/json;charset=UTF-8");

        // 简单路由：根据 PathInfo 分发
        String pathInfo = req.getPathInfo();  // 如 /list, /detail/1
        String method = req.getMethod();      // GET / POST / PUT / DELETE

        try {
            if ("/register".equals(pathInfo) && "POST".equals(method)) {
                handleRegister(req, resp);
            } else if ("/login".equals(pathInfo) && "POST".equals(method)) {
                handleLogin(req, resp);
            } else if ("/list".equals(pathInfo) && "GET".equals(method)) {
                handleList(req, resp);
            } else if ("/detail".equals(pathInfo) && "GET".equals(method)) {
                handleDetail(req, resp);
            } else if ("/update".equals(pathInfo) && "PUT".equals(method)) {
                handleUpdate(req, resp);
            } else if ("/delete".equals(pathInfo) && "DELETE".equals(method)) {
                handleDelete(req, resp);
            } else {
                writeJson(resp, Result.fail(404, "接口不存在"));
            }
        } catch (Exception e) {
            e.printStackTrace();
            writeJson(resp, Result.fail(500, "服务器内部错误：" + e.getMessage()));
        }
    }

    // ────────── ① 注册 ──────────
    private void handleRegister(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        String username = req.getParameter("username");
        String password = req.getParameter("password");
        String email = req.getParameter("email");
        String phone = req.getParameter("phone");

        User user = new User(username, password, email, phone);
        String result = userService.register(user);

        if ("注册成功".equals(result)) {
            writeJson(resp, Result.ok(result));
        } else {
            writeJson(resp, Result.fail(400, result));
        }
    }

    // ────────── ② 登录 ──────────
    private void handleLogin(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        String username = req.getParameter("username");
        String password = req.getParameter("password");

        String result = userService.login(username, password);

        if ("登录成功".equals(result)) {
            // 登录成功 → 创建 Session 保存用户信息
            req.getSession().setAttribute("username", username);
            writeJson(resp, Result.ok(result));
        } else {
            writeJson(resp, Result.fail(401, result));
        }
    }

    // ────────── ③ 查询列表（支持关键词搜索）──
    private void handleList(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        String keyword = req.getParameter("keyword");
        List<User> list = userService.findAll(keyword);

        Map<String, Object> data = new LinkedHashMap<>();
        data.put("total", list.size());
        data.put("list", list);
        writeJson(resp, Result.ok(data));
    }

    // ────────── ④ 查询详情 ──────────
    private void handleDetail(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        int id = Integer.parseInt(req.getParameter("id"));
        User user = userService.findById(id);

        if (user != null) {
            writeJson(resp, Result.ok(user));
        } else {
            writeJson(resp, Result.fail(404, "用户不存在"));
        }
    }

    // ────────── ⑤ 更新用户 ──────────
    private void handleUpdate(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        int id = Integer.parseInt(req.getParameter("id"));
        String username = req.getParameter("username");
        String email = req.getParameter("email");
        String phone = req.getParameter("phone");

        User user = new User();
        user.setId(id);
        user.setUsername(username);
        user.setEmail(email);
        user.setPhone(phone);

        String result = userService.update(user);
        if ("更新成功".equals(result)) {
            writeJson(resp, Result.ok(result));
        } else {
            writeJson(resp, Result.fail(400, result));
        }
    }

    // ────────── ⑥ 删除用户 ──────────
    private void handleDelete(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        int id = Integer.parseInt(req.getParameter("id"));
        String result = userService.delete(id);

        if ("删除成功".equals(result)) {
            writeJson(resp, Result.ok(result));
        } else {
            writeJson(resp, Result.fail(400, result));
        }
    }

    // ────────── 工具方法：输出 JSON ──────────
    private void writeJson(HttpServletResponse resp, Result result) throws IOException {
        // 简化版 JSON 输出（生产环境请用 Jackson/Gson）
        String json = String.format(
            "{\"code\":%d,\"message\":\"%s\",\"data\":%s}",
            result.getCode(),
            result.getMessage(),
            result.getData() != null ? result.getData().toString() : "null"
        );
        resp.getWriter().write(json);
    }
}
```

## 4. 依赖注入（IoC）的雏形

上面的代码中，Service 自己创建了 Dao 的实例：

```java
private final UserDao userDao = new UserDaoImpl();
```

这是一个简化写法。实际项目中使用 Spring 的 IoC 容器管理依赖：

```java
// Spring Boot 中的写法（概念对比）
@Service
public class UserServiceImpl implements UserService {
    @Autowired  // Spring 自动注入 UserDao 的实现
    private UserDao userDao;
    // 不需要 new UserDaoImpl()
}
```

> **核心思想是一样的**：
> - 面向接口编程（Controller 依赖 `UserService` 接口，不依赖 `UserServiceImpl`）
> - 依赖倒置（高层不依赖低层，两者都依赖抽象）
> - 在纯 Servlet 环境下，你手动 `new` 实现类（new UserDaoImpl()）
> - 在 Spring 环境下，容器帮你管理（@Autowired）

## 5. 分层的好处（实际项目体验）

| 好处 | 具体体现 |
|------|---------|
| **可维护性** | 改业务规则只改 Service，改 SQL 只改 Dao，互不影响 |
| **可测试性** | 可以 Mock Dao 来单独测试 Service 逻辑 |
| **可复用性** | 同一个 Service 可以给 Web Controller 用，也可以给定时任务用 |
| **可替换性** | 换数据库只需换 Dao 实现，Service 和 Controller 不需要动 |
| **团队协作** | 三个人可以分别写 Controller / Service / Dao，通过接口协商 |
| **符合 Spring Boot 习惯** | 你学的分层模式和 Spring Boot 项目结构完全对应 |

## 6. Spring Boot 项目的分层对应关系

你未来写 Spring Boot 时，这些知识直接映射：

| 纯 Servlet 项目 | Spring Boot 项目 | 职责 |
|----------------|-----------------|------|
| 手写路由分发 | `@RestController` + `@GetMapping` | 接收 HTTP 请求 |
| `req.getParameter("name")` | `@RequestParam String name` | 获取参数 |
| 手写 JSON 拼接 | `@RestController` 自动转 JSON | 输出响应 |
| `new UserServiceImpl()` | `@Service` + `@Autowired` | IoC 管理 |
| `new UserDaoImpl()` | `@Repository` + `@Autowired` | 依赖注入 |
| 手写 SQL + JDBC | MyBatis / JPA / JdbcTemplate | 数据访问 |

> **理解了纯 Servlet 的分层写法，你再看 Spring Boot 就知道框架替你省了哪些体力活，而不是一脸茫然**。

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ MVC = Controller + Service + Dao | Controller 接 HTTP，Service 管业务，Dao 管数据库 |
| ✅ 分层核心原则：上层依赖接口，不依赖实现 | `private UserService service = new UserServiceImpl();` |
| ✅ Controller 不能写 SQL 或复杂业务逻辑 | 它的唯一职责是：拿参数 → 调 Service → 返回响应 |
| ✅ Dao 不能写业务规则 | 它的唯一职责是：对数据库做 CRUD |
| ✅ Service 是业务的核心 | 所有"规则、校验、判断"都在这里 |
| ✅ 每层通过 Result 或异常与上层通信 | Controller 根据 Service 的返回决定返回什么状态码 |
