## 1. 「白话篇」Filter 是什么？

### 1.1 安检门的比喻

去机场坐飞机，你在登机口之前要经过一道**安检门**：

- 安检门检查你的行李（请求参数）
- 安检门确认你有登机牌（登录状态）
- 安检门可能让你脱掉外套（修改请求）
- 安检门可能拦下你（拒绝请求）

**Filter 就是那个安检门**——每个 HTTP 请求在到达 Servlet 之前，都要先经过 Filter：

```
请求来 → [Filter 1] → [Filter 2] → [Filter 3] → Servlet 处理
                                                        ↓
响应回 ← [Filter 1] ← [Filter 2] ← [Filter 3] ← Servlet 返回
```

> **白话**：Filter 是 Servlet 之前的"关卡"，你可以在这里干任何不想在每个 Servlet 里重复写的事——检查登录、处理乱码、记录日志、统计访问量。

### 1.2 不用 Filter 之前 vs 用了之后

```java
// ====== 不用 Filter：每个 Servlet 都要写一遍编码 ======
@WebServlet("/user")
public class UserServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) {
        req.setCharacterEncoding("UTF-8");  // 每个 Servlet 都要写
        resp.setContentType("text/html;charset=UTF-8"); // 每个都要写
        // 业务逻辑...
    }
}

@WebServlet("/order")
public class OrderServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) {
        req.setCharacterEncoding("UTF-8");  // 又写一遍
        resp.setContentType("text/html;charset=UTF-8"); // 又写一遍
        // 业务逻辑...
    }
}

// ====== 用了 Filter：写一次，全场生效 ======
@WebFilter("/*")  // 拦截所有请求
public class EncodingFilter implements Filter {
    public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain) {
        req.setCharacterEncoding("UTF-8");
        resp.setContentType("text/html;charset=UTF-8");
        chain.doFilter(req, resp);  // 放行，继续往后走
    }
}
// 所有 Servlet 都不用再写编码设置了！Filter 帮你统一做了。
```

## 2. Filter 完整详解

### 2.1 Filter 的核心接口

```java
public interface Filter {
    // ① init()：Filter 创建时调用一次
    default void init(FilterConfig filterConfig) throws ServletException {}

    // ② doFilter()：每次匹配的请求都会调用
    void doFilter(ServletRequest request, ServletResponse response,
                  FilterChain chain) throws IOException, ServletException;

    // ③ destroy()：Filter 销毁时调用一次
    default void destroy() {}
}
```

### 2.2 注解方式创建 Filter（推荐）

```java
import javax.servlet.*;
import javax.servlet.annotation.*;
import javax.servlet.http.*;
import java.io.*;

// @WebFilter 注解：声明这是一个 Filter
@WebFilter(
    filterName = "myFilter",        // Filter 名称
    urlPatterns = {"/api/*", "/user/*"},  // 拦截的 URL 模式
    initParams = {                          // 初始化参数
        @WebInitParam(name = "encoding", value = "UTF-8")
    }
)
public class MyFilter implements Filter {

    @Override
    public void init(FilterConfig config) throws ServletException {
        // Filter 初始化时调用一次
        String encoding = config.getInitParameter("encoding");
        System.out.println("MyFilter 初始化，编码：" + encoding);
    }

    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
                         FilterChain chain) throws IOException, ServletException {
        // ── 请求到达 Servlet 之前执行的代码 ──
        System.out.println("【MyFilter】请求到达，预处理...");

        // ※ 关键：调用 chain.doFilter() 把请求传给下一个 Filter 或 Servlet
        chain.doFilter(request, response);

        // ── Servlet 处理完，响应返回给浏览器之前执行的代码 ──
        System.out.println("【MyFilter】响应返回，后处理...");
    }

    @Override
    public void destroy() {
        System.out.println("MyFilter 销毁");
    }
}
```

### 2.3 XML 方式配置 Filter（老项目常见）

```xml
<filter>
    <filter-name>myFilter</filter-name>
    <filter-class>com.example.filter.MyFilter</filter-class>
    <init-param>
        <param-name>encoding</param-name>
        <param-value>UTF-8</param-value>
    </init-param>
</filter>
<filter-mapping>
    <filter-name>myFilter</filter-name>
    <url-pattern>/*</url-pattern>
    <!-- 匹配所有 URL -->
</filter-mapping>
```

### 2.4 Filter 执行链机制（面试重点）

> Filter 的执行是**洋葱模型**：请求一层一层穿透进去，响应一层一层返回出来。

```
请求 → [Filter-A 前] → [Filter-B 前] → [Filter-C 前] → Servlet
                                                            │
响应 ← [Filter-A 后] ← [Filter-B 后] ← [Filter-C 后] ←─────┘
```

**代码验证：**

```java
@WebFilter("/test")
public class FilterA implements Filter {
    public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain)
            throws IOException, ServletException {
        System.out.println("A → 请求到达");
        chain.doFilter(req, resp);   // 调用链上的下一个
        System.out.println("A ← 响应返回");
    }
}

@WebFilter("/test")
public class FilterB implements Filter {
    public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain)
            throws IOException, ServletException {
        System.out.println("  B → 请求到达");
        chain.doFilter(req, resp);
        System.out.println("  B ← 响应返回");
    }
}
// 输出：
// A → 请求到达
//   B → 请求到达        ← 请注意：A 的输出在 B 之前，请求穿透顺序
//   （Servlet 执行）
//   B ← 响应返回        ← 响应返回时 B 先处理
// A ← 响应返回
```

> ⚠️ **如果不调用 `chain.doFilter()`，请求会在此处中断，无法到达 Servlet！** 这是实现"拦截"的关键——条件不满足就不放行。

### 2.5 Filter 的拦截模式配置

```java
// 方式1：按 URL 路径拦截
@WebFilter("/user/*")        // 只拦截 /user/ 下的请求
@WebFilter("/api/order/*")  // 只拦截 /api/order/ 下的请求
@WebFilter("/*")            // 拦截所有请求

// 方式2：按 Servlet 名称拦截
@WebFilter(servletNames = {"UserServlet", "OrderServlet"})

// 方式3：按请求分派类型拦截
@WebFilter(
    value = "/*",
    dispatcherTypes = {
        DispatcherType.REQUEST,   // 直接请求（默认）
        DispatcherType.FORWARD,   // 转发
        DispatcherType.INCLUDE,   // 包含
        DispatcherType.ERROR,     // 错误页面
        DispatcherType.ASYNC      // 异步请求
    }
)
```

## 3. Filter 实战案例

### 3.1 实战一：全局中文乱码处理

```java
/**
 * 全站编码过滤器 —— 统一解决中文乱码问题
 * 拦截所有请求，设置请求和响应的字符编码
 */
@WebFilter("/*")
public class EncodingFilter implements Filter {

    private String encoding = "UTF-8";

    @Override
    public void init(FilterConfig config) {
        // 支持通过 web.xml 的 init-param 自定义编码
        String configEncoding = config.getInitParameter("encoding");
        if (configEncoding != null) {
            this.encoding = configEncoding;
        }
        System.out.println("EncodingFilter 初始化，编码：" + encoding);
    }

    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
                         FilterChain chain) throws IOException, ServletException {
        // 设置请求编码（处理 POST Body 中的中文）
        request.setCharacterEncoding(encoding);

        // 设置响应编码（处理返回内容中的中文）
        response.setContentType("text/html;charset=" + encoding);
        response.setCharacterEncoding(encoding);

        // ★ 放行，让请求继续往后走
        chain.doFilter(request, response);
    }

    @Override
    public void destroy() {}
}
```

### 3.2 实战二：登录状态校验 Filter

```java
/**
 * 登录检查过滤器 —— 拦截需要登录才能访问的页面
 * 如果用户没有登录（Session 中没有 username），重定向到登录页
 */
@WebFilter("/admin/*")   // 只拦截 /admin/ 下的内容
public class LoginCheckFilter extends HttpFilter {  // JDK 17 可直接用

    // 不需要登录就能访问的白名单
    private static final Set<String> WHITE_LIST = Set.of(
        "/admin/login.html",
        "/admin/api/login",
        "/admin/css/",
        "/admin/js/"
    );

    @Override
    public void doFilter(HttpServletRequest req, HttpServletResponse resp,
                         FilterChain chain) throws IOException, ServletException {

        String requestURI = req.getRequestURI();

        // ① 白名单放行（登录页、静态资源等）
        for (String white : WHITE_LIST) {
            if (requestURI.contains(white)) {
                chain.doFilter(req, resp);
                return;
            }
        }

        // ② 检查 Session 中是否有登录标记
        HttpSession session = req.getSession(false);
        if (session != null && session.getAttribute("username") != null) {
            // 已登录 → 放行
            chain.doFilter(req, resp);
        } else {
            // 未登录 → 重定向到登录页
            System.out.println("【登录拦截】未登录用户访问：" + requestURI);
            resp.sendRedirect(req.getContextPath() + "/admin/login.html");
        }
    }
}
```

### 3.3 实战三：访问日志记录 Filter

```java
/**
 * 访问日志过滤器 —— 记录每个请求的 URL、耗时、客户端 IP
 */
@WebFilter("/*")
public class AccessLogFilter implements Filter {

    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
                         FilterChain chain) throws IOException, ServletException {

        HttpServletRequest req = (HttpServletRequest) request;
        long start = System.currentTimeMillis();

        // ── 记录请求信息 ──
        String clientIP = getClientIP(req);
        String method = req.getMethod();
        String uri = req.getRequestURI();
        String queryString = req.getQueryString();

        System.out.printf("[%s] %s %s%s 来自 %s%n",
            new java.util.Date(), method, uri,
            queryString != null ? "?" + queryString : "", clientIP);

        try {
            chain.doFilter(request, response);
        } catch (Exception e) {
            System.out.println("【ERROR】请求处理异常：" + e.getMessage());
            throw e;
        } finally {
            // ── 记录响应耗时 ──
            long duration = System.currentTimeMillis() - start;
            System.out.printf("[%s] %s → 完成，耗时 %dms%n",
                new java.util.Date(), uri, duration);
        }
    }

    // 获取客户端真实 IP（处理代理场景）
    private String getClientIP(HttpServletRequest req) {
        String ip = req.getHeader("X-Forwarded-For");
        if (ip == null || ip.isEmpty()) {
            ip = req.getRemoteAddr();
        }
        return ip;
    }

    @Override
    public void init(FilterConfig config) {}
    @Override
    public void destroy() {}
}
```

### 3.4 实战四：敏感词过滤 —— 修改请求参数的 Filter

```java
/**
 * 敏感词过滤 —— 在请求到达 Servlet 之前，把请求参数中的敏感词替换掉
 * 需要包装 HttpServletRequest（装饰器模式）
 */
@WebFilter("/api/comment/*")
public class SensitiveWordFilter implements Filter {

    private static final String[] SENSITIVE_WORDS = {"fuck", "shit", "bitch"};

    @Override
    public void doFilter(ServletRequest request, ServletResponse response,
                         FilterChain chain) throws IOException, ServletException {

        // 用自定义的 Wrapper 包装原始 request
        // 这样后面的 Servlet 通过 getParameter() 拿到的就是过滤后的值
        HttpServletRequest wrappedRequest =
            new SensitiveWordRequestWrapper((HttpServletRequest) request);

        chain.doFilter(wrappedRequest, response);
    }
}

/**
 * 自定义 Request Wrapper —— 覆盖 getParameter() 方法
 * 扩展 HttpServletRequestWrapper（装饰器模式的便捷基类）
 */
class SensitiveWordRequestWrapper extends HttpServletRequestWrapper {

    public SensitiveWordRequestWrapper(HttpServletRequest request) {
        super(request);
    }

    @Override
    public String getParameter(String name) {
        String value = super.getParameter(name);
        if (value != null) {
            for (String word : SENSITIVE_WORDS) {
                value = value.replaceAll("(?i)" + word, "***");  // 忽略大小写替换
            }
        }
        return value;
    }
}
// 注：SensitiveWordRequestWrapper 中引用的 SENSITIVE_WORDS 数组
// 需要定义在 SensitiveWordFilter 中，或提取为常量类
```

> **关键技术点**：通过继承 `HttpServletRequestWrapper`，你可以修改 `getParameter()`、`getHeader()` 等方法的返回值，实现对请求的"透明修改"——后面的 Servlet 完全感知不到数据被改过。

## 4. Listener：监听器

### 4.1 什么是 Listener？

> **Listener（监听器）** 是观察者模式在 Servlet 中的实现。它监听 Servlet 容器中的特定事件，当事件发生时自动触发。

**生活类比**：
- 你去餐厅，服务员会在你进门时（事件）主动迎上来（监听器执行）
- 你不需要一直喊"我来了"，服务员也不需要一直盯着门口

### 4.2 八大监听器总览

| 类别 | 监听器接口 | 监听的事件 | 典型应用 |
|------|----------|-----------|---------|
| **ServletContext 生命周期** | `ServletContextListener` | 应用启动/销毁 | 初始化数据库连接池、加载全局配置 |
| **ServletContext 属性变更** | `ServletContextAttributeListener` | 属性添加/修改/删除 | 监控配置变化 |
| **HttpSession 生命周期** | `HttpSessionListener` | Session 创建/销毁 | 在线人数统计 |
| **HttpSession 属性变更** | `HttpSessionAttributeListener` | Session 中的属性变化 | 监控用户登录/登出 |
| **HttpSession 钝化/活化** | `HttpSessionActivationListener` | Session 持久化/恢复 | 分布式 Session 同步 |
| **HttpSession 绑定** | `HttpSessionBindingListener` | 对象绑定到 Session/从 Session 移除 | 对象级事件处理 |
| **ServletRequest 生命周期** | `ServletRequestListener` | 请求创建/销毁 | 请求耗时监控 |
| **ServletRequest 属性变更** | `ServletRequestAttributeListener` | 请求属性变化 | 调试、日志 |

### 4.4 实战二：在线人数统计 —— HttpSessionListener

```java
import javax.servlet.*;
import javax.servlet.http.*;
import javax.servlet.annotation.*;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * 在线人数统计监听器
 * Session 创建 → 人数 +1
 * Session 销毁 → 人数 -1
 */
@WebListener
public class OnlineCountListener implements HttpSessionListener {

    // 使用线程安全的原子计数器
    private static final AtomicInteger onlineCount = new AtomicInteger(0);

    /**
     * Session 创建时调用（用户首次访问网站）
     */
    @Override
    public void sessionCreated(HttpSessionEvent se) {
        int current = onlineCount.incrementAndGet();  // 原子自增
        System.out.println("【在线人数】+1，当前在线：" + current);

        // 将在线人数存入 ServletContext，所有 Servlet 都能获取
        se.getSession().getServletContext()
            .setAttribute("onlineCount", current);
    }

    /**
     * Session 销毁时调用（用户超时退出 或 手动 invalidate）
     */
    @Override
    public void sessionDestroyed(HttpSessionEvent se) {
        int current = onlineCount.decrementAndGet();  // 原子自减
        System.out.println("【在线人数】-1，当前在线：" + current);

        se.getSession().getServletContext()
            .setAttribute("onlineCount", current);
    }

    /** 获取当前在线人数 */
    public static int getOnlineCount() {
        return onlineCount.get();
    }
}

// ====== 使用示例：在 JSP 或 Servlet 中显示在线人数 ======
@WebServlet("/stats")
public class StatsServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws IOException {
        resp.setContentType("text/html;charset=UTF-8");
        Integer count = (Integer) getServletContext().getAttribute("onlineCount");
        resp.getWriter().write("<h2>当前在线人数：" +
            (count != null ? count : 0) + "</h2>");
    }
}
```

/**

@WebListener
public class SessionAttributeLogger implements HttpSessionAttributeListener {

        }

     * 属性被移除时触发

    @Override

        }
    }

    /**
     * 属性被修改时触发
     */
    @Override
    public void attributeReplaced(HttpSessionBindingEvent event) {
        System.out.println("Session 属性被修改：" + event.getName());
    }
}

### 4.6 实战四：请求耗时监控 —— ServletRequestListener

```java
/**
 * 请求级别监听器 —— 记录每次请求的开始和结束，计算耗时
 */
@WebListener
public class RequestTimingListener implements ServletRequestListener {

    // 用 ThreadLocal 存储请求开始时间（线程安全）
    private static final ThreadLocal<Long> START_TIME = new ThreadLocal<>();

    @Override
    public void requestInitialized(ServletRequestEvent sre) {
        // 请求到达时记录时间
        START_TIME.set(System.currentTimeMillis());
    }

    @Override
    public void requestDestroyed(ServletRequestEvent sre) {
        // 请求处理完毕时计算耗时
        Long start = START_TIME.get();
        if (start != null) {
            long duration = System.currentTimeMillis() - start;
            HttpServletRequest req = (HttpServletRequest) sre.getServletRequest();
            System.out.printf("【请求耗时】%s %s → %dms%n",
                req.getMethod(), req.getRequestURI(), duration);
            START_TIME.remove();  // 防止内存泄漏
        }
    }
}
```

## 5. Filter 在实际框架中的对应关系

你学 Filter 不是白学的——这些知识在 Spring 框架中直接对应：

| 纯 Servlet Filter | Spring 对应 | 说明 |
|-------------------|------------|------|
| `LoginCheckFilter` | Spring Security 的 `SecurityFilterChain` | 认证/授权拦截 |
| `EncodingFilter` | Spring MVC 的 `CharacterEncodingFilter` | 编码处理 |
| `AccessLogFilter` | Spring MVC 的 `HandlerInterceptor` | 访问日志 |
| `CorsFilter` | Spring MVC 的 `@CrossOrigin` / `CorsFilter` | 跨域处理 |
| `XssFilter` | Spring Security 的 `XssFilter` | XSS 防护 |
| `AppStartupListener` | Spring Boot 的 `ApplicationRunner` / `CommandLineRunner` | 启动初始化 |

> Spring MVC 的 `DispatcherServlet` 之前也挂了一堆 Filter：
> ```
> Request → CharacterEncodingFilter → CorsFilter → SecurityFilterChain
>         → DispatcherServlet → Controller
> ```

---

## 6. Filter vs Interceptor vs Listener 区别

| 对比维度 | Filter | Interceptor (Spring) | Listener |
|---------|--------|---------------------|----------|
| **规范** | Servlet 规范 | Spring 框架特有 | Servlet 规范 |
| **作用范围** | 所有请求 | 只拦截进入 DispatcherServlet 的请求 | 监听事件，不拦截请求 |
| **能获取 Spring Bean？** | ❌ 不能（除非用特殊方式） | ✅ 可以 | ❌ 不能 |
| **能处理请求/响应？** | ✅ 可以修改请求和响应 | ✅ 可以（preHandle/postHandle） | ❌ 只监听事件 |
| **执行顺序** | Filter → Servlet | Filter → DispatcherServlet → Interceptor → Controller | 事件发生时 |

---

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ Filter 是 Servlet 之前的"安检门" | 拦截请求→预处理→放行或拦截 |
| ✅ Filter 执行是洋葱模型 | 请求穿透进、响应逐层出 |
| ✅ `chain.doFilter()` 不调用 = 拦截 | 请求不会到达 Servlet |
| ✅ Filter 最常见的用途 | 编码、登录检查、日志、CORS、XSS 防护 |
| ✅ ServletContextListener = 应用启动入口 | 初始化连接池、配置等全局资源 |
| ✅ HttpSessionListener = 在线人数 | Session 创建 +1，销毁 -1 |
| ✅ 这些知识在 Spring 中直接对应 | Spring Security / Interceptor 底层就是 Filter |
