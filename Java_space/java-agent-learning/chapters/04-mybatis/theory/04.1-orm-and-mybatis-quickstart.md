## 1. ORM 是什么？为什么需要它？

### 白话理解

回顾第三章，你用 JDBC 写一次查询要做这些事：

```
① 加载驱动    ② 建立连接    ③ 写 SQL    ④ 设置参数
⑤ 执行查询    ⑥ 逐行取结果   ⑦ 手动封装成 Java 对象   ⑧ 关闭连接
```

其中 **第 6、7 步最烦人**：数据库返回一行行的数据，你要手动 `rs.getString("name")` 一条条取出来，再 `new User()` 塞进去。查 10 个字段就要写 10 行。

**ORM（对象关系映射）** 就是帮你干这件事的"翻译官"：

```
数据库表的一行记录  ←→  Java 的一个对象
  users 表 id=1    ←→  User(id=1, name="张三")
```

**MyBatis 就是 Java 最流行的 ORM 框架之一**。你只需要告诉它：
- **SQL 怎么写**（还是你自己写，MyBatis 不帮你生成 SQL）
- **结果怎么映射**（哪一列对应对象的哪个属性）

它自动完成参数设置和结果封装，让你告别 JDBC 重复代码。

## 2. MyBatis 的架构：两个核心对象

### 白话理解

```
mybatis-config.xml（总配置文件）
        │
        ▼
SqlSessionFactoryBuilder（建造工）
        │
        ▼
SqlSessionFactory（工厂）
        │ 每次操作 → openSession()
        ▼
SqlSession（干活的人 = 数据库会话）
        │
        ├─ 执行 SQL（selectOne / selectList / insert ...）
        ├─ commit() 提交事务
        └─ close() 关闭会话
```

| 对象 | 白话理解 | 特点 |
|------|---------|------|
| **SqlSessionFactory** | 工厂，负责生产"会话" | 整个程序**只创建一次**（重量级，线程安全） |
| **SqlSession** | 一次数据库会话，像 JDBC 里的一个 Connection | **用完就关**（轻量级，线程不安全，不能共享） |

### 技术要点

- `SqlSessionFactory` 通过读取 `mybatis-config.xml` 创建
- 一个应用只建一个 Factory，放工具类里
- 每次操作数据库，从 Factory 拿一个新的 Session，用完 `close()`

## 3. 搭建最小项目

### 3.1 Maven 依赖

```xml
<dependencies>
    <dependency>
        <groupId>org.mybatis</groupId>
        <artifactId>mybatis</artifactId>
        <version>3.5.16</version>
    </dependency>
    <dependency>
        <groupId>mysql</groupId>
        <artifactId>mysql-connector-java</artifactId>
        <version>8.0.33</version>
    </dependency>
</dependencies>
```

### 3.2 全局配置文件 mybatis-config.xml

放在 `src/main/resources` 下：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE configuration PUBLIC
    "-//mybatis.org//DTD Config 3.0//EN"
    "http://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>

    <!-- 环境：这里配置连接 MySQL 所需的一切 -->
    <environments default="development">
        <environment id="development">
            <transactionManager type="JDBC"/>
            <dataSource type="POOLED">
                <property name="driver" value="com.mysql.cj.jdbc.Driver"/>
                <property name="url" value="jdbc:mysql://localhost:3306/agent_learn?useSSL=false&amp;serverTimezone=Asia/Shanghai"/>
                <property name="username" value="root"/>
                <property name="password" value="123456"/>
            </dataSource>
        </environment>
    </environments>

    <!-- 注册 Mapper 文件（后面章节补充） -->
    <mappers>
        <mapper resource="mapper/UserMapper.xml"/>
    </mappers>

</configuration>
```

> **注意**：XML 中 `&` 要写成 `&amp;`，所以 URL 里是 `useSSL=false&amp;serverTimezone=...`

### 3.3 SqlSessionFactory 工具类

```java
public class MyBatisUtil {
    private static final SqlSessionFactory FACTORY;

    static {
        // 从类路径读取配置文件，构建工厂（只做一次）
        String resource = "mybatis-config.xml";
        try (InputStream in = Resources.getResourceAsStream(resource)) {
            FACTORY = new SqlSessionFactoryBuilder().build(in);
        } catch (IOException e) {
            throw new RuntimeException("初始化 MyBatis 失败", e);
        }
    }

    // 每次调用获取一个新的会话
    public static SqlSession openSession() {
        return FACTORY.openSession();
    }
}
```

## 4. 第一个查询（完整走一遍）

### 4.1 实体类

```java
public class User {
    private Integer id;
    private String username;
    private String password;
    private String email;

    // 必须有无参构造 + 每个字段的 getter/setter（MyBatis 靠它做映射）
    public User() {}

    public Integer getId() { return id; }
    public void setId(Integer id) { this.id = id; }
    public String getUsername() { return username; }
    public void setUsername(String username) { this.username = username; }
    public String getPassword() { return password; }
    public void setPassword(String password) { this.password = password; }
    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }

    @Override
    public String toString() {
        return "User{id=" + id + ", username='" + username + "'}";
    }
}
```

### 4.2 映射文件 mapper/UserMapper.xml

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC
    "-//mybatis.org//DTD Mapper 3.0//EN"
    "http://mybatis.org/dtd/mybatis-3-mapper.dtd">

<!-- namespace：命名空间，必须唯一（通常用接口全类名） -->
<mapper namespace="userMapper">

    <!-- id：这条 SQL 的唯一名字；resultType：结果自动封装成 User -->
    <select id="findById" parameterType="int" resultType="User">
        SELECT id, username, password, email
        FROM users
        WHERE id = #{id}
    </select>

</mapper>
```

### 4.3 main 方法运行

```java
public class Main {
    public static void main(String[] args) {
        // 1. 获取会话
        try (SqlSession session = MyBatisUtil.openSession()) {

            // 2. 执行 SQL：namespace + "." + id 定位到那条 SQL
            User user = session.selectOne("userMapper.findById", 1);

            // 3. 使用结果（MyBatis 已自动封装成 User 对象）
            System.out.println(user);
        }
    }
}
```

**运行结果：**

```
User{id=1, username='admin'}
```

> 对比 JDBC：你只需要写 SQL + 调用一句话，连接管理、参数设置、结果封装全部由 MyBatis 完成。

## 5. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ ORM = 数据库行 ↔ Java 对象 自动映射 | 告别手写 ResultSet 取值 |
| ✅ SqlSessionFactory 全局唯一 | 程序启动时创建一次 |
| ✅ SqlSession = 一次数据库会话 | 用完必须 close() |
| ✅ 定位 SQL 用 `namespace.id` | 如 `userMapper.findById` |
| ✅ `resultType="User"` 自动封装 | 列名与属性名一致时最简单 |
