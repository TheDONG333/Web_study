# 04.4 动态 SQL：<if> <where> <foreach> <choose>

> **学习目标**
> - 理解为什么需要动态 SQL
> - 掌握 if / where / foreach / choose 四种标签
> - 能写出条件查询和批量插入

---

## 1. 什么是动态 SQL？为什么需要？

### 白话理解

条件查询的场景：用户可能只填用户名、也可能填用户名+邮箱、还可能什么都不填。SQL 的 WHERE 条件**不固定**。

没有动态 SQL 时，你只能拼字符串（易错、注入风险）：

```java
String sql = "SELECT * FROM users WHERE 1=1";
if (name != null) sql += " AND username = '" + name + "'";
```

**动态 SQL 就是让 SQL 标签可以根据条件"长出来"**——条件满足，这段 SQL 就拼上；不满足就不拼。

```
用户传了 name → SELECT * FROM users WHERE username = '张三'
用户传了 name + email → SELECT * FROM users WHERE username = '张三' AND email = 'x@y.com'
什么都没传 → SELECT * FROM users
```

---

## 2. <if>：条件判断

### 白话理解

`<if test="条件">` 里的条件成立，标签内的 SQL 片段才拼进去。

```xml
<select id="search" parameterType="map" resultType="User">
    SELECT * FROM users
    WHERE 1 = 1
    <if test="username != null and username != ''">
        AND username = #{username}
    </if>
    <if test="email != null and email != ''">
        AND email = #{email}
    </if>
</select>
```

**为什么要有 `WHERE 1=1`？** 防止"只有一个条件成立"时出现 `WHERE AND ...` 的语法错误。下面用 `<where>` 解决得更优雅。

---

## 3. <where>：自动处理 WHERE 和 AND

### 白话理解

`<where>` 标签是 `<if>` 的最佳搭档：它**自动**判断——有条件成立就拼 WHERE，并**自动去掉**第一个条件多余的 AND。

```xml
<select id="search" parameterType="map" resultType="User">
    SELECT * FROM users
    <where>
        <if test="username != null and username != ''">
            AND username = #{username}
        </if>
        <if test="email != null and email != ''">
            AND email = #{email}
        </if>
    </where>
</select>
```

| 传入参数 | 生成的 SQL |
|---------|-----------|
| 都不传 | `SELECT * FROM users`（没有 WHERE） |
| 只传 username | `SELECT * FROM users WHERE username = ?`（AND 被自动去掉） |
| 两个都传 | `SELECT * FROM users WHERE username = ? AND email = ?` |

> 这就是实际开发中最常用的"**条件查询**"写法，请重点掌握。

---

## 4. <foreach>：批量操作

### 白话理解

处理"传一个集合"的场景，比如批量插入、IN 查询。`<foreach>` 负责把集合里的每个元素**循环拼**出来。

```xml
<!-- 批量插入：VALUES 后面循环拼多组 -->
<insert id="batchInsert" parameterType="list">
    INSERT INTO users (username, password)
    VALUES
    <foreach collection="list" item="user" separator=",">
        (#{user.username}, #{user.password})
    </foreach>
</insert>
```

```xml
<!-- IN 查询 -->
<select id="findByIds" parameterType="list" resultType="User">
    SELECT * FROM users
    WHERE id IN
    <foreach collection="list" item="id" open="(" close=")" separator=",">
        #{id}
    </foreach>
</select>
```

### foreach 属性说明

| 属性 | 作用 |
|------|------|
| `collection` | 集合名。传 List 写 `list`，传数组写 `array` |
| `item` | 循环变量名，循环体里用 `#{item}` 取当前元素 |
| `separator` | 元素之间的分隔符（如 `,`） |
| `open` / `close` | 整个循环外包的符号（如 `(` 和 `)`） |

**Java 调用：**

```java
List<User> users = List.of(
    new User("user1", "123456"),
    new User("user2", "123456")
);
int rows = session.insert("userMapper.batchInsert", users);
session.commit();
```

## 5. <choose>：多选一（类似 if-else if-else）

### 白话理解

`<if>` 是"每个条件都独立判断，可多个同时生效"；`<choose>` 是"从上到下，**只选第一个成立**的"，类似 Java 的 if-else if-else。

```xml
<select id="findByCondition" resultType="User">
    SELECT * FROM users
    <where>
        <choose>
            <when test="username != null">
                AND username = #{username}
            </when>
            <when test="email != null">
                AND email = #{email}
            </when>
            <otherwise>
                AND id > 0
            </otherwise>
        </choose>
    </where>
</select>
```

| 传入参数 | 结果 |
|---------|------|
| 传 username | 按 username 查（email 条件被跳过） |
| 不传 username 传 email | 按 email 查 |
| 都不传 | 走 `<otherwise>`：查出所有 |

---

## 6. 四个标签速查

| 标签 | 白话 | 对应 Java | 典型场景 |
|------|------|----------|---------|
| `<if>` | 条件成立就拼 | if | 每个条件独立判断 |
| `<where>` | 自动管 WHERE/AND | — | 条件查询（最常用） |
| `<foreach>` | 循环拼接 | for | 批量插入、IN 查询 |
| `<choose>` | 多选一 | if-else if-else | 优先级条件 |

---

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 动态 SQL = 根据条件动态生成 SQL | 解决"条件不固定"的问题 |
| ✅ `<where>` + `<if>` 是最常用的组合 | 条件查询必备 |
| ✅ `<foreach>` 传集合时 collection 写 `list`/`array` | 批量插入、IN 查询 |
| ✅ `<choose>` 只选第一个成立的条件 | 与 `<if>` 的区别就在这 |
