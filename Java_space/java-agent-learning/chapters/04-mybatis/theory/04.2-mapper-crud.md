# 04.2 mapper.xml：增删改查与参数/结果映射

> **学习目标**
> - 会用 mapper.xml 写 select / insert / update / delete
> - 理解 parameterType、resultType、resultMap 的区别与用法
> - 掌握新增时取回自增主键

---

## 1. mapper.xml 的作用

### 白话理解

mapper.xml 是你告诉 MyBatis"**每条 SQL 长什么样、参数怎么传、结果怎么映射**"的地方。

```
你的 Java 代码（SqlSession.insert("xxx", user)）
        │
        ▼
mapper.xml 中的 <insert id="xxx"> ← 在这里定义 SQL
        │
        ▼
数据库执行
```

### 技术要点

- 四个标签对应四个操作：`<select>`、`<insert>`、`<update>`、`<delete>`
- 每个标签必须有 `id`（唯一标识）
- `namespace` 通常是 Mapper 接口的全限定类名（后面学了接口就知道了）

---

## 2. 查询：select + resultType

### 白话理解

resultType 告诉 MyBatis："查询结果每行数据，自动封装成这个类型"。列名和属性名**一致时直接匹配**。

```xml
<mapper namespace="userMapper">

    <!-- 返回单个对象 -->
    <select id="findById" parameterType="int" resultType="User">
        SELECT id, username, password, email
        FROM users
        WHERE id = #{id}
    </select>

    <!-- 返回列表：resultType 写集合里的元素类型，MyBatis 自动装成 List -->
    <select id="findAll" resultType="User">
        SELECT id, username, password, email FROM users
    </select>

    <!-- 返回单个值（如数量） -->
    <select id="count" resultType="int">
        SELECT COUNT(*) FROM users
    </select>

</mapper>
```

**Java 调用：**

```java
User user = session.selectOne("userMapper.findById", 1);
List<User> list = session.selectList("userMapper.findAll");
int total = session.selectOne("userMapper.count");
```

| 返回情况 | 用哪个方法 |
|---------|-----------|
| 单条记录 | `selectOne` |
| 多条记录 | `selectList` |
| 单个值（int/String） | `selectOne`（resultType 写 int/String） |

## 3. 新增：insert + 取回自增主键

### 白话理解

插入后常常马上需要拿到"刚插入的 id"（比如插入订单后要关联订单明细）。`useGeneratedKeys` 就是让数据库把自增 id 回填给你。

```xml
<mapper namespace="userMapper">

    <!-- useGeneratedKeys: 使用数据库自增主键 -->
    <!-- keyProperty: 自增 id 回填到 User 对象的哪个属性 -->
    <insert id="insert" parameterType="User"
            useGeneratedKeys="true" keyProperty="id">
        INSERT INTO users (username, password, email)
        VALUES (#{username}, #{password}, #{email})
    </insert>

</mapper>
```

**Java 调用：**

```java
User user = new User("test", "123456", "test@example.com");

int rows = session.insert("userMapper.insert", user);

// 注意：参数传的是对象，insert 后 id 被自动回填
System.out.println("影响行数: " + rows);
System.out.println("新用户 id: " + user.getId());
```

**关键点**：`#{username}` 表示"取出 User 对象的 username 属性"。你传一个对象，XML 里就能用 `#{}` 取它的任何属性。

## 4. 更新与删除

```xml
<mapper namespace="userMapper">

    <update id="update" parameterType="User">
        UPDATE users
        SET username = #{username},
            email = #{email}
        WHERE id = #{id}
    </update>

    <delete id="deleteById" parameterType="int">
        DELETE FROM users WHERE id = #{id}
    </delete>

</mapper>
```

**Java 调用：**

```java
// 更新：返回受影响行数
int rows = session.update("userMapper.update", user);

// 删除
int rows2 = session.delete("userMapper.deleteById", 5);

// ⚠️ 增删改默认不自动提交！必须手动 commit
session.commit();
```

> **新手最容易忘**：insert / update / delete 之后要调 `session.commit()`，否则数据没有真正写进数据库。（select 不需要）

## 5. resultMap：列名和属性名对不上时

### 白话理解

resultType 要求列名和属性名**完全一致**才能自动匹配。但数据库常用下划线（`user_name`），Java 属性常用驼峰（`userName`）。名字对不上时，用 resultMap 手动指定"哪一列 → 哪个属性"。

```xml
<mapper namespace="userMapper">

    <!-- 手动指定映射关系：column 是数据库列名，property 是 Java 属性名 -->
    <resultMap id="userMap" type="User">
        <id     column="id"        property="id"/>
        <result column="user_name" property="userName"/>
        <result column="password"  property="password"/>
        <result column="email"     property="email"/>
    </resultMap>

    <!-- resultMap="userMap" 代替 resultType="User" -->
    <select id="findById2" parameterType="int" resultMap="userMap">
        SELECT id, user_name, password, email FROM users WHERE id = #{id}
    </select>

</mapper>
```

### resultType vs resultMap 对比

| 对比 | resultType | resultMap |
|------|-----------|-----------|
| 用途 | 列名和属性名一致时 | 列名和属性名不一致时 |
| 写法 | 一行搞定 | 需要额外定义映射 |
| 复杂映射（关联查询） | 不支持 | 支持（后续章节） |
| 使用频率 | 简单查询常用 | 复杂查询、关联查询必用 |

> 也可以开全局驼峰映射：`<settings><setting name="mapUnderscoreToCamelCase" value="true"/></settings>`，`user_name` 自动映射到 `userName`，省去手写 resultMap。

## 6. 参数传入的几种方式

| 传入方式 | XML 中写法 | 适用场景 |
|---------|-----------|---------|
| 单个值 | `#{任意名字}` | 只传一个参数（int、String） |
| 对象 | `#{属性名}` | 传 User 等实体对象 |
| Map | `#{key}` | 多个无关参数（如查询条件） |

```xml
<!-- Map 传参示例 -->
<select id="search" parameterType="map" resultType="User">
    SELECT * FROM users
    WHERE username = #{name} AND email = #{mail}
</select>
```

```java
Map<String, Object> params = new HashMap<>();
params.put("name", "admin");
params.put("mail", "admin@example.com");

List<User> list = session.selectList("userMapper.search", params);
```

---

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 四个标签：select / insert / update / delete | 每个都有唯一 id |
| ✅ `#{属性名}` 从传入对象中取值 | 传对象时用对象属性，传 Map 时用 key |
| ✅ 单条 selectOne / 多条 selectList | resultType 写元素类型 |
| ✅ 增删改后必须 `session.commit()` | 否则不生效 |
| ✅ 列名对不上用 resultMap | 或开 mapUnderscoreToCamelCase |
| ✅ 插入要回填主键 | useGeneratedKeys + keyProperty |
