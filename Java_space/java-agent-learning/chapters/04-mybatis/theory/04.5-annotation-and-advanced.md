# 04.5 注解开发与进阶：关联查询、分页、日志

> **学习目标**
> - 了解注解开发 @Select / @Insert（工作以 XML 为主）
> - 掌握一对一、一对多关联查询的基础用法
> - 会配置分页和 SQL 日志打印

---

## 1. 注解开发（了解即可）

### 白话理解

注解开发 = 把 SQL 直接写在 Java 接口的方法上，省去 mapper.xml。**适合简单 SQL，复杂 SQL（动态 SQL）还是要用 XML**。实际工作以 XML 为主，注解了解即可。

```java
public interface UserMapper {

    @Select("SELECT * FROM users WHERE id = #{id}")
    User findById(int id);

    @Insert("INSERT INTO users (username, password) VALUES (#{username}, #{password})")
    int insert(User user);
}
```

**Java 调用：**

```java
// 通过接口调用（需要先注册接口）
UserMapper mapper = session.getMapper(UserMapper.class);
User user = mapper.findById(1);
```

> 接口方式调用（`session.getMapper()`）比字符串定位（`"userMapper.findById"`）更规范、类型安全，是主流用法。XML 文件同样可以用接口：`namespace` 写接口全类名 + 方法名和 id 一致即可。

## 2. 一对一关联查询

### 场景

订单表里有个 `user_id` 外键。查订单时要**顺便查出下单的用户**——一个订单对应一个用户。

### 实体类

```java
public class Order {
    private Integer id;
    private String orderNo;
    private Integer userId;
    private User user;   // 关联的用户对象

    // getter/setter 省略
}
```

### 用 resultMap + association 实现

```xml
<resultMap id="orderMap" type="Order">
    <id     column="id"       property="id"/>
    <result column="order_no" property="orderNo"/>

    <!-- association：一对一关联。property 填实体里的对象属性 -->
    <association property="user" javaType="User">
        <id     column="uid"        property="id"/>
        <result column="username"   property="username"/>
    </association>
</resultMap>

<select id="findOrderWithUser" resultMap="orderMap">
    SELECT o.id, o.order_no, u.id AS uid, u.username
    FROM orders o
    JOIN users u ON o.user_id = u.id
    WHERE o.id = #{id}
</select>
```

### 白话理解

- SQL 用 JOIN 查出两张表的字段
- `association` 告诉 MyBatis："查出来的 uid、username 这几列，封装成 Order 里的 user 对象"
- **关键**：SQL 里的列名要用 `AS` 起别名（`u.id AS uid`），避免和订单表的 `id` 冲突

## 3. 一对多关联查询

### 场景

查一个用户，顺便查出**他下的所有订单**——一个用户对应多个订单。

### 实体类

```java
public class User {
    private Integer id;
    private String username;
    private List<Order> orders;   // 关联的订单列表

    // getter/setter 省略
}
```

### 用 resultMap + collection 实现

```xml
<resultMap id="userMap" type="User">
    <id     column="id"       property="id"/>
    <result column="username" property="username"/>

    <!-- collection：一对多关联。ofType 写集合元素类型 -->
    <collection property="orders" ofType="Order">
        <id     column="oid"      property="id"/>
        <result column="order_no" property="orderNo"/>
    </collection>
</resultMap>

<select id="findUserWithOrders" resultMap="userMap">
    SELECT u.id, u.username, o.id AS oid, o.order_no
    FROM users u
    LEFT JOIN orders o ON o.user_id = u.id
    WHERE u.id = #{id}
</select>
```

### association vs collection 对比

| 对比 | association | collection |
|------|-------------|-----------|
| 关系 | 一对一 | 一对多 |
| 封装结果 | 一个对象 | 一个 List |
| 属性 | `javaType`（对象类型） | `ofType`（元素类型） |

> **学习建议**：能看懂上面的写法即可（"掌握基础"）。MyBatis 复杂关联查询实际开发中常配合分页、懒加载等，等用到再深入。

## 4. 分页查询

### 白话理解

数据量大时不能一次全查出来（比如 100 万条）。分页 = 一次只取一页，比如第 1 页取 10 条。

### 方式一：手写 LIMIT（简单，推荐入门）

```xml
<select id="findByPage" parameterType="map" resultType="User">
    SELECT * FROM users
    LIMIT #{offset}, #{limit}
</select>
```

```java
int page = 2;      // 第 2 页
int pageSize = 10; // 每页 10 条
int offset = (page - 1) * pageSize;  // 偏移量 = 10

Map<String, Object> params = Map.of("offset", offset, "limit", pageSize);
List<User> list = session.selectList("userMapper.findByPage", params);
```

### 方式二：PageHelper 插件（工作中常用，了解）

```xml
<dependency>
    <groupId>com.github.pagehelper</groupId>
    <artifactId>pagehelper</artifactId>
    <version>5.3.3</version>
</dependency>
```

```java
// 调用前设置分页，PageHelper 自动给下一条 SQL 加 LIMIT
PageHelper.startPage(2, 10);
List<User> list = session.selectList("userMapper.findAll");

// PageInfo 包含总条数、总页数等信息
PageInfo<User> info = new PageInfo<>(list);
System.out.println("总条数: " + info.getTotal());
```

## 5. 日志：打印 SQL（开发必备）

### 白话理解

开发时看不到 SQL 很难调试。配置日志后，MyBatis 会把执行的 SQL 和参数**打印到控制台**。

### 配置 log4j（推荐）

**第一步**：pom.xml 加依赖：

```xml
<dependency>
    <groupId>log4j</groupId>
    <artifactId>log4j</artifactId>
    <version>1.2.17</version>
</dependency>
```

**第二步**：resources 下建 `log4j.properties`：

```properties
log4j.rootLogger=DEBUG, stdout

log4j.appender.stdout=org.apache.log4j.ConsoleAppender
log4j.appender.stdout.layout=org.apache.log4j.PatternLayout
log4j.appender.stdout.layout.ConversionPattern=%m%n
```

**第三步**：mybatis-config.xml 中开启：

```xml
<settings>
    <!-- 日志实现：log4j；也可用 STDOUT_LOGGING（控制台） -->
    <setting name="logImpl" value="STDOUT_LOGGING"/>
</settings>
```

**运行后控制台输出：**

```
==>  Preparing: SELECT * FROM users WHERE id = ?
==> Parameters: 1(Integer)
<==    Columns: id, username, password, email
<==        Row: 1, admin, e10adc39, admin@example.com
<==      Total: 1
```

> 能看到：执行的 SQL（参数是 `?`）、传入的参数、查询结果。这就是你调试 SQL 的眼睛。

## 6. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 注解 @Select/@Insert 了解即可 | 工作以 XML 为主 |
| ✅ association = 一对一，collection = 一对多 | 复杂映射用 resultMap |
| ✅ 关联查询列名冲突用 `AS` 起别名 | `u.id AS uid` |
| ✅ 分页入门先写 LIMIT | 工作用 PageHelper |
| ✅ 配置 log4j 打印 SQL | 开发调试必备 |
