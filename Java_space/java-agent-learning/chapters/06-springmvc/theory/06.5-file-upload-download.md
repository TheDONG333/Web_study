# 06.5 文件上传与下载

> **学习目标**
> - 掌握 MultipartFile 接收上传文件
> - 掌握文件下载的两种写法
> - 理解文件上传的配置要求

---

## 1. 文件上传

### 白话理解

前端提交文件时要用 `multipart/form-data` 格式（回忆 01.2 的 MIME 类型）。SpringMVC 用 `MultipartFile` 对象接住文件，你只需要保存到磁盘。

### 前端表单

```html
<!-- 必须：enctype="multipart/form-data" + type="file" -->
<form action="/demo/upload" method="post" enctype="multipart/form-data">
    <input type="text" name="username" placeholder="上传者">
    <input type="file" name="file">
    <button type="submit">上传</button>
</form>
```

### 后端接收

```java
@RestController
public class FileController {

    @PostMapping("/upload")
    public Result upload(@RequestParam("username") String username,
                         @RequestParam("file") MultipartFile file) throws IOException {
        // ① 获取文件信息
        String originalName = file.getOriginalFilename();  // 原始文件名
        long size = file.getSize();                        // 文件大小

        // ② 保存到指定目录（文件名用时间戳防重名）
        String saveDir = "D:/uploads/";
        String saveName = System.currentTimeMillis() + "_" + originalName;
        file.transferTo(new File(saveDir + saveName));     // 一行保存到磁盘！

        return Result.ok("上传成功: " + originalName + " (" + size + " 字节)");
    }
}
```

### 技术要点

- 参数类型 `MultipartFile`，`@RequestParam("file")` 对应表单里 file 的名字
- `file.transferTo(File)` 保存文件
- 文件名用时间戳 + 原文件名拼接，防止不同用户上传同名文件互相覆盖

### 配置文件上传大小限制（springmvc.xml 或配置类）

```xml
<!-- 上传大小限制（默认 1MB，太小的文件传不上去） -->
<bean id="multipartResolver"
      class="org.springframework.web.multipart.commons.CommonsMultipartResolver">
    <property name="maxUploadSize" value="10485760"/>   <!-- 10MB -->
    <property name="defaultEncoding" value="UTF-8"/>
</bean>
```

```xml
<!-- 依赖：commons-fileupload -->
<dependency>
    <groupId>commons-fileupload</groupId>
    <artifactId>commons-fileupload</artifactId>
    <version>1.5</version>
</dependency>
```

## 2. 文件下载

### 白话理解

把服务器上的文件通过响应流写给浏览器，并触发"另存为"对话框。关键在两个响应头：`Content-Disposition: attachment`（触发下载）+ 文件名编码。

### 写法一：HttpServletResponse 手动写

```java
@RestController
public class FileController {

    @GetMapping("/download")
    public void download(HttpServletResponse response) throws IOException {
        // 要下载的文件
        File file = new File("D:/uploads/avatar.png");

        // ① 告诉浏览器：这是下载附件（attachment = 弹保存框）
        response.setContentType("application/octet-stream");
        response.setHeader("Content-Disposition",
            "attachment;filename=" + URLEncoder.encode(file.getName(), "UTF-8"));

        // ② 把文件字节流写给响应
        Files.copy(file.toPath(), response.getOutputStream());
    }
}
```

> 注意文件名中文要 `URLEncoder.encode` 转码，否则浏览器下载时中文名乱码。

### 写法二：ResponseEntity 返回（推荐）

```java
@RestController
public class FileController {

    @GetMapping("/download2")
    public ResponseEntity<byte[]> download2() throws IOException {
        File file = new File("D:/uploads/avatar.png");
        byte[] data = Files.readAllBytes(file.toPath());

        // 声明下载头（含文件名）
        HttpHeaders headers = new HttpHeaders();
        headers.setContentDispositionFormData("attachment",
                URLEncoder.encode(file.getName(), "UTF-8"));

        return new ResponseEntity<>(data, headers, HttpStatus.OK);
    }
}
```

### 两种写法对比

| 写法 | 白话 | 特点 |
|------|------|------|
| 手动写响应流 | 自己往 response 里写字节 | 灵活但代码多 |
| ResponseEntity | 返回数据 + 头信息，框架帮你写 | **简洁，推荐** |

## 3. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ 上传：MultipartFile 接文件 + transferTo 保存 | 表单必须 multipart/form-data |
| ✅ 下载：Content-Disposition: attachment 触发保存框 | 中文文件名要 URL 编码 |
| ✅ 大文件上传要配 multipartResolver | 默认 1MB |
| ✅ 推荐 ResponseEntity 写法下载 | 简洁 |
