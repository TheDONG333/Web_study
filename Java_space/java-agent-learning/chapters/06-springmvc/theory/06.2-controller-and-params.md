# 06.2 控制器与请求参数获取

> **学习目标**
> - 掌握 @Controller 和 @RestController 的区别
> - 掌握四种参数获取方式：普通参数、对象接收、@RequestParam、@PathVariable、@RequestBody
> - 能根据场景选择正确的接收方式

---

## 1. @Controller vs @RestController

### 白话理解

两个都是"我是控制器"的标记，区别只有一个：**方法返回值怎么处理**。

| 对比 | @Controller | @RestController |
|------|------------|----------------|
| 返回 String | 当作**视图名**（找 JSP 页面） | 当作 **JSON 字符串**直接返回 |
| 返回对象 | 默认不处理（报错） | **自动转 JSON** 返回 |
| 等于 | @Controller | @Controller + 每个方法都加 @ResponseBody |
| 使用场景 | 传统页面开发（返回 JSP） | **前后端分离（只返回 JSON）** |

```java
@Controller          // 返回视图：return "list" → 找 list.jsp
public class PageController {
    @GetMapping("/page")
    public String page() {
        return "list";   // 去找 /WEB-INF/jsp/list.jsp
    }
}

@RestController       // 返回数据：return user → 自动转 JSON
public class UserController {
    @GetMapping("/user")
    public User user() {
        return new User(1, "张三");   // 响应体直接是 {"id":1,"name":"张三"}
    }
}
```

> 现代项目基本都是 @RestController（前后端分离），学的时候重点掌握它。

## 2. 参数获取方式一：普通参数（最简单）

### 白话理解

前端传 `?name=张三&age=20`，你直接在方法参数里声明 `name`、`age`，Spring 自动填进去。

```java
@RestController
public class UserController {

    // 请求: GET /user?name=张三&age=20
    @GetMapping("/user")
    public String user(String name, Integer age) {
        return "name=" + name + ", age=" + age;
    }
}
```

### 技术要点

- 方法参数名和请求参数名**一致**时自动绑定
- 基本类型（int）传少了会报错，用包装类型（Integer）可传可不传

---

## 3. 参数获取方式二：对象接收（表单场景最常用）

### 白话理解

参数太多时，不用一个个写——**直接用一个对象接**，Spring 按属性名自动填充。

```java
public class User {
    private String name;
    private Integer age;
    private String email;
    // getter/setter 省略
}

@RestController
public class UserController {

    // 请求: POST /user/add?name=张三&age=20&email=x@y.com
    @PostMapping("/user/add")
    public String add(User user) {   // 一个对象接住所有参数
        return "收到: " + user.getName() + ", " + user.getAge();
    }
}
```

> **白话**：参数名 = 对象属性名，Spring 自动 new 对象并 set 进去。表单提交几十个字段也不怕。

---

## 4. @RequestParam：重命名 + 必填校验

### 白话理解

前端传的参数名和你的方法参数名不一致时，用 `@RequestParam` 指定"前端传的叫什么"；还可以设置**必填**。

```java
@RestController
public class UserController {

    // 前端传: ?username=张三&pageNo=1&pageSize=10
    @GetMapping("/user/list")
    public String list(
        @RequestParam("username") String name,    // 前端叫 username，方法里叫 name
        @RequestParam(value = "pageNo", defaultValue = "1") int page,     // 不传默认 1
        @RequestParam(value = "pageSize", required = false) Integer size  // 可不传
    ) {
        return "name=" + name + ", page=" + page;
    }
}
```

### 属性说明

| 属性 | 作用 |
|------|------|
| `value` | 指定前端传的参数名（前后端名字不同时用） |
| `required` | 是否必填（默认 true，缺了就 400 报错） |
| `defaultValue` | 不传时的默认值 |

---

## 5. @PathVariable：从 URL 路径取参数（RESTful 风格）

### 白话理解

RESTful 风格把 id 直接放在 URL 里（`/user/1`），而不是 `?id=1`。用 `@PathVariable` 把路径中的 `{id}` 取出来。

```java
@RestController
public class UserController {

    // 请求: GET /user/1    → id=1
    // 请求: GET /user/2    → id=2
    @GetMapping("/user/{id}")
    public String getById(@PathVariable("id") Integer id) {
        return "查询用户: " + id;
    }
}
```

### 技术要点

- URL 里的 `{id}` 花括号是**占位符**
- `@PathVariable("id")` 把路径中的值取出来赋给参数
- 一个 URL 可以有多个占位符：`/user/{id}/order/{orderId}`

---

## 6. @RequestBody：接收 JSON（前后端分离最常用）

### 白话理解

前端用 AJAX 提交 JSON 字符串（`Content-Type: application/json`），用 `@RequestBody` 让 Jackson 把 JSON **自动反序列化成对象**。

```java
@RestController
public class UserController {

    // 请求体（JSON）:
    // {"name":"张三","age":20,"email":"x@y.com"}
    @PostMapping("/user/save")
    public String save(@RequestBody User user) {   // JSON → User 对象
        return "保存成功: " + user.getName();
    }
}
```

### 前端配合（ajax 示例）

```javascript
fetch('/demo/user/save', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },   // 必须声明 JSON
    body: JSON.stringify({ name: '张三', age: 20, email: 'x@y.com' })
})
```

### 四种方式速查表

| 方式 | 请求示例 | 适合场景 |
|------|---------|---------|
| 普通参数 | `?name=张三` | 参数少（1-3 个） |
| 对象接收 | 表单/URL 参数多 | 表单提交 |
| @PathVariable | `/user/1` | RESTful 风格 URL |
| @RequestBody | Body 传 JSON | 前后端分离（主流） |

> ⚠️ 常见报错：用 @RequestBody 接收时，前端没传 `Content-Type: application/json`，会报 415 Unsupported Media Type。

---

## 7. 关键要点总结

| 要点 | 说明 |
|------|------|
| ✅ @RestController = 返回 JSON | @Controller = 返回视图 |
| ✅ 普通参数：方法参数名 = 请求参数名 | 最基础 |
| ✅ 对象接收：参数名 = 对象属性名 | 表单大量参数 |
| ✅ @PathVariable：URL 花括号取值 | RESTful |
| ✅ @RequestBody：JSON 自动转对象 | 前后端分离主流 |
