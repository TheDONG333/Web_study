## 学习建议

### 时间安排
- **每天 2-3 小时**：阅读理论（~1h）+ 动手实践（~1.5h）
- **总计约 40 天**可完成全部章节 + 3 个综合项目

### 学习方法
1. **理论先行**：先通读 theory/ 文档，建立知识框架
2. **实操巩固**：按 practice/ 指南动手操作，做完才算学会
3. **AI 辅助**：遇到疑问先用 AI 工具查询，培养独立解决能力
4. **笔记输出**：用自己的话总结每章要点，形成个人知识库

### 实操验收标准
每章实操完成后，你应该能回答：
- 这章的核心概念是什么？
- 动手做了什么？每一步解决了什么问题？
- 如果从头再做一次，能否不靠文档完成？
